# 05 迁移与清理清单

逐模块说明现有代码在 v5 中的去向：**保留**（不改）、**复用**（逻辑不变，调整入口或数据结构）、**改造**（职责变化）、**删除**（任务卡指明的时机删除）。执行智能体删除前必须确认没有新代码依赖；不确定时在验证记录中说明并保留。
