# K52 — 真实 QGIS 与端到端验收边界

环境：macOS、QGIS-LTR 自带 Python；临时运行目录；不部署插件、不改变用户正在使用的工程、不使用真实 API Key。2026-10-27 的结果记录在本目录日志和 qgis-summary/。

## 实际通过的 QGIS 链路

1. `TestProductionFlowWebSocketRealQGISLoadAndExport` 两场景（指定指南、编排提交计划）：生产 WebSocket、计划工具、角色运行器、实际 QGIS 加载/导出及核验，属性与坐标保留。模型为固定工具序列，未调用在线模型。
2. `TestBuiltinAcquisitionRealQGIS`：真实内置省域抽取/共享边界，6 次本地 HTTP 下载，自动获取8层和用户数据补齐8层，实际 QGIS 加载、符号化、标签字段和来源保留。六种非边界数据为明确标注的合成夹具，不宣称公开服务在线可用。
3. 五个旧制图验收案例通过新 GuideStore → CartoPlan → StartFromPlan 链路：route-no-review、route-with-review、statistical、province-density、survey-route。全部输入哈希不变，三个黄金对照 success=true、differences=[]。审查回执为固定夹具，PDF/PNG 是真实 QGIS 导出。
4. `test_layout_refactor_qgis[plan_observation]`：真实版面元素 ID、类型、角色、启用网格、说明文字可经 layout_info 读取，为最终确定性检查提供观察值。

产物保留于 `/private/tmp/enio2-v5-acceptance-20261027-final/` 和 `/private/tmp/enio2-v5-qgis-production/`（系统临时目录可能日后清理）；结果/黄金比较摘要已复制入仓库，原数据未修改。

## 可复现命令

在 carto_agent：

```sh
AUTOCARTO_QGIS_PYTHON=/Applications/QGIS-LTR.app/Contents/MacOS/python \
AUTOCARTO_FLOW_QGIS_EVIDENCE_DIR=/private/tmp/enio2-v5-qgis-production \
go test ./internal/websocket -run TestProductionFlowWebSocketRealQGISLoadAndExport -count=1 -v
AUTOCARTO_QGIS_PYTHON=/Applications/QGIS-LTR.app/Contents/MacOS/python \
go test ./internal/api -run TestBuiltinAcquisitionRealQGIS -count=1 -v
```

仓库根目录运行五案例 `autocarto/tests/integration/acceptance/run.py`，输入为三个 `autocarto/tests/integration/acceptance/scenarios/*.json` 与两个 `docs/refactor/acceptance-flows/*/resources/acceptance.json`。解释器同上；`AUTOCARTO_GOLDEN_BASEMAP_DIR` 指向已有 China_map 数据，`AUTOCARTO_ROUTE_RENDERER_DIR` 指向已有 RouteBezierPlotPlugin；`PYTHONPATH` 包含仓库、golden/.runtime/deps 和 QGIS plugins，`QT_QPA_PLATFORM=offscreen`。
