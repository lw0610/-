# K11 指南加载、资源作用域与指南接口

## 结论
完成；主进程装配由主泳道接入。

## 改动摘要
- GuideStore 复用原包存储、原子保存、复制、导入导出、资源锁与修复；主文档优先 GUIDE.md。
- 全局停用保存于 config/guides.yaml；API /guides 提供列表、详情、保存、复制、导入导出、停用、资源迁入/修复。
- GuideBackend 只挂编排智能体；技能名 guide-<id>；Get 附加资源摘要及当前会话 data_find 本地预判回调。
- Resolve 返回 GuideDoc、锁摘要和 resource.Scope；作用域保留数据表文件夹关联及已解析资源。
- API 无模型、编译器、网络调用；新接口不依赖方案启用流程列表。

## 计数与耗时
指南 HTTP 创建/读写/复制/导入导出/停用链路无模型依赖，调用次数 0。定向 Go 回归约 3 秒。

## 与方案不一致之处
GuideBackend 位于 internal/deepagent 而非 subagents：现有 config 依赖 subagents，后者导入 flow 会形成循环。接口和仅编排端挂载行为一致。

## 修改涉及范围以外文件
- 包存储相关文件：识别 GUIDE.md、保留资源锁、使资源引用/导出使用指南声明。
- convert.go：导入必须在临时目录先转换才能原子发布；与 K12 共享实现，避免先发布旧格式后失败的中间态。
- deepagent/agent.go、agentruntime/deep_builder.go/types.go、api/api.go 的接线与其他泳道同文件变更由主泳道最终提交。
