# K20 — 可见制图计划契约与版本存储

新增 `internal/plan`：严格 JSON 结构、事实/假设/数据来路、能力步骤、产出与检查；校验真实数据、已查询候选、步骤依赖、指南来源约束。无模型调用或下载。

每会话 `plans/<id>.json` 保存当前状态，`<id>.vN.json` 保存不可变版本。乐观版本冲突、原子写、路径编号和符号链接检查。`UpdateStatus` 不允许改写计划正文。

验证：`go test ./internal/plan -count=1` 通过，覆盖无效模型结构、前向依赖、虚构来源、真实文件、并发版本竞争与历史不可变。执行与 WebSocket 联调分别记录 K21/K22。
