# K42 计划执行与恢复

## 结论
计划在原位置切换为执行进度；任务区保留当前计划摘要，完整步骤过程仍可展开查看。任务与过程继续在同一面板，文件独立。

## 改动摘要
- 计划/运行使用同一 plan_id 对应，不再生成另一份重复流程卡。接收运行快照时统一投影到运行状态。
- 新 flow.acquisition_progress 以 row 独立显示各数据获取状态、已接收量及速度；总大小未知不构造百分比；终态拒绝迟到的普通进度。
- needs_replan 展示换来源/调整、提供数据、可选步骤跳过和停止操作；replanning 时禁用重复修订，保留停止入口。
- 新计划中断恢复保留 run_id，资源变化只允许明确 continue_snapshot；不再提供偷偷重新运行完成步骤的 restart 操作。
- 完成卡保留交付文件、来源说明、核验结论、剩余问题及文件区定位。
- 旧 flow-plan 运行记录只读；保留历史展示所需的最小类型，不保留旧输入表单、预览、编译状态与角色映射组件。
