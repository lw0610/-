# K30 统一数据服务

## 结论
已实现并接入工具、HTTP 本地预览和计划执行器；全链路装配由 K21/K22 记录。

## 改动摘要
- 新增 internal/dataservice：类别/描述/资源清单查询、12层候选理由、30分钟会话查询快照、固定选择、实际 Engine.RunItem 获取、兜底规范化登记与会话来源说明。
- 用户文件只读核验；混合清单返回逐行路径与 EntryOverrides。获取结果入原有数据仓并登记会话文件区。
- 新增数据记忆，旧输入记忆启动迁移先保留原字节备份；指南/数据及类别/范围两种键。
- 范围与数据仓命中使用原 acquire 实现；bbox 输入南西北东转换为内部西南东北。
- sessionfiles 增加精确外部附件登记，逐文件授权；不授权整个外部目录，重新读取时核验符号链接身份。

覆盖：三种需求写法；Find 零工具调用、零网络；非法候选/过期；用户绑定与缺项混合；本机/离线/HTTP假服务器/OSM假服务器取数；数据仓命中；兜底几何不符拒绝；来源网址脱敏；外部文件相邻路径和变更符号链接拒绝。

## 与方案差异
- 已确认计划固定保存 Selection，执行可超过查询30分钟；普通工具仍严格要求未过期 find_id，避免长任务等待造成已确认来源失效。
- 根据用户此前明确要求，联网默认 direct；兜底仍按 ask/allow/deny。所有测试使用临时目录与环回服务器，没有访问公网或真实运行数据。
- 新增 sessionfiles/external.go 与 API 独立路由文件属于附件和统一数据服务实际连通所需。
- 在线瓦片安全加载限制：旧引擎返回 `waiting_user` 和无密钥连接定义时，统一服务不能宣称获取完成。当前未接入“同意密钥写入 QGIS 工程”的独立确认，`data_find` 明确排除天地图瓦片定义及其缓存；`data_get` 对已保存的选择和任何适配器意外返回的定义再次拒绝，不复制或登记为数据。已下载的栅格文件、已有工程栅格图层仍可核验使用，不影响天地图其他数据类别。
