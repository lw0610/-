# K43 制图指南库

## 结论
/指南页面使用 GUIDE.md 与 /api/guides；旧 /flows 入口只负责跳转。模板与样式库及其显式资源管理继续保留。

## 改动摘要
- 列表支持搜索、启用/停用、新建/导入；详情支持复制、编辑保存、导出、在对话中引用。
- 详情分别展示适用任务与信息、数据、图层处理、制作要点、版面、产出检查、资源和 Markdown。
- 数据来源预览调用无会话 /api/data/find，只查询来源，不获取数据或写入任务绑定。
- 保存显示确定性解析后的预览和可操作诊断；旧 FLOW.md 导入后显示转换报告，不请求模型编译。
- 内置指南只读，可显式复制；资源导入/删除/修复/锁定沿用指南 API；资源同名选择使用确切 ID。
- 删除旧流程输入记忆、角色映射、固定步骤预览、编译状态组件和专属协议测试。资源回归迁移到 features/guides。
