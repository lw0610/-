## 构建隔离修正

收尾发现 Next.js 15 在 `output: export` 模式下把非默认 distDir 用作导出目录，实际编译缓存仍为 `.next`。仅设置环境变量不能隔离已有开发服务器。因此门禁需在临时源码副本构建前端，避免测试清理/覆盖正在使用的缓存；正常开发启动方式保留。

真实页面测试中的工具包开关会写配置，所以 Playwright 后端也复制四类内置资产到临时目录，避免只隔离 HOME 却修改源码资产。Tauri 构建脚本会写 sidecar，因此 Rust 检查同样使用临时源码副本；check 不再清理原项目构建目录。

实际 Rust 检查还发现 macOS 的 `/var` 与 `/private/var` 路径别名会令 Node 脚本的 CLI 入口字符串判断失效，静默跳过后端构建。入口改为比较真实路径；通过符号链接启动与作为模块导入的真实 Node 行为回归均通过，不靠预先生成旧 sidecar 掩盖问题。
