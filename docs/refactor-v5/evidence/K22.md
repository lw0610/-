# K22 — 从可见计划执行

planexec 把已校验 CartoPlan 绑定到实际角色、数据与指南资源；按能力选择现有角色或临时补齐普通能力，受限/隐藏包不隐式授权。路线知识使用系统执行器；审图步骤检查模型图像能力。原文仅绑定受信任引用，不让模型复制原文作为执行输入。

Controller.StartFromPlan 执行已确定步骤，acquire 通过数据服务；没有旧 Compiler、条件解释或输入表单入口。当前做法、可用数据、指南段落、真实前序结果进入步骤上下文。每步和最终可机器检查条件使用真实产出/图层/版面观察值核验，主观项记录人工检查。

收尾回归额外覆盖：同次 data_find 的两个候选可分别绑定不同数据项，选择按 data ID 保存，不互相覆盖；已有底图目录缺少必需文件时，计划提交即返回具体诊断，不把不能启动的计划伪装成已接受；隐式获取步骤的编号不与模型提供的步骤编号冲突。

验证：真实 QGIS 生产 WebSocket/角色/工具链加载与导出两场景；v3 五个实际 QGIS 固定动作案例；三方案×四指南×用户/获取两输入组合的24格校验和启动。详见 K51/K52，固定模型与动作不代表在线模型质量。
