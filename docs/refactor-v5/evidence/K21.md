# K21 — 计划工具与确认策略

新增 plan_propose/plan_revise 与会话服务、计划列表/修改/开始/取消/失败决定接口。主智能体的三种方案统一注入指南与真实能力索引；成功提交后通过主模型边界结束本轮，错误计划允许模型继续修正，避免提交后重复自由执行。

本地校验、来源候选与乐观版本检查先于持久化。高影响假设、超过十步和读图审查按 when_needed 确认；always/never 可配置。**按用户先前明确要求，network_policy 默认 direct，替代方案中的默认 confirm**；服务开关、deny 及兜底策略仍生效。

验证：runtimecontrol 的实际 Eino ChatModelAgent 脚本模型测试覆盖 propose/revise 成功立即停止、首轮无效后修正；planexec 覆盖四类确认条件；WebSocket 覆盖正常提交、Plan 不执行、版本冲突；API 测试覆盖读取、修改、错误码、附件核验。最终命令结果统一见 K51。
