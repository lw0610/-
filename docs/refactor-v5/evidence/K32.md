# K32 数据源手册

## 结论
九个内置来源均补齐结构化手册；本机来源可通过既有来源API读写，前端编辑由K44泳道完成。

## 改动摘要
Handbook包含good_for/not_for/coverage/scale/fields/cautions/examples。缺失适用范围产生DS_HANDBOOK_MISSING警告，不阻断旧本机来源；Find候选带摘要，系统数据专家提示带目录生成的一行索引。

## 验证
`go test ./internal/datasource ./internal/dataservice -count=1` 通过，覆盖九份内置手册、缺失警告、候选摘要和目录索引。目录加载不联网。
