# K41 澄清与制图计划

## 结论
已接入独立的制图计划快照、候选数据来源及版本化编辑，取代旧流程预览。澄清复用既有多问题 InterruptCard，支持默认答案、补充说明和统一提交；对话框也可直接回答。

## 改动摘要
- 计划卡显示事实及来源、假设、数据绑定、候选来源依据、制作步骤、产出和完成检查。
- 修改事实/假设会把明确的修改草稿放入对话；替换数据来源通过版本化 HTTP 请求确定性处理。
- Plan 模式不显示开始按钮；Build 的 ready/awaiting_confirmation/preview 可开始；编辑、开始和取消都有请求中与失败反馈。
- plan_event、事件重放、session_state、HTTP 历史恢复按 session_id/plan_id/version 合并。终态及较新版本不被旧消息覆盖。
- 前端发送 GUIDE 引用的链接直接指向 /chat，避免根页跳转丢失参数；切会话时拒绝迟到引用。

## 验证
- PlanCard.test.tsx：候选 ID 修改、事实来源、Build/Plan 隔离、旧版本/终态重放、恢复资源快照、必要步骤不可跳过、自动修订期间禁用重复动作。
- WebSocketProvider.test.tsx：真实前端接收分支的 plan_event、非当前会话隔离与 session_state 恢复。
- InterruptCard.test.tsx：3 条现有多问题/默认值/统一答案测试继续通过。
- 全量前端 385 tests 通过；真实 Go 资源 API 6 tests 另行通过。lint、tsc、隔离 Next production build 通过。
- 完整浏览器套件 `npm run test:e2e`：38 passed / 5 skipped（52.8 秒）；其中指南真实 HTTP/磁盘验收另以显式开关运行，1 passed（6.8 秒）。剩余 4 项需要真实 QGIS 环境。
- 已实际查看 K41-plan-card.png：事实来源、步骤与开始/取消入口可见，无重叠。

## 方案差异
按用户偏好保留“任务与过程”同面板；没有恢复列表警告计数。未访问真实用户会话或调用模型；浏览器执行计划为 HTTP/WS 契约回放，真实执行器另由 Go 测试验证。
