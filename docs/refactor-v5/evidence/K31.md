# K31 系统数据获取智能体

## 结论
系统专家已挂入所有 Build 方案；Plan 模式不创建专家或恢复执行工具。

## 改动摘要
- system_data_acquisition 不写入用户方案，主模型默认、设置可覆写。固定规则为先 find 后 get；只有没有确定性候选时才允许自定义OSM/门户/搜索；必要确认以单次查询保存；兜底文件必须 register。
- system_route_knowledge 直接复用专用知识执行器，只持有契约与编译工具，不依赖默认角色。
- 普通角色在既有包授权之后过滤 OSM/browser/web/admin/file_downloader；GEE保留分析，拒绝下载模板及明确下载原语。任意 Python 并非安全沙箱，本卡不将静态原语限制表述为安全隔离。
- 默认方案与主程序装配由主泳道同步；用户方案文件不改。隐藏兼容 file_downloader；data_load_tiles归入隐藏 data-acquisition 包，修复基线归属缺失。
