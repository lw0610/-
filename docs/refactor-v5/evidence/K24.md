# K24 — 共用主智能体的 Plan / Build

移除独立 PlanExecute builder、独立 Plan 模型与旧工具配置入口。Plan 复用主模型、业务提示词、指南后端与系统规则，只有只读工具与计划工具可达；不创建执行子智能体，不允许 download/OSM 获取等写操作。Build 使用同一计划服务执行。

设置不再显示 Plan 专用配置与开关。旧 YAML 的 plan/flows/flow_policy 只作迁移输入，规范化不进入新运行。Plan 模式提交保存 preview；切到 Build 可开始同一 ID/版本，模式同步更新会话投影。

验证：agentruntime 新白名单/统一主模型测试，WebSocket Plan 不执行及切换 Build 后原计划版本完成测试，前端设置断言与 e2e（见 K51）。
