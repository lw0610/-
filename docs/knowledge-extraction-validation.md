## 修复范围

问题协议的提示和校验共用字段表。模型响应入口兼容明确的等价写法，例如路线 `paths.nodes → nodes`、主体 `name → identity`，不任意去除 JSON 路径前缀。多条非法问题一次反馈；对象绑定、原文依据、真实歧义仍须通过校验。

历史统一语义核对还出现表示层误报：已说明的实体归并会机械更新其他对象的引用；可选空数组与缺省字段含义相同；新路线的说明可能已经覆盖其新路径。比较规则仅对这些已证明等价的情况放行。节点顺序、事实字段、证据变化以及已有路径的修改仍要求说明和依据。

修改比较只作用于副本，不删除用户草稿中的字段。新增路线的说明仅能覆盖同样新增、且证据均包含在该说明中的路径。抽取缓存版本同步更新。

路线与路径分别核对：父路线比较路径 ID 序列，子路径独立比较全部事实，避免对子路径已说明的修改再要求父路线重复说明。路径增加、删除、归属和顺序变化仍属于父路线的实质修改。
