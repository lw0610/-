# F20 数据类别与来源目录

日期：2026-10-25。

已建立 23 个类别、9 个内置来源；Go 统一严格加载词表和来源 YAML，解析别名及隐含参数，建立稳定排序与目录指纹。用户来源须用 user. 前缀，不能覆盖内置；内联密钥、含凭据 URL、越界相对路径和未列入白名单的下载地址均拒绝。

疆域来源规则在 TerritoryReason 统一实现；用户明确登记的本机数据按方案保留例外，数据来源标签不构成系统认证。

隐藏工具包说明位于现有架构要求的 autocarto/skills/system/data-acquisition/SKILL.md；工具定义、类别与来源资产位于 autocarto/tools/system/data-acquisition。方案中把 SKILL.md 放入 tools 的写法未沿用，避免形成扫描器不会发现的工具包。

外部事实核实（官方页面，2026-10-25）：

- [Natural Earth 下载目录](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/)及[物理要素目录](https://www.naturalearthdata.com/downloads/10m-physical-vectors/)：10m 铁路、公路、地名、河流、湖泊与海岸线实际下载入口；[许可](https://www.naturalearthdata.com/about/terms-of-use/)为公有领域。字段候选仍以每次规范化的实际字段核验为准，不保证所有图层都有中文名。
- [Geofabrik 中国目录](https://download.geofabrik.de/asia/china.html)：最新全国 Shapefile 不可用，当前 PBF 约 1.5 GB，采用 china-latest.osm.pbf。体量只是目录估计，实际下载仍执行上限。
- Overpass 清单与 v4 固定上游节点契约一致，真实节点可用性由 F60 运行时测速确认，不在目录加载时联网。
- 天地图、GEE、门户及 GeoCode 专题底图来源目前标 experimental；待适配器各自验证后逐项启用。GeoCode 代码 MIT 不等同于地理数据许可，不把来源未核实的线数据列为可用疆域来源。

验证：go test ./internal/datasource -count=1 通过。覆盖 23/9 数量、别名、省级参数、稳定 JSON、用户覆盖拒绝、冲突、未知类别、密钥、白名单以及本机来源例外；测试完全离线。
