# F61 地理文件信息与缩略图

## 结论
完成。两个工具只读取独立的数据图层，不向当前 QGIS 工程注册图层；缩略图使用新 PNG 路径，拒绝覆盖。

## 改动摘要
- 新增 `data-loading/handlers/geodata.py`、两份工具定义与真实 QGIS 测试。
- 数据加载工具包加入文件核验和缩略图方法。
- `geodata_inspect(path, layer_name?, sample_limit=5)` 返回 `data.kind/format/layers`，每层包含 CRS、范围、数量、字段和样本。栅格返回尺寸、分辨率、波段和无数据值。
- CSV 坐标表可显式传 `x_field/y_field/crs`；样本最多 200 行。
- `geodata_thumbnail(path, output_path, size=512, layer_name?)` 返回新 PNG 路径；单波段按 2%–98% 拉伸。
- 无兼容层。

## 运行的命令与结果
QGIS Python 使用现有 `autocarto/tests/golden/.runtime/deps` 的 pytest，设置 QGIS 自带 PROJ/GDAL 数据目录及 `QT_QPA_PLATFORM=offscreen`。

| 命令 | 结果 |
|---|---|
| QGIS Python -m pytest autocarto/tests/test_geodata_inspect_qgis.py -q | 4 passed，0.76 秒 |

覆盖 Shapefile、GeoJSON、两子图层 GeoPackage、GeoTIFF、CSV 坐标表、损坏文件、样本上限、重复输出拒绝；断言源文件字节、工程图层数与脏状态不变。

## 跳过的测试及原因
无在线请求；不需要联网或真实用户工程。端到端文件区调用由 F71/F72 验证。

## 与方案不一致之处
真实 QGIS 测试名使用 `_qgis.py`，使现有质量门禁自动在独立进程运行。现有 QGIS Python 未安装全局 pytest，复用项目已存在的隔离依赖。

## 遗留问题与后续任务需要知道的事
