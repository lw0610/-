# F23 Go 适配器与 F24 开放数据适配器

本机来源只读；内置行政区通过明确的工具通道按 level/within 提取；HTTP 有主机及重定向约束、流式大小限制、429/503 重试、取消清理、地址凭据脱敏。Overpass 复用 F60 的共享实现，先统计再查询，必要时按行政区范围分批，必需行拒绝不完整结果。

验证：`go test ./internal/acquire` 通过，覆盖假 HTTP 的白名单/重定向/超限、只读本机文件与 Shapefile 辅文件、离线调用参数、共享 OSM probe/get 与部分结果拒绝。真实 QGIS 管线验收见 F51；没有把假 HTTP 结果写成真实公网下载成功。

Natural Earth 公共领域与下载目录、Geofabrik 中国提取页已核对。中国整包目前使用 PBF；区域请求优先 Overpass，大型整包不会排在小区域查询前面。疆域类数据仍受来源合规标签限制，内置参考数据不代表法定地图审定。
