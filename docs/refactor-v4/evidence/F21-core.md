# F21 确定性数据需求规划

实现范围：类别/行参数与字段绑定，比例尺估计，区域代码和范围解析，按政策/服务/密钥存在性/大小/覆盖范围排除来源，稳定排序，隐式获取步骤；真实输入到位后重新规划，既可输入也可产出的范围优先使用输入，否则等待产出。区域索引由已有行政区资产提取，不新增另一份边界几何。

本地验证（2026-10-25）：`internal/acquire` 规划测试、`internal/flow` 需求测试、输入/逐行覆盖测试通过；预览无模型、无网络。API 的零模型/零网络调用守卫由 F50 记录。后续内置流程变更的全量回归见 F50/F51。

数据仓命中用完整缓存规格与文件校验确认后排在网络来源之前；缓存读取仅在输入检查/运行规划发生，保存流程不会启动下载。
