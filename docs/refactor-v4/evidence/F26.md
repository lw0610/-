# F26 数据仓与获取配置

日期：2026-10-25。

已实现 raw/out/manifest.json 及原子 index.json 数据仓。缓存键覆盖来源版本、类别参数、查询、范围（四位小数）、面摘要、比例尺档位、规范化规格和适配器版本。命中须同时满足有效期、文件大小与 SHA256；范围包含命中只返回原件，调用方须按新范围重新规范化。

同键获取期间持有操作系统文件锁，进程退出自动释放；索引另有文件锁，避免多个进程同时提交时丢条目。临时目录与原子替换保留失败前的成品；容量不足明确报错，不清理其他数据。目录遍历、符号链接和短键碰撞均拒绝。

获取配置默认：2048 MB、20 GB、总并发 2、单主机 1、自动换源开启、联网搜索关闭。显式关闭自动换源在 YAML 往返中保留。LLMProviderConfig.Vision 由 F11 实现、因共享 config.go 归属在此卡一并提交；对应解析与保存往返已测试。

验证：go test ./internal/acquire ./internal/config -count=1 通过。数据仓覆盖同键并发只构建一次、过期重建、摘要损坏、范围包含、取消文件锁等待、超容量不删除已有数据及路径/符号链接拒绝；配置覆盖默认值和显式 false。
