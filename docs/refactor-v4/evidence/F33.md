# F33 数据获取设置

已新增设置页“数据获取”（`/settings/acquisition`）及后端导航元数据。

- 来源列表显示类别、许可、配置是否就绪和具体缺失原因；内置来源只读。本机来源可扫描文件夹或 CSV/XLSX 数据清单，确认类别、字段对应和必要参数后保存；编号由服务器生成 `user.` 前缀，支持编辑目录/文件位置与删除配置，原数据保留。
- 扫描复用 resource.InspectLocalData 和既有表格解析器，保留中文/英文表头规则；文件名/类别别名仅是建议，不将扫描结果直接写入来源目录。macOS 临时目录符号链接先规范化，以符合已有 XLSX 安全读取规则。
- 数据仓使用 `<HOME>/data/acquired`，展示容量、来源、类别、范围、时间、有效期、文件完整性及引用运行。引用只读 `<HOME>/data/sessions/**/flows/*/run.json` 的 acquisition.items[].store_key；删除须确认，过期清理保留有运行引用的缓存，运行记录保留。
- 获取配置经 SettingsMutationService → ConfigService 写入并 Validate，不直接改 YAML；总/单主机并发、容量、下载上限、失败回退及联网搜索设置可管理。联网搜索默认关闭，界面明确说明每次搜索仍需确认。增加 Overpass URL 及非有限容量校验，拒绝凭证 URL，允许合法本机 HTTP(S) 测试地址。
- 所有新增设置接口只做本机扫描/读取/配置写入，不联网、不调用模型；可用性标明为本机配置状态，不虚构远端登录或服务探测结果。

验证（Go 进程显式使用 mktemp HOME 和 AUTOCARTO_DISABLE_KEYRING=1）：

- `npm test -- src/features/acquisition/DataAcquisitionWorkspace.test.tsx`：5 项通过。覆盖可用性、内置只读、确认后保存、字段映射、删除时运行引用提示、联网搜索默认关闭及配置保存。
- 对新设置页、编辑组件、features/acquisition 和 settingsRegistry 执行 ESLint：通过。

范围说明：注册本机数据源不会读取 GIS 属性表来猜测字段；字段建议仅来自清单的显式映射，用户可以确认/修改。真实模型、在线服务、QGIS 运行态测试留给整体验收；不读取真实运行目录。UI 测试放在 features/acquisition，避免现有 vitest 对 components/settings 的排除规则导致测试未执行。
