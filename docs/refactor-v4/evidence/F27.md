# F27 获取执行器与流程运行

实现：请求只登记计划；执行阶段对范围已确定的条目立即启动后台获取，与前序模型步骤并行。产出依赖在生产步骤完成后解析，原用户步骤编号不变。管线包含只读原件、安全解压、规范化/派生、质量核验、原子入库、缓存与大范围原件复用。系统调用使用独立允许清单；GEE 只接受固定模板和编码参数。

流程取消和应用退出取消后台任务；各任务独立记录来源、尝试、错误、产物、许可说明。隐式数据步骤等待自己的条目。失败通过既有人工确认机制提供重试、换来源、自行提供、跳过和终止；必需项不允许跳过，自行提供也必须通过同样的类型/字段/范围核验。原件不改写，临时核验副本自动清理。流程完成后数据仓继续保留。

已验证：
- `TestAcquisitionPrefetchParallelEffectiveInputAndCache`：前序步骤与下载并行；条件及步骤消息看到实际文件；新控制器复用缓存而不重新下载。
- `TestAcquisitionPendingOutputDoesNotStartEarly`：等待产出后按范围外扩获取。
- `TestAcquisitionFailureProvideAndRequiredCannotSkip`、恢复审查补充用例：错误几何/缺字段/无法读取不能进入下一步，补交有效文件恢复。
- `TestAcquisitionCancellationStopsWorker`；`go test -race ./internal/acquire ./internal/flowrun ./internal/resource` 通过。
- F51 的真实 Go→QGIS 管线验证获取成品确实可读、可加载、可套用样式，非仅测试文件存在。

Mac `/var` 与 `/private/var` 使用规范路径判断，避免将同一文件当作外部原件重复复制。Shapefile 主文件固定在结果第一项，其他成员完整保留。点/线结果不使用面积覆盖率误判，面/栅格仍保留覆盖检查。
