# F25 验证记录

## 实现与边界

- 天地图县级驻地适配器复用现有地名客户端、250ms 全局请求间隔、429 Retry-After 与服务端密钥读取。先取内置县域与代表点，逐县查询政府驻地；核对 6/9 位行政代码、县名、政府名称和落点位于原县面（含洞），按与代表点的距离选候选并记录距离。查询失败或候选不合格时保留县域代表点并明确标注近似，不能冒充实际驻地。取消立即停止。
- 天地图适配器先返回不含密钥的 `LayerDefinition`。运行阶段已补齐明确确认和隐藏加载器：用户同意密钥进入 QGIS 工程后，最终绑定实例的私有桥才注入密钥；普通工具参数、来源记录和回执不携带密钥。现有 authcfg 不能证明可替代 tk 查询参数，因此不假装支持免确认认证配置。完整闭环及真实 QGIS 测试密钥验证见 F25-tiles.md。
- GEE 获取只允许系统目录中的 5 个固定模板，私有工具调用契约为 `gee_run_script({template, params})`。参数编码为 JSON 后注入固定脚本；目录穿越、任意脚本、来源以外的数据集、无效范围/分辨率/年份/日期均拒绝。
- DEM、WorldCover、Sentinel-2、WorldPop、VIIRS 模板保留源投影，按显式范围和分辨率裁剪下载。光学包含场景云量与 SCL 云/阴影筛选，夜光用 cf_cvg>0 过滤未观测像素，空集合拒绝下载。默认年份与时段明确记录，可按支持范围修改。
- 新 `download_features` 默认最多 5,000 个要素和 25 MiB，可设置但最高 50,000 / 100 MiB。仅接受 HTTPS Google Earth Engine/Google 下载域名，重定向也校验；流式下载，GeoJSON 结构与数量校验后排他发布；禁止覆盖，返回实际文件、字节数、SHA-256。签名 URL 不进入进度/错误摘要。

## 上游事实核实

- [天地图搜索 V2](https://lbs.tianditu.gov.cn/server/search2.html)：queryType=12、9 位 gb 行政范围、POI countyCode。area 中的 bound/中心点不足以作为行政区面来源；未声明边界下载能力。当前账户具体日配额、QPS 和批量使用授权未获可核验证据，来源保持 experimental，不把现有 250ms 节流说成官方配额。
- [Copernicus DEM 2024_1](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_DEM_GLO30_2024_1)：旧 GLO30 已弃用，采用新 ImageCollection。30m DSM 含建筑和植被，EGM2008 高程；遵守 WorldDEM-30 许可及署名，不能写成裸地 DTM 或 CC 通用许可。
- [ESA WorldCover v200](https://developers.google.com/earth-engine/datasets/catalog/ESA_WorldCover_v200)：2021 年、Map、10m、CC BY 4.0。
- [Sentinel-2 SR Harmonized](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED)：B4/B3/B2、10m、反射率比例 10000、SCL 与云量属性，Copernicus Sentinel 条款。
- [WorldPop GP/100m/pop](https://developers.google.com/earth-engine/datasets/catalog/WorldPop_GP_100m_pop)：2000–2020 年、population、原始约 92.77m、CC BY 4.0。默认 2020，不能称为当前人口。
- [VIIRS VCMSLCFG](https://developers.google.com/earth-engine/datasets/catalog/NOAA_VIIRS_DNB_MONTHLY_V1_VCMSLCFG)：avg_rad / cf_cvg、约 463.83m、public domain；0 亮度不能直接解释为无数据。
- GEE 目录已核实不等于用户云端已授权；真实服务可用性仍由扩展服务配置、认证和网络决定。
