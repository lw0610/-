# 流程编写指南

流程是一份给智能体阅读的 Markdown 文档，保存为 `FLOW.md`。在流程页新建或复制内置流程，直接编辑正文，下方实时预览；保存不调用模型。每次运行时，模型结合流程、用户消息和实际数据提出本次制图计划。

## 文档写法

```markdown
---
名称: 河流专题图
说明: 为用户指定区域制作河流分布图，标出河名，适用于水系分布与流域底图任务。
版本: 1.0.0
---

# 河流专题图

需要所选区域的线状河流数据，显示河名，使用样式「河流线」。
用户提供文件或工程已有合适图层时直接复用；缺少数据时查找可用来源。

核验范围、几何和名称字段，加载真实数据并套用样式。
使用版面「四角对齐版式」，纸张默认 A4 横向。
主图覆盖所选区域，图例只展示实际图层，说明实际数据来源。

导出 PDF，交付成果路径和数据来源，不改写原文件。
```

头部的名称和说明供列表、搜索和流程匹配；编号取目录名。说明应写清适用请求，建议不超过300字。版本用于内部锁定和导出，不是软件版本。

正文自由组织。可以用段落、列表、表格辅助阅读，不要求固定章节。程序只读取头部和样式/版面引用，不把表格解析成执行指令。需要写清：

- 每项数据是什么、几何类型和范围，以及是否由前面的处理产生。
- 每个图层如何处理、采用什么样式、标注什么；默认纸张和输出格式。
- 可选环节何时执行，以及成果怎样检查。

不写本机数据路径、角色分工、工具调用参数或专用条件语法。数据路径在运行时通过对话、附件、文件夹或 `@图层` 提供。不要把数据文件打包进流程。

## 样式和版面引用

写作 `样式「河流线」`、`版面「四角对齐版式」`。`版式「…」`仍可识别；没有类型前缀的 `「名称」` 在与库中样式或版面同名时也会识别。没有匹配资源的普通引用不会被当成数据绑定。

编辑时可从“样式与版面”选择资源并插入引用。详情右侧显示资源预览和标注字段等说明；保存生成 `flow.lock`。导出携带文档、锁定文件和引用的资源，不携带任务数据。

路线样式与军标、图例属于路线工具预设，正文直接写“路线样式用‘红蓝对比’”“专题点用‘军标’符号”，不作为公共资源引用。

## 数据怎样确定

用户提供的数据优先。用户给文件夹时，系统按文件/图层名称、类别别名和实际几何对应到需要的数据；不确定的匹配在计划卡标“请确认”。工程中符合要求的现有图层可以复用，缺项才经统一数据服务获取。由处理产生的数据引用对应步骤的产出。

计划卡逐项展示“您提供、工程图层、由某步产生、自动获取”及来源理由、样式预览。用户可以修改来源，也可以用自然语言修改计划。流程作者不需要制作 CSV 清单或配置某个固定底图文件夹。

## 提示与旧流程迁移

保存时只做本地检查：头部缺名称/说明、样式或版面不存在/重名、正文出现角色分工或本机路径。提示说明具体问题，不阻止保存，不生成固定执行步骤。

旧 `GUIDE.md` 和结构化 `FLOW.md` 会备份转换为普通 `FLOW.md`。原文、旧包资源和迁移报告保留；旧样式集拆分为单样式，符号和路线样式转为工具预设，数据说明与参考文档内容转入正文。转换后查看报告并核对要求，迁移不会自动执行地图任务。

内置流程只读，可复制为自己的流程。停用后不进入模型的流程索引；选择流程本身不会改变启用状态。
