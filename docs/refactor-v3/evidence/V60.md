# V60 运行目录指向检测

## 结论
完成。启动日志与诊断页都能提示数据目录越界，并显示当前进程实际日志文件。

## 改动摘要
- Config.DirectoryDiagnostics 只读计算当前运行目录、数据目录与日志文件；外部数据目录报告 `DATA_DIR_OUTSIDE_RUNTIME_HOME`，目录内不报告警告。
- 比较目录边界而非简单字符串前缀，识别指向外部的符号链接；路径尚未创建时解析已有父目录，不创建任何文件。
- ConfigService 初始化时记录警告；保存启动时日志目录，设置修改后仍显示本进程实际日志文件。
- 前端归一化保留 runtime_paths，诊断页显示运行根目录、实际数据目录、当前日志文件和后端警告。
- WebSocket 首次快照与后续广播同样带 runtime_paths，避免前端收到推送时清掉 HTTP 加载的路径提示。
- 现有 GET /api/runtime/snapshot 增加 `runtime_paths: {runtime_home,data_dir,log_file,warnings:[{code,message}]}`。
