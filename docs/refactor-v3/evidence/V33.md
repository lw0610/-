# V33 模板与样式库界面

## 结论
完成。公共库类型以服务端 public 字段为准；导入、从工程保存、旧资源移入流程、别名调整均有界面入口。

## 改动摘要
- 页签为“模板与样式”；以按钮筛选版式、样式、样式集，导入无需先选类型，结果显示识别类型。
- 从工程保存支持版面主图 UUID、可见矢量图层默认选择、单图层样式；未连接实例时禁用并说明原因。
- 保留显式覆盖、引用查询、替换与删除保护；捕获同名冲突提供另存和确认替换。
- 样式集详情允许修改各条目别名；旧资源区列出流程引用并移入对应用户流程，诊断也可触发迁移。

## 跳过的测试及原因
真实工程捕获完整链路在 V51 统一执行。组件测试已覆盖多地图 UUID、默认可见矢量选择和未连接禁用；工具本体的真实 QGIS 测试见 V31。

## 与方案不一致之处
现有替换接口只有文件路径，不能支持界面修改别名。V32 扩展同一接口的 entry_aliases，仍走校验和备份事务；未要求用户打开 CSV。捕获接口增加 replace_id，只有明确替换操作才发送。

## 修改了涉及范围以外的文件
`scripts/playwright_check_server.py` 改用已有的静态导出路由服务：原 http.server 无法把 `/flows` 映射到 `flows.html`，导致原流程测试页面 404。修复后上述浏览器测试通过；V50 将流程测试加入默认门禁。
