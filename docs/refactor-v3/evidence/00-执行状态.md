## 明确的验证边界
V51 的在线真实模型部分没有执行。方案一方面要求复用用户实际模型配置，另一方面禁止读写真实 `autocarto_data/`；本轮遵守禁止访问约束。隔离环境没有可用凭据，所以没有伪造四个流程的真实模型耗时、错误率或页面关闭实测。模拟慢模型和无界面 QGIS 不替代这一验证。

用户桌面的实时 QGIS/Tauri 点击、发行包 smoke、依赖 Linux 发行产物的检查也没有冒充通过。具体通过/跳过清单、命令和证据见 [V51](V51.md) 与 [工程捕获往返](V51-capture.md)。

## 使用上的变化
- 保存后显示步骤预览，“重新编译”在后台更新模型分析；独立“体检”已按后续用户要求移除，未完善的计划可按已有内容运行。
- “公共资源库”界面变为“模板与样式库”，只管理版式、样式、样式集；其他内容由流程或工具携带。
- 数据位置在流程输入中选择、即时校验并在本机记住；换目录不需要改清单。固定清单的文件组成仍由流程作者维护，未新增图形化逐行清单编辑器。
- 旧绑定只在启动迁移时按可恢复、先备份、幂等规则转为记忆；测试没有修改用户真实记忆和配置。
- 运行目录越界只提示，不改写已有配置。源码启动与插件重新加载说明见项目 [README](../../../README.md)。
