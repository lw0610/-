# V41 文件输入记忆与即时校验

## 结论
完成。运行表单预填本机上次选择，数据问题逐输入显示；流程中心可以设置和清除记忆，旧绑定入口已移除。

## 改动摘要
- 先显示输入表单，再读取本机记忆；预填优先于默认值，异步返回不会覆盖用户已编辑的字段。
- 输入变化 400 毫秒后调用校验接口；错误或校验未完成时不能发送，发送前再以真实对话正文校验一次。
- 图层列表可用时核对所选图层；资源条目的未知存在状态显示为运行时检查。
- 输入页提供记忆修改/清除；关联清单显示其文件夹输入；旧绑定改用 convert_to_input 修复动作。
- 后台更新保留表单值，计划就绪后更换模型可再次触发增量入队。
