# V30 模板与样式库后端收窄

## 结论
完成。公共管理接口只显示版式、样式、样式集；旧非公共用户资源可读、可迁入流程。跨子系统完整门禁在 V50/V51 汇总。

## 改动摘要
- 格式正本新增 public；公共列表筛选三类，retired 返回旧用户资源及流程引用（包含声明 label）。
- 默认路线样式迁到路线工具 assets/resources，编号保持 route_style.mono；只按编号解析，owner 为 tool，拒绝显式覆盖和盗用工具编号，不出现在公共列表。
- 导入自动识别 QPT、布局 YAML、QML、含 QML 的目录；过渡 type 必须匹配；其他类型拒绝。缺对照表时只在副本生成规范 CSV，源目录保持原样。
- 非公共旧用户资源解析给 FLOW_RESOURCE_LIBRARY_TYPE_RETIRED / adopt_into_flow。adopt 在流程存储事务内复制完整资源、改写准确声明位置并移除锁，原库资源保留；内置流程只读。
- include_library_deps 只打包公共类型；原有随包私有资源保持原样。
- 公共绑定写入返回 410；已有绑定只读兼容。
- 兼容登记：resource_import_type_v2、resource_library_retired_type_v2、resource_library_binding_read_only_v2。
