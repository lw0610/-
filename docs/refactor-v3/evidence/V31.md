# V31 从 QGIS 保存版式与样式集

## 结论
完成。两个新工具公开注册并具备 `tool.invoke` 权限，真实 QGIS 测试通过。没有操作用户正在使用的工程或真实 `autocarto_data/`。

## 改动摘要
- 新增 `layout_save_template`：将当前版面序列化到临时 QPT，只在 XML 副本中设置唯一的 `main_map`，原版面的 ID、文字和工程脏状态保持不变；多个地图项需显式传 ID 或 UUID，返回可选项与文字占位符。
- 新增 `style_set_export`：默认导出图层树中实际可见的矢量图层，支持名称/ID 显式选择；自动生成合法且不重名的 QML 文件名和 UTF-8 对照表。简单字段标注写入标注字段；表达式、规则及禁用标注留空，原始状态保存在 QML 中。
- 样式集输出须为空或不存在，防止覆盖已有文件；图层名称重复时要求明确选取或重命名，避免生成违反 Go 资源格式唯一性要求的对照表。
- 新工具加入版面编排、符号与标注工具包及通用使用说明。
- 补充 `layout_list.data.layouts[].map_items` 的 ID/UUID/名称；单图层样式保存支持 ID、拒绝歧义名称；图层列表增加真实图层树 `visible`，包含父组隐藏状态，供 V32/V33 使用。
- 资源旁路守卫对新导出模块限定为只写表：读取调用及非纯写模式仍拒绝，有反例测试。
- 新登记的兼容层：无。

## 跳过的测试及原因
- 本卡未执行完整 `./build.sh check`，由 V50/V51 在各泳道完成后统一执行。

## 与方案不一致之处
- 现有 `layout_list` 只提供文本，方案要求的地图项选择信息原来不存在，本次补充结构化返回，保留原文本。
- `open_project` 依赖默认公开策略，新工具采用显式 policy 声明，满足同一授权检查。
- 现有样式集格式要求图层列唯一。对于同名图层，导出工具明确报错，不能只给 QML 文件加后缀而写出不可导入的重复表行。

## 修改了涉及范围以外的文件
- `_shared/print_layout_impl.py`：给 V32 的版面选择接口提供结构化数据。
- `_shared/style_basic_impl.py`、`cartography/layer_save_style.yaml`：现有单样式工具支持前端选择得到的图层 ID，避免重名时保存错误图层。
- `_shared/project_state_impl.py`：为 V33 默认选择可见矢量图层提供真实可见性。
- `autocarto/tests/test_resource_bypass_guard.py`：允许方案明确要求的只写导出，继续禁止 Python 解析资源表。

## 遗留问题与后续任务需要知道的事
- V32 接口应消费工具 envelope 的 `data`；版式为 `{path,map_items,placeholders}`，样式集为 `{directory,mapping_file,entries}`。失败返回 `success:false`，多个地图项需选择时附 `error_type:main_map_required` 和 `data.map_items`。
- `main_map_item` 建议传 UUID，覆盖无名称或同名地图项。
