## 遗留问题与后续任务需要知道的事
1. **`~/.zshrc` 导出了指向 Eino 的 `AUTOCARTO_HOME`、`AUTOCARTO_ASSETS_ROOT`**。从终端启动的任何 enio2 进程（含 `go test`、`./build.sh dev` 拉起的 Tauri）都会继承它们；`./build.sh check` 自己会覆盖。本轮所有测试命令都显式覆盖。这与 V60 相关，未改动用户配置。
2. **enio2 的 `autocarto_data/config/config.yaml` 中 `data_dir` 指向 `Eino/autocarto_data/data`**。当天 Eino 目录下的后端 `agent.log` 确为 enio2 后端写入（日志加载了只有 enio2 才有的 `flow-control` 工具包）。同属 V60。
3. **QGIS 自带 Python 没有 pytest**。本轮用 QGIS 的 pip 把 pytest 9.1.1 安装到会话临时目录，通过 `PYTHONPATH` 提供，未改动 QGIS 安装。
4. **`carto_agent/defaults/config.yaml` 被 `.git/info/exclude` 排除，但 `carto_agent/defaults/embed.go` 用 `//go:embed` 嵌入它**：全新克隆或 worktree 无法编译 Go 模块。该文件头注释写明 API Key 不写入其中，字段检查也只有 token 上限等配置，不含凭据。建议纳入版本库（需用户确认，本轮未改）。基线 worktree 中为此手动复制了该文件。
