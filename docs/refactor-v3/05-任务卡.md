# 05 任务卡

每张卡可以单独交给一个执行智能体。交付时附上本卡、`README.md`，以及卡中"必读"列出的文档。

通用要求（每张卡都适用，不再重复）：
- 遵守 `README.md` §6 与 v2 `README.md` §6 的全局约束；开工前对照 §3 文件归属表，确认要改的文件没有被进行中的任务占用。
- 完成后写 `docs/refactor-v3/evidence/<任务号>.md`（格式见 `evidence/README.md`），在 `refactor/v3` 分支提交（提交信息以任务号开头，不推送）。
- 命令约定：Go 命令在 `carto_agent/` 下执行；前端命令在 `autocarto-web/` 下执行；Python 命令在仓库根执行，`$PYTHON_BIN` 指能导入 QGIS 的解释器（见 `build.sh`），`test_*_qgis.py` 每个模块单独进程运行。
- 测试一律使用临时运行目录（`AUTOCARTO_HOME` 指向 `t.TempDir()` 或临时目录），不读写真实的 `autocarto_data/`。
- 新增兼容层时在 `carto_agent/defaults/architecture/removal_ledger.yaml` 追加条目，并跑 `go test ./internal/control -run TestCompatLayerRequiresRemovalCriteria -count=1`。
