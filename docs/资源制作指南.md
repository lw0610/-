# 样式与版面制作指南

“样式与版面”页签保存两类可复用的制图外观：单个图层的 QML 样式，以及 QPT 或 `.layout.yaml` 版面。数据文件可作为任务输入，也可登记到独立的内置图层库；路线样式和军标等属于工具预设。

## 导入

点击流程页的“样式与版面”，选择“导入模板或样式”。支持 `.qml`、`.qpt`、`.layout.yaml` 文件，也支持包含这些文件的文件夹。文件夹中的各文件会分别导入为独立资源，不再合并为样式集。

资源名称是列表中显示、流程正文中引用的名称。不填时取文件名；单文件重名时提示更换名称，批量导入的同名项自动增加后缀并列出结果。内置与用户资源的名称共同保持唯一。

内置资源只读。修改内置外观时复制成一个不同名称的用户资源，并在流程正文引用新名称。

底图的普通颜色、线宽和标注可以直接写在流程中，不必先制作 QML。流程明确画法时按参数设置并读回核对；复杂标准符号仍可引用样式，例如铁路。流程未写画法时使用内置图层登记的默认样式，没有则采用简洁表达并说明。现有 11 个样式继续保留，供预览和复用。

## 从当前工程保存

连接 QGIS 后点击“从当前工程保存”：

- 图层样式：可选一个或多个图层，每个图层分别保存为一个 QML 样式，默认取图层名。
- 版面：选择打印版面，保存为 QPT。版面包含多个地图项时，明确选择主地图。

保存后自动读取适用几何、标注字段或版面说明。资源库按样式/版面分类，样式可按点、线、面、栅格筛选，并支持来源、名称、标签和说明搜索。

## 标注字段

QML 可以保留符号和标注设置。使用时按本机可用字体处理中文黑体回退，遵循流程规定的尺寸基准与纸张缩放；读取实际字体和设置，留意返回的警告。套用时可用工具参数 `label_field` 指定数据中的实际字段，不必为了套样式去改数据字段名。若未指定、样式中的字段又不存在，系统尝试 `NAME`、`name`、`name:zh`、`名称` 等常见字段；没有合适字段时关闭标注并返回原因。规则或表达式标注保留其原有语义，具体支持情况以工具返回为准。

`layer_load_styles` 支持一次传多组图层、样式和可选标注字段，逐项报告成功和失败。流程正文不需要写工具调用形式。

## 预览与维护

每项资源显示预览，点击可放大。导入、从工程保存或替换内容时，通过 QGIS 在独立工程里生成预览，不往当前地图添加示例图层。未连接时显示占位，连接后补生成；内容变化后旧预览失效。

用户资源可重命名、编辑说明与标签、替换文件、导出或删除。详情列出引用它的流程；删除或替换前会展示影响。原资源内容按迁移/替换规则备份，重命名后应留意引用更新提示。

## 文件组织与迁移

每个资源一个目录：`resource.yaml`、实际 QML/QPT/layout 文件、`preview.png`。内置位置是 `autocarto/resources/system/styles/` 或 `layouts/`；用户位置是 `<AUTOCARTO_HOME>/resources/styles/` 或 `layouts/`。清单中的版本和摘要用于身份、替换与依赖核验。

旧国标底图样式拆为11个独立样式。旧用户样式集按“样式集名-图层名”拆分；名称冲突加后缀。旧资源目录在迁移前备份，并记录新位置。

内置路线“单色”“红蓝对比”、军标和图例位于路线工具的私有资产目录；用户旧流程自带预设迁到 `<AUTOCARTO_HOME>/presets/route-cartography/`。这些不在公共资源库里显示。旧数据说明和参考文档的有用内容转入流程正文，任务数据继续通过对话或文件夹提供。

## 内置图层库

流程页的“内置图层”与“样式与版面”分开：图层保存可复用数据的登记，样式保存外观，版面保存打印布局。系统自带行政区面、界线和明确标为近似的驻地点；近似驻地点不能冒充真实政府驻地。

连接 QGIS 后点击“导入图层文件夹”，选择本机数据目录并扫描。扫描结果逐个显示文件、几何、要素数、字段和坐标系建议。确认或修改名称、类别、注记字段、实际坐标系、适用比例尺；不需要的行取消勾选。点击“确认导入”后生成登记和预览，原文件留在原处。

登记名称用于列表显示及流程引用，例如 `图层「河流线」`。原文件中的声明坐标系与实际使用坐标系分别记录；文件声明错误时只改登记解释，不改原文件。比例尺写分母范围，例如 500000 至 2000000，表示约 1:50 万至 1:200 万。未确定的参数不假装已经核实。

图层按包名和类别分组，可搜索名称、别名和类别。详情显示预览、范围示意、来源许可、注记字段、默认样式与两种坐标系。用户导入的登记可编辑元信息、更新预览或删除登记；删除不删除原始数据文件。原文件移动或变化时，按提示重新选择并核对。

用户登记保存在 `<AUTOCARTO_HOME>/layers/`，系统登记保存在 `autocarto/data/layers/system/`。图层库识别到旧的底图文件夹登记时显示迁移入口；先扫描再确认，不自动搬走数据。在线 OSM、Earth Engine、天地图和门户服务仍在“设置 → 数据获取 / 扩展服务”配置。
