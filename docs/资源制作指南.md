# 样式与版面制作指南

资源库只保存两类可复用的制图外观：单个图层的 QML 样式，以及 QPT 或 `.layout.yaml` 版面。数据文件属于任务输入；路线样式和军标等属于工具预设。

## 导入

点击流程页的“样式与版面”，选择“导入模板或样式”。支持 `.qml`、`.qpt`、`.layout.yaml` 文件，也支持包含这些文件的文件夹。文件夹中的各文件会分别导入为独立资源，不再合并为样式集。

资源名称是列表中显示、流程正文中引用的名称。不填时取文件名；单文件重名时提示更换名称，批量导入的同名项自动增加后缀并列出结果。内置与用户资源的名称共同保持唯一。

内置资源只读。修改内置外观时复制成一个不同名称的用户资源，并在流程正文引用新名称。

## 从当前工程保存

连接 QGIS 后点击“从当前工程保存”：

- 图层样式：可选一个或多个图层，每个图层分别保存为一个 QML 样式，默认取图层名。
- 版面：选择打印版面，保存为 QPT。版面包含多个地图项时，明确选择主地图。

保存后自动读取适用几何、标注字段或版面说明。资源库按样式/版面分类，样式可按点、线、面、栅格筛选，并支持来源、名称、标签和说明搜索。

## 标注字段

QML 可以保留符号和标注设置。套用时可用工具参数 `label_field` 指定数据中的实际字段，不必为了套样式去改数据字段名。若未指定、样式中的字段又不存在，系统尝试 `NAME`、`name`、`name:zh`、`名称` 等常见字段；没有合适字段时关闭标注并返回原因。规则或表达式标注保留其原有语义，具体支持情况以工具返回为准。

`layer_load_styles` 支持一次传多组图层、样式和可选标注字段，逐项报告成功和失败。流程正文不需要写工具调用形式。

## 预览与维护

每项资源显示预览，点击可放大。导入、从工程保存或替换内容时，通过 QGIS 在独立工程里生成预览，不往当前地图添加示例图层。未连接时显示占位，连接后补生成；内容变化后旧预览失效。

用户资源可重命名、编辑说明与标签、替换文件、导出或删除。详情列出引用它的流程；删除或替换前会展示影响。原资源内容按迁移/替换规则备份，重命名后应留意引用更新提示。

## 文件组织与迁移

每个资源一个目录：`resource.yaml`、实际 QML/QPT/layout 文件、`preview.png`。内置位置是 `autocarto/resources/system/styles/` 或 `layouts/`；用户位置是 `<AUTOCARTO_HOME>/resources/styles/` 或 `layouts/`。清单中的版本和摘要用于身份、替换与依赖核验。

旧国标底图样式拆为11个独立样式。旧用户样式集按“样式集名-图层名”拆分；名称冲突加后缀。旧资源目录在迁移前备份，并记录新位置。

内置路线“单色”“红蓝对比”、军标和图例位于路线工具的私有资产目录；用户旧流程自带预设迁到 `<AUTOCARTO_HOME>/presets/route-cartography/`。这些不在公共资源库里显示。数据清单和参考文档的有用内容转入流程正文，任务数据继续通过对话或文件夹提供。
