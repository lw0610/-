# 01 概念与界面

本文从用户角度定义重构后的概念和页面。前端任务（T14、T24、T32）以本文为准，后端接口见 `02`、`03` 文档。

## 1. 用户只需要懂的东西

```text
智能体方案
├── 角色（子智能体）
│     ├── 职责说明（通用，不写具体专题）
│     ├── 模型
│     ├── 类型：通用智能体 / 专用执行器
│     └── 勾选的工具包（只能勾工具包）
├── 所有角色共享的工具包（可选）
└── 启用的流程包

工具包（系统提供）：一类工具 + 使用说明 + 参考资料
流程包（用户编写/导入）：FLOW.md + 可选 resources/
资源（流程包自带或公共资源库）：数据清单、样式、版式、符号、参考文档
```

和现在相比：
- 不再有"技能包"这个说法，也不再有"分类包、流程包、知识包"混在同一个下拉框里。
- 不再有"专属技能包"（方案独有的技能包目录）。方案需要的场景能力，通过启用流程包获得。
- 方法类说明（缓冲分析怎么做、分级设色怎么选方法）并入对应工具包，勾了工具包就同时有了它的使用说明。
- 流程包不挂到角色上。流程的每一步写明由哪个角色负责，系统运行时把这一步交给那个角色。

## 2. 典型操作路径

**A. 使用内置流程制图**
1. 对话页输入框旁选择"流程：行军路线图"（或保持"自动"，让编排智能体判断）。
2. 系统弹出输入表单（来自流程的"需要准备"）：史料原文默认取本条消息、纸张、是否质量审查。
3. 发送后，对话中出现流程进度卡片，逐步显示状态。
4. 完成后卡片给出成果文件和问题清单。

**B. 导入别人给的流程包**
1. 流程中心 →"导入"，选择文件夹、`.zip` 或单个 `FLOW.md`。
2. 系统解析并体检，显示步骤预览和诊断。例如"第 2 步：数据清单「中国底图」需要选择底图所在文件夹""第 5 步：制图专家没有勾选'版面编排'工具包"。
3. 用户点诊断旁的修复按钮（选择文件夹、为角色勾选工具包）。
4. 体检无错误后，在方案中启用该流程。

**C. 自己写一个新流程**
1. 流程中心 →"新建"，选择"从模板开始"或"让 AI 起草"（输入一段描述）。
2. 在编辑器里按模板写：适用场景、需要准备、使用的资源、步骤、必须遵守、交付。
3. 写作时可以打开右侧"能力手册"，按中文名搜索系统有哪些能力，例如搜"排版"会看到"按版式一次排版""按 QGIS 模板排版"。
4. 点"解析预览"查看体检结果，修正后保存。
5. 用"试运行"跳到对话页运行。

**D. 调整方案**
1. 设置 → 智能体方案 → 编辑角色 → 勾选工具包（按分组，显示中文名和工具数）。
2. 在"启用的流程"区勾选需要的流程，旁边显示该流程在当前方案下的体检状态。

## 3. 页面设计

### 3.1 设置 → 智能体方案（改造现有 `AgentConfigWorkspace.tsx`、`AgentEditDrawer.tsx`）

方案编辑区分三块：

1. **基本信息**：名称、说明、默认执行模式（保留现有）。
2. **角色**（卡片列表）：每张卡显示名称、类型、职责说明摘要、模型、工具包标签和工具总数。编辑抽屉分为：
   - 基本：显示名称、类型（通用智能体 / 专用执行器）、职责说明（多行文本）、独立模型、启用开关。
   - 工具包（仅通用智能体）：按分组显示复选列表。分组为数据、在线数据、矢量、栅格与分析、制图、版面与输出、脚本、质检。每个工具包显示中文名、一句话说明、工具数，可展开查看工具中文名清单。系统基础包以锁定状态显示在顶部，说明"所有角色自动拥有"。隐藏包不显示。
   - 专用执行器（仅专用执行器）：选择执行器类型（当前只有"路线知识抽取"），显示说明"仅在流程中使用，不参与自由委派"。
   - 高级：用户输入模板、运行模式提示词（保留现有字段）。
3. **所有角色共享的工具包**：沿用现有"全局技能包"位置，但只列工具包。
4. **启用的流程**：列出全部流程包（内置与用户），每行显示名称、版本、来源、在当前方案下的体检状态（可用 / 有警告 / 有错误），复选启用；点名称跳转到流程中心详情。默认全部启用。

Plan 角色配置保持现有结构，只是把技能包选择器换成工具包选择器。

删除的界面元素：混合"智能体技能包"选择器、知识抽取专家的特殊文案（改为由角色类型决定的通用文案）。

### 3.2 工具中心（改造现有 `ToolCenterWorkspace.tsx`）

- **工具包**页签：只列工具包（系统基础包和隐藏包放在折叠的"系统"分组）。详情抽屉显示工具清单（中文名 + 英文名）、使用说明正文、参考资料列表。
- **能力手册**页签（替代原"目录"页签的面向用户部分）：按工具包分组的全部工具，显示中文名、说明、关键词、所属工具包；支持中文搜索。每个能力给一句"写流程时可以这样描述"的示例，如"按「四角对齐版式」排版"。
- 导入功能只面向开发者导入工具包。导入的 SKILL.md 如果没有 `tools`，提示"这是说明文档，请改写成流程包，或作为资源放入流程包"。

### 3.3 流程中心（新页面 `/flows`）

**列表**：名称、说明、版本、来源（内置/用户）、更新时间、在当前方案下的体检状态。操作：导入、新建、复制、导出、删除。内置流程只能复制后修改。

**详情 / 编辑**（左右两栏）：
- 左栏：FLOW.md 编辑器（Markdown），顶部"插入模板段落"菜单（插入步骤、插入资源引用、插入条件），右侧可展开能力手册。
- 右栏页签：
  - **步骤预览**：按步骤显示卡片，内容为序号、标题、负责角色、条件、做法摘要（可展开全文）、建议使用的能力（中文名）、引用的资源、完成标准（产出名称 + 类型）、失败时处理方式。
  - **体检**：错误、警告、提示三组。每条显示位置（第几步/哪个资源）、说明和修复按钮。修复动作见 §5。
  - **资源**：本流程 `resources/` 下的文件（上传、替换、删除、预览），以及引用的公共资源。数据清单显示每个条目的实际路径和是否存在，需要绑定基准目录的显示"选择文件夹"。
  - **输入**：解析出的输入项（名称、类型、必填、默认值），即运行时的表单预览。
- 底部：保存（自动重新解析）、重新解析、试运行。

**导入对话框**：选择路径（桌面端用系统选择器，与现有 `SkillImportDialog` 交互一致）、同名时"覆盖（旧版本自动备份）/ 另存为新流程"。导入后直接打开详情页的体检页签。

**新建对话框**：从空白模板、复制已有流程、AI 起草（输入一段描述，生成 FLOW.md 草稿，T55 可选）。

### 3.4 资源库（流程中心下的"公共资源"页签）

按类型列出公共资源：数据清单、样式、版式、符号、参考文档；区分内置和用户。支持导入、预览（样式和版式显示文件信息；符号显示缩略图；数据清单显示条目和存在状态）。内置资源只读。

### 3.5 对话页（改造 `ChatInput.tsx`、`MessageList.tsx`）

- 输入框旁新增"流程"选择器：默认"自动"（编排智能体判断是否使用流程），可指定某个已启用流程。
- 指定流程时，在发送前展开输入表单（来自执行计划的 `inputs`）。"对话原文"类输入默认取本条消息，不需要填写。
- 流程运行时显示**流程进度卡片**：流程名称、总体状态；每个步骤一行，显示状态（等待/进行中/完成/跳过/失败/等待确认）、负责角色、耗时；展开可看回执摘要、产出（文件可点击打开）、校验结果和问题。失败后等待用户时，卡片内直接给出"重试本步 / 跳过本步 / 终止流程"按钮和补充说明输入框。
- 现有知识审查卡片（`KnowledgeReviewCard`）在流程第 1 步需要人工确认时照常出现，流程卡片显示"等待确认"。

### 3.6 Plan 模式

命中流程时，Plan 模式不再让模型自由规划，而是展示该流程的步骤预览和体检结果，并检查输入是否齐全。没有命中流程时保持现有 Plan 行为。

## 4. 文案规范

| 场景 | 使用 | 不再使用 |
|---|---|---|
| 一类工具的集合 | 工具包 | 技能包、分类包、category |
| 专题做法 | 流程包、流程 | 技能、workflow、知识包、编排 skill |
| 工具 | 能力（中文名），必要时括注英文名 | 只显示英文函数名 |
| 编译检查 | 体检、错误、警告、提示 | validation、lint |
| 每步输出 | 产出、回执 | artifacts（用户界面） |
| 方案独有的包 | 无（不再提供） | 专属技能包 |

状态文案：等待中、进行中、已完成、已跳过、失败、等待确认、已终止、完成但有问题。

## 5. 体检的一键修复动作

| 诊断 | 修复按钮 | 动作 |
|---|---|---|
| 负责角色不在当前方案 | "改为…" / "在方案中添加角色" | 下拉选择现有角色并改写 FLOW.md 中该步的"负责"；或打开方案页 |
| 角色缺少某工具包 | "为〈角色〉勾选〈工具包〉" | 调用方案保存接口追加工具包 |
| 资源找不到 | "上传资源" / "从公共资源库选择" | 打开资源页签 |
| 数据清单未绑定 / 文件缺失 | "选择文件夹" | 选择基准目录并保存绑定 |
| 系统没有对应能力 | "查看能力手册" | 打开能力手册并以该步做法搜索；同时提示可能需要开发新能力 |
| 条件无法转为规则 | 无（提示） | 说明运行时由模型判断，建议改为"提供了 X 时执行"这类句式 |
| 执行计划过期 | "重新解析" | 调用编译接口 |
