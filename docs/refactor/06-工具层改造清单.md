# 06 工具层改造清单（Python / QGIS 插件）

实现任务：T40–T47。每项都要求：旧参数在过渡期继续可用；新工具配中文 `display_name` 和说明；配单元测试和（需要 QGIS 的）`*_qgis.py` 测试；与黄金样例对比（T01）。

## 0. 原则

1. **工具只提供机制**：样式、版式、数据来源、标注名称都由参数或资源文件传入，代码里不写具体专题、图层名、颜色方案和路径。
2. **能一步做完的不拆成十步**：把原来要模型连续调用多次、并按公式计算的操作，做成一次确定性调用（排版、按样式集上样式、按清单加载）。
3. **可重复执行**：同样的调用执行两次，结果与执行一次相同（同名版面替换、已加载图层复用），这样流程某一步失败后可以安全重试。
4. **返回真实结果**：返回实际图层 ID、版面元素 ID、矩形、文件路径，供执行器校验和后续步骤使用。
5. **规则由工具保证**：字号锁定、审查导出 DPI、元素不越界等规则由工具检查，不再写在提示词里让模型遵守。

## 5. 版面（T44、T45）

### 5.1 新工具 `layout_compose`（按版式一次排版）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `layout` | string | 是 | 版面名称；已存在时替换（`replace_existing` 默认 `true`） |
| `spec` | string | 是 | 内置版式名（如"四角对齐版式"）或 `.layout.yaml` 绝对路径 |
| `paper` | string | 否 | `A0`–`A4`，或 `宽x高`（毫米）；默认取版式的 `default_paper` |
| `orientation` | enum `landscape`/`portrait` | 否 | 默认取版式 |
| `title` | string | 是 | 标题 |
| `overview_text` | string | 否 | 综述正文；版式中综述为可选元素，不传时不添加 |
| `overview_title` | string | 否 | 综述标题 |
| `map_layers` | array | 否 | 主图显示的图层（名称或 ID，顺序即上下顺序）；不传时用工程中可见图层 |
| `extent_layers` | array | 否 | 用这些图层的范围确定主图范围；不传时用 `map_layers` |
| `extent` | object | 否 | `{xmin, ymin, xmax, ymax, crs}`，与 `extent_layers` 二选一 |
| `padding` | number | 否 | 范围留白比例，默认 `0.03` |
| `legend_layers` | array | 否 | 图例中的图层；不传时用 `map_layers` |
| `legend_title` | string | 否 | 默认"图例" |
| `legend_extra_items` | array | 否 | `[{label, image_path, size_mm}]`，图例中额外的示意条目（如路线箭头） |
| `elements` | object | 否 | 开关覆盖，如 `{"grid": false, "border": false}` |
| `overview_max_width_ratio` | number | 否 | 覆盖版式中的综述宽度比例 |

行为：
1. 创建或替换版面，设置纸张。
2. 按版式页边距放主图，设置图层和范围（复用 `set_map_extent_handler` 中"按图层范围并转换到地图坐标系"的逻辑，保持地图框尺寸）。
3. 依次添加装饰框、网格（间隔按范围自动取整，稀疏）、标题、综述、图例、比例尺、指北针；字号取版式字号表中该纸张的值（毫米）。复用 `print_layout_items_impl.py`、`print_layout_advanced_impl.py` 中的内部函数，不通过工具接口互相调用。
4. 图例、综述等先按内容调整尺寸，再按 `anchor` 计算位置：`inside` 时与参照框对应角对齐；`outside` 时紧贴参照框外侧；比例尺使用实际尺寸对齐，不强制缩放。
5. 每个元素写入自定义属性：`autocarto/compose_role`（语义名：main_map、border、grid、title、overview、legend、scalebar、north_arrow）、`autocarto/anchor`（JSON：to、at、placement）、`autocarto/font_locked`（true）、`autocarto/compose_spec`（版式名）。
6. 检查所有元素都在页面内、标题综述图例比例尺指北针互不相交；有问题时放入 `warnings`，不静默失败。

返回 `data`：`{layout, page_size_mm, item_ids: {main_map, border, grid, title, overview, legend, scalebar, north_arrow}, rects_mm: {<item_id>: {x, y, width, height}}, warnings}`。没有添加的元素不出现在 `item_ids` 中。

放入工具包"版面编排"。内置版式文件见 04 文档 §3.5，由本任务创建。

验收：用黄金样例（行军）数据，`layout_compose(spec="四角对齐版式", paper="A1")` 生成的版面与基线快照比较：元素种类齐全；各元素位置误差 ≤ 1 mm（基线位置按旧技能包公式计算）；字号与字号表一致。

`layout_set_label_style`、`layout_set_legend_style`、`layout_set_scalebar_style` 收到改变字号的参数，而目标元素带 `autocarto/font_locked=true` 时，拒绝并返回中文错误"该元素字号由版式锁定，如需修改请传 unlock_font=true"。这条规则替代所有提示词中的"禁止修改 font_size"。

### 6.5 版面快照带上锚点

`layout_get_items_properties` 的 `item_ids` 改为可选：不传时对版面中的全部元素生成快照，并按 `autocarto/callout_group` 把图文标注归并为 `layout_item_ids.callouts`，其余元素按 `layout_compose` 记录的语义名归入 `layout_item_ids.standard`，智能体不再需要自己整理 ID 清单。返回的每个元素增加 `anchor`（来自自定义属性）和 `font_locked`；生成的快照文件同样包含。`prepare_quality_review` 生成的审查清单增加 `legal_anchors`，质量审查工具包说明中写明"带锚点的元素位于其锚点位置是版式规定，不是问题"。

### 6.6 移动越界检查

`layout_move_item`、`layout_resize_item`、`layout_move_callout` 增加可选参数 `container_item_id`：传入时，如果移动后的完整矩形超出容器或页面，拒绝执行并返回越界的边；`layout_move_callout` 已有容器参数，保持行为。
