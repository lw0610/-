# 07 任务卡

每张卡可以单独交给一个执行智能体。交付时附上本卡、`README.md`，以及卡中"必读"列出的文档。

通用要求（每张卡都适用，不再重复）：
- 遵守 `README.md` §7 全局执行约束。
- 完成后写 `docs/refactor/evidence/<任务号>.md`：改动摘要、运行的命令与结果、跳过的测试及原因、遗留问题、与本方案不一致之处。
- 测试命令在仓库根目录执行；Go 命令在 `carto_agent/` 下执行；前端命令在 `autocarto-web/` 下执行。

## 待确认事项（开工前由用户确认）

1. **Windows 默认运行目录**：现在 Go 和 Python 都把 `F:\AutoCarto` 作为 Windows 默认目录。方案建议改为"环境变量 → 已存在的 `F:\AutoCarto` → `%LOCALAPPDATA%\AutoCarto`"。如果队友的 Windows 部署依赖 `F:\AutoCarto`，可以保持不变（T47 只做配置化）。
2. **流程解析使用的模型**：默认使用方案中编排智能体的模型。如需单独配置，在 T23 中增加设置项。
3. **流程包能否携带大数据**：默认允许单文件 ≤ 200 MB、总计 ≤ 2 GB，并建议用数据清单引用外部数据。
4. **范围外**：Windows MapGIS 端不在本次范围内。流程包只写自然语言，将来 MapGIS 端提供同名能力即可复用流程包。

## T01 黄金样例回归脚手架

- **目标**：建立"重构有没有改坏"的自动判断依据：固定输入 → 版面快照 → 与基线比较。
- **必读**：`06-工具层改造清单.md` §0、§9
- **涉及范围**：新建 `autocarto/tests/golden/**`；不修改生产代码。
- **步骤**：
  1. 找到现有无界面 QGIS 测试的初始化方式（如 `autocarto/tests/test_statistical_workflow_qgis.py`、`test_thematic_style_qgis.py`），提取为 `autocarto/tests/golden/qgis_bootstrap.py`。
  2. 准备夹具：
     - `fixtures/route_dataset/`：在 `autocarto_data/data/sessions/` 中找一个含 `intermediate/route_knowledge/compile_manifest.json` 且校验通过的数据集，**只读复制**六张 CSV 和符号文件；把其中的本机绝对路径改为相对路径。
     - `fixtures/statistical/`：从 `autocarto/skills/system/china-admin-boundaries/data/china_city.geojson` 抽取一个省的地级市面（例如 adcode 以 42 开头），存为 `regions.geojson`；编写合成的 `values.csv`（年份逐行、地区逐列），故意留一个空值和一个不匹配的地区名。
  3. 驱动脚本 `run_golden.py --scenario route|statistical --driver legacy|new --out <目录>`：
     - 环境变量：`AUTOCARTO_GOLDEN_BASEMAP_DIR`（China_map 底图目录）、`AUTOCARTO_ROUTE_RENDERER_DIR`（路线渲染插件目录），路线场景必需；缺失时以退出码 77 表示跳过。
     - `legacy` 驱动：直接调用现有 handler，按 `print-layout-marching-route` 的步骤和公式（字号表、四角锚点、装饰框外扩 5 mm、比例尺目标宽 80 mm）在代码中确定性执行；统计场景按 `print-layout-statistical` 执行。
     - `new` 驱动：先抛出 `NotImplementedError`，由 T41、T43、T44 补齐。
     - 输出 `snapshot.json`：版面元素（ID、类型、矩形 mm、字号）、主图图层列表与范围、图例条目、各图层渲染器类型与 `renderer().dump()` 的哈希、标注字段；输出 `preview.png`（72 DPI）。
  4. 对比脚本 `compare_golden.py <基线目录> <新目录>`：元素集合一致；矩形误差 ≤ 1 mm；图层列表、图例条目、字号、渲染器哈希一致（可配置忽略项）；图片只报告感知哈希距离，不作为失败条件。
  5. 用 `legacy` 驱动生成基线，提交到 `autocarto/tests/golden/baseline/{route,statistical}/`。
  6. 测试包装 `test_golden_regression_qgis.py`：没有 QGIS 或缺环境变量时跳过；有环境时，`legacy` 重跑应与基线一致；`new` 实现后比较 `new` 与基线。
  7. 写 `autocarto/tests/golden/README.md`：环境准备与运行方法。
- **不要做**：不提交 China_map 数据和渲染插件；不修改 `autocarto_data/`。
- **验收**：两个场景都有基线；有环境的机器上 `python -m pytest autocarto/tests/golden -v` 通过，无环境时显示跳过。
- **测试**：`python -m pytest autocarto/tests/golden -v`
