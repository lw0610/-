# T11 工具包 v2：元数据、归包、拆分

## 结论

已完成。现有 36 个 category 包具备 v2 元数据，正式归属覆盖当前工具集；系统基础包和隐藏包按元数据挂载。通过真实配置转换比较原 Git 基线与当前源码，默认 7 个角色原有工具全部保留。

## 范围与事实差异（实施前记录）

- 工具包挂载策略不能只在 `tool_config.go` 增字段：Build 的配置转换与 Plan 构建必须把真实目录中的包策略传入，否则系统包和 Plan 隐藏包不会实际自动挂载。因此需扩展既有配置转换、Plan 构建和相应行为测试，不改已有提示词。
- 把路线绘制从 `cartography-styling` 移到 `route-cartography` 后，默认制图角色会失去原工具。为满足本卡“当前默认方案工具只增不减”，只向内嵌默认制图角色添加新包引用；用户配置迁移留给 T13，运行数据不动。
- 合法隐藏系统包不等于 `system: true` 的系统基础包。路线知识、能力查询和创建者属于“系统”分组，仍须受隐藏包自动/显式挂载规则约束，不能为了归属断言将其自动赋给所有角色。工具归属检查将认可这些正式系统分组包；隐藏的旧 `misc-tools`、`layout-image-export` 不作为正式归属兜底。
- 系统包方法正文留给 T12。本卡仅改已有 category 包头部和工具列表，不改 workflow/knowledge 包；另外创建任务指定的三个新包。T40 的 admin-boundaries 和 T44 的 layout_compose 由各自任务实现，本卡与其协调归属和包头部。

## 改动摘要

新增 route-cartography、charts、mesh-analysis 三个包；拆出路线、8 个图表及 11 个网格工具，补齐样式和版面孤儿工具，merge_vector_layers 归入 vector-geometry。旧 misc-tools、layout-image-export 保留但隐藏。T40 新增 admin-boundaries、data_load_list 和 T44 新增 layout_compose 已纳入归属检查。

SkillFrontMatter、SkillPackage、设置列表、能力快照传递 display_name/domain/system/hidden/auto_mount。包加载器读取同一份 SKILL 元数据和 config.yaml enabled，按目录优先级覆盖，禁用覆盖会屏蔽较低优先级包。Build、Plan 与活动/全局工具目录共用自动挂载规则。公开 catalog 的 package_id 来自实际 category 的 tools 反向归属，优先正式包，避免 workflow 或隐藏旧杂项包抢占归属。

已有 category 正文相对实施前快照未改；新增三个包写了最小通用说明。默认方案只增加制图角色的 route-cartography 引用。正文整理属于 T12。

## 与方案不一致之处

表中“系统包”不是 system:true 的同义词：能力查询、路线知识及创建者保持各自授权规则。其正式 category 归属可被覆盖率认可，旧杂项隐藏包不能代替归包。本卡为使挂载和公开归属真实生效，扩展了配置转换、Plan 构建、能力投影与 control fallback 索引，并有对应测试。
