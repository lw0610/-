## 真实问题及修复

1. 正式能力目录接口返回 `data.catalog.items`，流程中心曾误读顶层 `data.items`，导致真实能力手册为空。已复用统一目录规范化并补生产返回形状的回归；最终 341 项前端测试与构建覆盖此修复。
2. 点图层范围计算曾在投影前跳过每个单点的零面积包围框，导致多个点无法聚合为正确范围。已保留有限的点范围，新增三点从 EPSG:4326 到 EPSG:3857 的真实 QGIS 回归，五项排版组合测试通过，最终完整检查已覆盖。单个点或全部共线而无法形成二维范围时仍需显式范围，不凭空添加比例常数。A2 首次成功出图使用现有显式范围接口，后续通用修复没有被冒充为其“零代码”前提。
3. 测试运行目录、系统 keyring 和 Qt 模块污染等隔离问题在 T52 收敛。测试显式禁用系统 keyring，实际工作配置和原系统密钥未被读取或删除；[清理与历史失败说明](T52.md)。
4. 新流程发送入口最初没有携带正式 task 协议所需的 `request_id` 和 `idempotency_key`，后端在进入流程前拒绝任务。已复用实际请求标识机制并补发送契约回归，真实 Chrome 在修复后完整通过；没有修改后端要求或放宽验收。最终全量门禁已覆盖此修复。
5. 第三轮普通 Python 矩阵中，脚本执行器先发布成功状态再写入结果，读取方可看到 `succeeded/result=None`。这是真实并发窗口，前轮通过不能否定它；[第三轮失败日志](../../../autocarto/tests/golden/.runs/T53-check/attempt-03.log) 已保留。终态、结果/错误和完成时间现于同一锁内发布，读取快照也持锁；新增屏障回归在旧代码稳定复现成功/失败/超时三种缺字段，修后全部通过，原断言及超时未放宽。[执行器证据](T53-executor.md)。独立普通矩阵还发现并修正了一个 `/var` 与 `/private/var` 的预期路径比较，保留精确物理目录语义。
6. 实际 API 的可选字段 `default:null` 曾被初始化为文本 `false`，可能错误进入任务输入。现仅布尔字段回退为 false，其他空值保持空并在提交时省略。正式浏览器断言了内置输入框为空、任务实际输入中没有这两个未填写字段。
7. 会话集合变化使连接 effect 的 callback 依赖变化，流程结束时会清理并重建 WebSocket。现通过 ref 使用最新订阅目标，独立更新 attach/detach，保持连接生命周期稳定。两项新回归旧实现均失败，修后相关 47 项通过；最终真实浏览器任务期间 socket 关闭次数为 0，终态无断连提示。[连接生命周期证据](T53-provider.md)。

上述全部修复均被最终第四轮完整检查覆盖。历史第二轮通过、第三轮失败与最终通过日志分别保留，没有用早期通过覆盖后续生产变更。
