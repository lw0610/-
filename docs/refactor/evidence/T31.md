前后端契约：
- task.data.flow={id,inputs}；自动模式仍用原普通任务入口。
- flow_event.data 为 flowrun.Event（event/session_id/flow_run_id/payload），统一运行事件镜像/回放照常保留。
- session_state.data.flow_run 和 REST SessionRecord.flow_run 为 RunState；快照附 flow_run_event_seq=run.event_seq，防旧回放覆盖新进度。
- 步骤过程与历史消息 data.flow_run_id/step_id；不把步骤回执作为最终响应。
- flow_preview 返回 {flow_id,name,plan,diagnostics,input_check:{missing:string[],valid:boolean}}。

必要范围扩展：
- agentruntime.Factory提供可选角色工厂/只读校验工具/无工具JSON模型接口，避免websocket复制其模型、工具、中间件装配逻辑。
- T32图层输入需要当前工程图层下拉；现有HTTP没有图层列表，新增只读 GET /api/instances/{id}/layers，复用既有实例授权与工具桥接；返回 data={items:[{id,name}],instance_id}。

所有验证用隔离运行目录，真实开发数据迁移与启动留到T51。


已落地：
- DeepServer接入API同一FlowCompiler，StepRunner复用真实runAgentPhase/consumeEvents；编排工具登记待执行流程，编排本轮结束后再启动Controller。
- 每步角色工厂、干净输入、原文独立上下文、步骤过程/持久历史flow_run_id与step_id；最后助手回复用于回执，不误用最后工具结果。流程步骤不发整个任务的最终响应。
- 原生人工确认、知识核对及失败三选项保留checkpoint；恢复后的步骤结果只回调一次。拒绝确认和取消都会释放Controller运行槽。
- 流程快照由不可变发布副本读取，长步骤不会阻塞attach。REST/WS返回同一RunState和实际统一事件水位；统一seq另用项目运行目录内的原子文件持久化，进程重启不会复用旧序号。

- 对审查实际复现的问题补回归：图层校验仅接受实际图层记录，拒绝嵌套字段/样式名；专用知识执行器将人工重试补充说明合入本次rules和已有兼容哈希。
