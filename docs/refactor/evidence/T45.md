# T45 按 QGIS 模板排版

## 结论

实现完成。任务卡指定的模板测试 12 项通过；最终加上工具包迁移、定义校验共 19 项、352 个子断言通过，无跳过。真实 QGIS 3.44.10 中验证了 QPT 占位符替换、主图图层与跨 CRS 范围、图例筛选、完整元素回执以及失败时保留旧版面。所有修改仅在 `enio2`，没有安装、部署或修改用户工程和源数据。

## 改动摘要

- 扩展 `autocarto/tools/system/_shared/print_layout_impl.py` 的 `import_layout_template_handler`，保留 `template`、`name` 及原返回字段，增加 `texts`、`map_item_id`、`map_layers`、`extent_layers`、`extent`、`padding`、`legend_layers`。
- `texts` 对文字项中的 `{{名称}}` 做一次字面替换；支持中文名称、空白、换行和空字符串，拒绝非文字替换值。保留模板字体、文字框与位置，HTML 文字的替换值转义后显示。保留的占位符按文字项写入中文 `warnings`，同时返回去重排序的 `unreplaced_placeholders`。
- 主图默认 ID 为 `main_map`。请求主图设置时复用 T44 内部的图层定位及范围转换函数，图层可按唯一名称或 ID 指定，保留模板地图框和地图 CRS，范围留白默认 0.03。显式范围与范围图层互斥。
- `legend_layers` 设置模板中各图例的原生模型，不自行增加图例；模板没有图例时返回明确警告。未提供的图例参数保留模板原状。
- 返回所有 `QgsLayoutItem`（包含页面）的唯一 ID 和 `rects_mm`；空 ID 或重复 ID 生成新 ID，避免漏项或覆盖矩形。矩形取包含旋转、分组变换的场景外接矩形，并从布局原生单位转换成毫米。
- 候选布局完成加载、设置和快照后才注册并替换同名布局；设置失败不会清空旧布局。注册失败恢复旧布局名称。
- 工具 YAML 从 `cartography/` 移至 `print-layout/`，更新 `metadata.domain`、中文名称“按 QGIS 模板排版”及参数映射。`handlers/layout.py` 与 `handlers/__init__.py` 均导出该 handler；旧 cartography Python wrapper 继续作为兼容转发，但旧目录没有重复工具定义。
- T11 已将该工具挂到 `print-layout/SKILL.md`，T12 负责正文；本卡未覆盖并行修改的技能文件。

真实 QPT 验证覆盖：

1. 含 `{{标题}}`、`{{综述}}`、未提供的 `{{数据来源}}`、`main_map` 和原生图例的模板。检查替换文字、特殊字符/HTML 转义、未替换警告、图层顺序、图例白名单、范围转换和 0.05 留白；地图框仍为 `(20,30,120,60)` mm，标题框仍为 `(20,10,120,12)` mm，标题保留 6.25 mm 加粗格式。
2. 自定义 `map_item_id=custom_map`，提供 EPSG:4326 显式范围，实际地图仍为 EPSG:3857，转换后范围包含输入并保持中心及框尺寸。
3. 厘米原生布局、空/重复 ID、相对 SVG 图片资源。切换 CWD 后按项目相对路径导入同一 QPT，图片仍以 QPT 所在目录解析；9 个真实元素均有唯一 ID 和毫米矩形，页面数量为 1。
4. 只有文字、没有主图的旧模板仍可仅用 `template/name` 导入；成功替换后旧元素移除，没有未替换占位符时 `warnings=[]`。请求不存在的图例会有明确提示。
5. 丢失地图项、丢失图层、范围参数冲突、无效 CRS、无效替换文字、破损 XML 和错误根元素均失败；原布局对象及标题内容保留。

主场景还通过 `ToolDefinitionLoader` 和 `ProcessingToolExecutor` 的 `handler_file/handler_function` manifest 契约实际调用迁移后的 wrapper，验证新路径可执行。该 Python 用例按 YAML 构造与 authority 相同的绑定契约，没有宣称启动了完整 Go 服务端链路。已查看真实导出的预览 PNG，普通标题、综述、保留占位符及 HTML 文字均可见。

## 实测修正

- 旧实现先 `initializeDefaults()` 再加载 QPT。真实 QGIS 3.44.10 中，一页模板会额外保留默认页。移除候选布局的默认页初始化，直接从模板读取页面；真实用例严格断言只有一页。
- 真实运行时会把 `htmlState=1` 标签迁成 `QgsLayoutFrame`，当前构建不提供 `QgsLayoutHtml`，导致原文字和 ID 丢失。加载前给这些标签临时 ID 并按普通标签读取，加载后恢复原 ID 和 HTML 显示模式；无需安装组件，实际 HTML 文字替换与渲染通过。
- 首次相对路径单测把 macOS `/var` 与实际解析的 `/private/var` 作字符串比较；已以规范化后的真实路径比较。未修改路径解析规则来迎合测试。

## 与方案不一致之处

- 按用户较新的要求，QPT 路径接受项目相对路径，解析不依赖 CWD；QPT 内部的相对图片资源仍以模板目录为基准。
- 为兼容已有调用，未传任何主图设置参数时保留模板图层和范围，不强制要求文字模板包含 `main_map`。一旦请求主图设置，地图项缺失就明确失败。
- 同名替换改为注册完整候选布局后移除旧对象，保留公开工具返回契约，但不再保证旧 Python 布局对象身份。调用者应按布局名称重新获取对象。
- 04 文档 §3.5 的消费方名称写作 `layout_apply_template`，与 06 §5.2、T45 卡明确要求的“工具名不变”不一致；实现以 T45 和 06 为准，继续使用 `import_layout_template`，没有新增别名。

## 跳过与边界

- 本卡测试无跳过；未执行安装、部署或桌面发行构建，也未重跑不受本卡影响的黄金场景。
- 接受当前 QGIS `Layout` 根元素的 UTF-8 `.qpt`，文件上限 10 MiB；未实现旧式 `Composer` 根元素迁移。
- 占位符处理目标是普通及 HTML 模式的文字标签，不会改写图层表达式、图片路径、表格内容或远程 HTML 文档。模板内这些功能仍由 QGIS 自身处理。
- 不自动扩张文字框或重新排版长文本；调用方需检查完整回执和模板的容纳能力。模板保真的位置及字号优先于自动调整内容。
