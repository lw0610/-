# T12 方法说明并入工具包、参考资料读取

## 范围与实施前判断

- 按 05 §1 的“并入”项整理通用方法；原目录只标 deprecated，不删除。不改转换为流程/资源的旧包正文。
- 正文长度须从真实文件加载时计算，不能只在手工配置里填长度；沿用同一目录优先级与 enabled 覆盖结果。字符按 Unicode 计数，排除 Markdown 标题和空白。
- deprecated 字段需要传到包模型，并从设置/API 列表中过滤，才能兑现“前端不再列出”；详情仍可直读，旧配置迁移仍可识别。
- reference_read 白名单使用现有项目路径解析器得到的资产/运行根，不依赖 cwd，不创建目录。工具包目录开放允许扩展名（相对路径例子使用 references）；流程开放 resources/docs 文档和 resources 中 CSV/JSON/YAML 对照表；资源库开放规范指定文本扩展名。拒绝符号链接、越界和非文本文件，读取上限 200 KiB。
- gee-scripting 的 LICENSE、UPSTREAM、references、templates 复制到目标包并逐文件核对内容；旧副本留到 T52。Python 模板的读取继续用已分配脚本工具，reference_read 按规范不开放 .py。

## 实施与验证

已完成。41 个“并入”来源目录均保留，只增加 deprecated:true；22 个目标 category 正文整理为通用方法；29 个方法参考文件逐一按迁移表落位。GEE 另增加执行质量说明参考，并复制原 7 个许可/来源/参考/模板文件，逐字节核对通过。所有 category 正文均不超过 8 KiB。

正文整理保留统计数据“先验证再生成、空值不是零、不猜名称”与真实产物字段；分级渲染保留实际方法、色带、范围核验；坐标系改为按实际分析/量算需要转换。PyQGIS 的 13 个旧方法各自形成参数化参考，保留 API、方法选择、执行检查和错误边界，移除示例中固定输入图层、路径、专题参数与错误推断（例如正则化样条不称为 Kriging，训练点回代不称独立交叉验证）。quality-feedback 保留通用审查原则、八个维度与初审/终审 JSON 契约，专题合法结构/保护内容不留在工具包；版式锚点、锁字号和自动 DPI 以工具契约为准。

`RuntimeSkillPackageMetadata.BodyCharacters` 从文件正文按 Unicode 字符计算，排除标题和空白。角色拥有的 category 满 200 字符才加入中间件；系统基础包和隐藏包沿用 T11 的实际绑定。新增真实 Eino middleware 测试读取 vector-geometry 正文，另以真实工具 YAML→SkillEngine→internal backend→reference_read 读取 `references/缓冲与邻近分析.md`。

`deprecated` 写入 SkillFrontMatter 与设置摘要，普通/governed/按 scope 三种列表过滤弃用方法，详情仍可直接读取以便迁移。未删除旧目录，未禁用旧配置中的方法读取，最终引用迁移由 T13 处理。

## reference_read 的真实边界

- internal 运行时，运行控制系统基础包挂载；实际 YAML 参数映射经过工具引擎调用测试。
- 工具包内允许规范指定文本扩展名，既可读取 references，也可读取 SKILL.md/config.yaml。相对路径遵从实际 runtime 的低到高包目录优先级；先选有效的整个包，缺参考不回退读取旧副本。
- 在 `buildRuntimeTools` 创建工具实例时，把该次 registry 使用的目录列表注入 invoker context。目录随已构造 runtime 保持，切换当前方案不会使旧工具读到新方案的同名参考。为此范围扩展到 `cmd/agent/main_deep.go` 的构造边界；没有给模型增加任意根目录参数。
- 允许内置/用户流程 resources/docs 的文本以及 resources 下 CSV/JSON/YAML 表格格式，允许内置/用户资源库的指定文本。拒绝配置凭据目录、其他项目文件、上级越界、前缀相似目录、文件/目录及中间组件符号链接、非普通文件、二进制、非 UTF-8、.py/.pdf 等不支持扩展名。
- 最多读取 200 KiB+1 字节判断截断，UTF-8 字符边界返回 text/truncated/warning，不拒绝仅因超限的文本，不创建目录。
