# T46 图例条目、综述、审查导出、字号锁定与锚点

## 结论

六项实现完成。新增真实 QGIS 八个场景全部通过；相关综述和质量链路合计 25 项通过，独立旧版图文标注移动、渲染、统计版面及 10 项黄金回归通过。任务卡较广的单进程测试命令没有全绿：如实保留其模拟模块污染、独立构建失败和跳过记录，不把这些结果计为通过。所有修改仅在 `enio2`，无安装、部署或用户数据改写。

## 六项改动

1. **额外图例条目**：`layout_set_legend_style` 支持 `legend_extra_items=[{label,image_path,size_mm}]`。支持 SVG、PNG、JPEG，项目相对路径统一解析；参数完整验证后才改图例，辅助点图层不加入图层树，写入 `autocarto/legend_extra_item` 并按完整条目复用。省略时保留通用额外条目，显式空数组清空图例中的额外条目。读取兼容旧 `autocarto/military_arrow_legend` 属性。`include_military_arrow=true` 映射内置“路线箭头”图片资源和通用名称，不再在通用实现中保留原专题名称。
2. **综述只消费输入**：删除旧文件综述模块中的模型配置获取、HTTP 调用、自动摘要、区域和专题关键词推断等路径。隐藏的旧入口仅放置调用者提供的 `summary/overview_text`，不读取输入文件，不归纳或截断正文；未提供正文明确失败。新调用使用 `layout_compose` 或 `layout_add_label`。
3. **审查导出分辨率**：`layout_export_image` 增加 `purpose=final|review`，默认 final。review 未提供 DPI 时 A0=100、A1=140、其他=200，横竖方向均可；每页均检查 1600 万像素预算，超出时下调实际 DPI，返回 `data.dpi/purpose`。显式 review DPI 同样遵守预算；final 默认使用布局原始 DPI。拒绝零、负数、非有限值及布尔 DPI。
4. **字号锁定**：三个文字样式工具在任何修改前检查 `autocarto/font_locked`。显式字号请求须 `unlock_font=true`，否则原样返回指定中文错误。仅改颜色、字体家族、加粗等属性时复制现有格式，保留字号、单位及其他属性；图例每种文字角色分别保留自身字号，避免通过共享格式间接改字号。解锁只授权本次调用，元素后续仍保留锁标记。
5. **自动快照与合法锚点**：`layout_get_items_properties` 的 `item_ids` 可选，省略时读取全部内容项及主图网格子对象；页面尺寸单独记录。自动生成 `layout_item_ids.standard/callouts` 并保存不可变快照，状态增加 `anchor/font_locked`，毫米矩形包含旋转和分组变换。`prepare_quality_review` 从已校验快照提取 `review_context.legal_anchors` 并保存到审查清单。
6. **移动边界**：移动和缩放普通元素可传容器 ID 或 `page`，按 QGIS 实际完整矩形同时检查容器和页面；失败恢复原位置/尺寸，并返回 `overflow_edges/violations`。图文标注延续必需容器、整组移动和固定地图锚点规则，增加子元素及计划牵引线边界检查；原标注框越界也返回越界边。

T44 compose 的网格是主图子对象，不是普通 `itemById` 项；本卡快照实际遍历 `main.grids()`，使用真实网格 UUID 及主图矩形。与 T43 约定 `autocarto/callout_group=<稳定ID>`、`autocarto/callout_role=box/image/title/body/leader`，多条 leader 汇为数组；未知旧元素仅按组放入 `items`，不猜编号或角色。T43 已通知该元数据写入，但其工具行为通过与否以 T43 证据为准。

## 必要接口补齐与内容协调

- 原 `layout_get_item_corners`、`layout_set_map_scale` 的 YAML 已存在，但共享实现没有对应函数，wrapper 也未导出。本卡补齐实际毫米外接矩形/四角读取、有限正数比例尺设置和主线程包装，并在 `print-layout/handlers/layout_items.py`、包导出中注册。

- 技能说明由 T12 同步，本卡没有覆盖 `SKILL.md`。旧测试对已删除专题技能和固定 DPI/禁改字号提示词的整段字符串断言，替换为当前资源/工具执行契约及真实 QGIS 行为断言；原图保护、终稿绑定、CLI、图像有效性等质量测试保留。
- 按 06 §6.1，生产兼容参数的新默认名称为“路线箭头”。旧黄金基线包含原专题名称，黄金 legacy 驱动改为显式传额外图例条目和旧场景名称，保留原始基线；new 驱动本来已显式传入。该场景名称只在测试夹具/驱动中出现，不重新写回通用实现。

## 广测失败与跳过的真实边界

- `test_plugin_ui_migration.py` 在收集阶段无条件把 `qgis`、`qgis.core` 等写成 `MagicMock`。即使这些 UI 测试被 `-k` 排除，真实 QGIS 测试仍受污染：标注移动调用真实 SIP 对象时收到 `MagicMock` 枚举，标注渲染和编译亦出现跨测试行为。它们分别在独立进程通过，支持这是测试隔离问题；没有修改无关 UI 夹具来掩盖广测失败。
- 独立构建失败仍存在：`build.sh` 第 307 行报 `guidance` 后跟非 UTF-8 字节的 `unbound variable`，随后测试的 `subprocess` UTF-8 解码抛异常。本卡不修改构建脚本，交 T53 统一处理。
- 广测 14 个跳过包含 3 个无发行产物检查，以及受已有/模拟 QGIS 应用状态保护的旧集成类；这些跳过不作为真实行为通过的依据。新增八场景全部在独立真实 QGIS 进程执行，未跳过。
- 场景守卫精确清单要求所有并行变更同步。本卡只删除 `print_layout_advanced_impl.py:军标` 一条自身债务，两个相关通用模块已不含该场景词。T43 随后已同步删除其路线模块旧债务；其新默认插件名的归属修正由 T43 负责。
