# T43 路线专题工具拆分与视觉预设外置

## 结论

完成。新增 `route_draw`、`route_points_build`、`layout_add_callouts`，三个真实工具入口均经对应 YAML 绑定和 authority execution manifest 实际调用。旧组合入口保留，内部改为调用独立工具并适配旧参数、资源中的旧名称和原回包形状。补齐了旧 `cartography_symbolize_points_by_mapping` handler 的缺失导出。

最终新增专项 **16 passed**（6 项纯资源/编译回归、10 项真实 QGIS）；完整黄金与场景词守卫 **16 passed**（黄金 10、守卫 6）。同一份原黄金会话完整知识图谱，以冻结的旧 compiler/词表和新 compiler 各编译一次，六表 **81/16/100/81/5/2** 行全部逐字节一致，未使用路径豁免。原始图谱与原 T01 基线未修改。

## 接口与实现

| 工具 | 实际输入与行为 | 实际输出 |
|---|---|---|
| `route_draw` | 接受当前任务或显式六表、行数/任务断言、可选路线样式表、渲染器目录和标注图层名称；只绘制路线及其名称 | `data.routes.items/count/failed_count`、`data.route_labels`、实际 `data.layers[{name,id}]`、`data.dataset` |
| `route_points_build` | 从 points.csv 建层或复用，按数据集符号表或可选符号资源符号化；默认 waypoint 普通小圆点，保留地名和非空 meeting_label 标注 | 原阶段 `data.points_layer`、`data.symbols`、`data.meeting_labels`，另有实际图层 ID 与数据集信息 |
| `layout_add_callouts` | 读取数据集或独立 callouts CSV，解析图片基准目录，按实际版面元素进行避让 | `data.items[{id,success,created_item_ids}]`、创建/失败数量、警告与数据集信息；leader 可为多个实际 ID |

- 新 YAML 位于 `route-cartography/` 和 `print-layout/`，中文名称、关键词、参数说明及工具归属通过 T10/T11 检查。路线两个新工具加入“路线专题绘制”，图文标注加入“版面编排”；旧组合挂载保留至 T52。
- 路线名称和汇合点规则的中性默认值分别为“路线名称”“汇合点标注”。黄金 `new` 驱动显式传原基线名称，并传空 `default_symbol_types` 使用原数据集全部 SVG；没有添加比较豁免。新工具普通点默认值独立测试可见的普通点规则，避免把默认类型误隐藏。
- 每个实际标注元素写入 `autocarto/callout_group=<CSV编号>`，以及相同值的 `autocarto/callout_part`、`autocarto/callout_role=box/image/body/leader`。后一个键与 T46 联动；实际快照已归并两组标注。既有入口不渲染标题，故不会产生不存在的 title 元素；双引线的每条线都有同组和 leader 角色。
- `dataset_handoff.resolve_route_dataset` 为新名称，原 `resolve_marching_route_dataset` 保留同一函数别名；显式相对路径统一按项目根解析。数据集信任边界、断言与六表校验继续复用原实现。
- `renderer_plugin_dir` 可显式指定；旧 `plugin_dir` 仍接受。省略时按 `plugin_config.yaml:route_renderer.plugin_name` 在当前 QGIS profile 的插件目录查找。`ConfigProxy` 的默认值读资源，不写本机路径或把插件名称写死在工具实现中。

## 视觉资源与编译器

- 新增 `styles/路线样式-红蓝对比.csv`、`路线样式-单色.csv`。标准中文/英文列覆盖拓扑、阵营、路线类型、绘制方式、样式编号、线宽系数、图例说明；兼容扩展列保存预设键、默认阵营、参考样式映射、路径标注和自动线宽组选择。数据集中的非空 style_id 优先；缺失样式/绘制方式时由资源补充，不修改输入表。
- `styles/route-defaults.json` 保存三类标签字体、毫米字号、缓冲、普通点和图文标注默认视觉配置，以及旧工具所需名称与规则说明。具体专题名称、颜色及字体从运行时工具移入资源；三个旧工具模块和符号映射模块的 **5 条**场景词债务已删除，没有新增场景词债务。
- 原 `knowledge/assets/symbols/` 的 **8 个 SVG 原样移动**到 `resources/system/symbols/军标/`，逐个与 Git 中原字节比较全部一致。对照表保存 5 个预设的尺寸、优先级、锚点和事件到符号的映射。`symbols/图例/` 增加原箭头图片与对照表；随后 T23 真实解析发现公共 symbols 只接受 SVG/PNG，已另存像素相同的 PNG 并将对照表指向 PNG。旧 JPG 和旧图片位置保留给 T46 的旧参数兼容调用。
- 新增无 QGIS 依赖的 `knowledge/visual_presets.py`。`vocabulary.py` 保留语义词表，视觉常量从资源加载。资源解析检查重复键、相对资产路径、Windows 绝对/穿越路径和非有限数值。
- `compile_task_knowledge` 和 `marching_route_compile_dataset` 新增 `route_style_table`、`symbol_table`；每次编译使用本次资源参数，不修改全局预设。资产复制读取新资源目录。新增自定义 style_ref 时，编译校验的该枚举随本次资源声明变化，其他语义校验保持原规则；validate_only 和实际编译调用同一份资源，且 validate_only 不创建输出目录。真实 manifest 用例覆盖了这条链。
- `_shared/route_runtime_support.py` 统一数据集错误回包、渲染器目录解析和资源文本格式。旧通用箭头绘制机制与几何构建保留，没有修改外部渲染插件。

## 旧入口兼容边界

`cartography_build_and_draw_from_tables` 不再包含独立的路线、符号和注记实现：依次调用新工具，转递旧 plugin_dir、points_layer、运行开关和覆盖参数，从资源传入旧标签名称，并组装原 `dataset/points_layer/routes/symbols/callouts` 回包及标签诊断。实际测试检查原顶层键、callouts 键和 debug 键集合。传 layout_name 时才执行图文标注，遵循本卡新兼容约定；不再因省略该参数而自行选择首个版面。

已在 `removal_ledger.yaml` 登记 `python_route_combined_handler_compat`，删除阶段为 T52；当前仍保留旧工具供既有数据回放。低层 `cartography_add_callouts_handler` 继续接受原对象数组，新 CSV 工具复用它的绘制机制。
