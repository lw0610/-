## 与方案不一致之处

- QGIS 自带 Python 没有 pytest，使用任务目录内独立依赖目录。普通 `python` 命令需替换为可导入 QGIS 的解释器，运行方式已文档化。
- 旧统计流程提供的是布局指导，并没有完全确定的单一版式。本卡确定性选用 A4 横向、五级分位数及右侧真实图例，不将路线四角强制对齐规则套入统计场景。
- 为使路线图片注记可移植，除六表与符号外复制了这两条注记引用的小型图片资产。没有复制底图、插件、用户原文或整个会话。
