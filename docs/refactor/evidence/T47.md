# T47 项目内运行目录与相对路径

## 结论

本卡完成。Go 配置全包、Python 路径测试、Rust 桌面单测均通过。

## 用户确认的规则

用户明确当前使用 macOS，并要求默认放在项目内部、使用相对路径。该要求取代任务卡的 Windows 三段式默认目录提案；各平台采用同一规则，不再默认写到固定盘符。

- 默认运行目录：`<项目根>/autocarto_data`。
- `AUTOCARTO_HOME` 可覆盖；相对值固定按项目根展开，绝对值与 `~` 仍可用。
- 项目根可用绝对 `AUTOCARTO_PROJECT_ROOT` 指定；开发环境从资产目录、可执行位置或源码位置发现。定位不依赖调用者随意变更的工作目录。
- 项目内资源绑定保存相对路径，外部数据和外部应用保留绝对路径。T22 调用统一 helper 实现绑定写入；外部插件查找及数据资源迁移分别由 T43/T50 验收。
- 解析函数不创建目录、不迁移数据。

## 范围及必要扩展

任务卡列出的 Go/Python 路径函数和测试已修改。由于桌面端原来会主动注入应用数据目录、Windows 构建脚本会覆盖为固定盘符，仅改 Go/Python 无法实现用户要求，因此同时调整 `autocarto-web/src-tauri/src/lib.rs` 和 `build.bat` 的运行入口。没有启动真实应用、修改原项目或写入复制的运行数据。

Go 提供 `ResolveProjectRoot`、`ResolveProjectPath`、`PreferProjectRelativePath` 供其他模块复用。Python 提供同等辅助函数。桌面端把固定项目根传给子进程，便于后端和 QGIS 共用。

## 验证

- Python `python3 -m unittest autocarto.tests.test_paths -v`：4 项通过，覆盖默认目录、显式覆盖、不同工作目录、中文相对路径往返、外部路径及非法输入。
- Go 路径与会话测试通过；`AUTOCARTO_ASSETS_ROOT= TMPDIR=/private/tmp go test ./internal/config -count=1` 全包通过。使用真实路径的临时目录避免已有 macOS 路径别名断言影响结果。
- Rust `AUTOCARTO_ASSETS_ROOT= cargo test --lib --offline`：11 项全部通过，包括桌面入口默认路径、工作目录变化和现有 sidecar 生命周期。第一次构建遇到 T22 公共诊断类型提取的短暂编译冲突；代理修复后完整重跑通过。
- Windows 实机暂不可用；默认/绝对覆盖/相对覆盖的跨平台 Go 测试不依赖具体盘符，Windows 构建入口仅静态核对。

执行环境原本继承了指向旧项目的 `AUTOCARTO_ASSETS_ROOT`。测试显式清理/设置环境，避免把旧目录内容误判为新实现结果。原有 macOS `/var` 与 `/private/var` 断言差异在本卡路径测试内按同一实际路径校正；未在生产代码中硬编码平台别名。
