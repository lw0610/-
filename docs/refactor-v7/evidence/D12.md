# D12 内置图层页面与设置入口

## 结论
前端实现完成；浏览器交互验证通过。真实 QGIS 的扫描、投影识别和加载验证见 D11，不能由本页面夹具测试替代。

## 改动摘要
- 新增 `LayerLibrary`、`LayerImportDialog`：按图层包与类别分组，搜索名称/别名/类别，缩略图与完整预览，范围示意，坐标系、比例尺、来源/许可详情。
- 用户层支持编辑元信息与删除登记；系统图层只读。删除前说明只删除登记、保留原件。
- 扫描文件夹后逐行确认名称、类别、注记字段、坐标系与比例尺，可跳过文件；不自动把建议坐标系覆盖为真实坐标系。
- 设置页移除本机文件夹登记和已无调用的 `DataSourceEditor`，提供到内置图层页的链接。
- 补齐 D13 前端：编辑流程时可进入图层库，选择图层并插入 `内置图层「名称」`；保存仍使用既有引用检查。
- 未新增兼容层。未恢复体检、重新编译或工具包导入。
