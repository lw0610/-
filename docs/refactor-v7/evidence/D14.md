# D14 参数符号化与真实 QGIS 核验

2026-10-29，QGIS 3.44.10（macOS，独立临时 profile）。本卡没有启动模型任务，也没有修改用户工程、会话或输入数据。

## 已实现

- 新 `layer_set_symbology(items, scale)`：面/线/点，多层自下而上叠加；填充及透明度、描边、虚线数组、正负偏移、端点、空心点；标注字段、字体、字号、颜色、白色描边、水平/沿线/点周围放置、合并、重复间隔、全部显示、粗体与要素避让障碍开关。
- `labels` 省略保持，`null` 关闭；`symbol` 省略保持。字段 `auto` 优先 `layer_load_builtin` 保存在工程图层上的清单 `label_field`，再按 NAME/name/name:zh/名称选择。明确字段缺失关闭标注并保留警告与期望/实际差异，不伪造“已标注”。
- 尺寸先从 pt 换算成毫米，再整体缩放；字号至少 1.8 mm、线宽/描边至少 0.1 mm。偏移、点大小、虚线、文字描边也缩放。
- 字体按可用的微软雅黑、苹方、思源黑体、Noto Sans CJK 顺序选择。本机选择 PingFang SC；用真实 QRawFont 验证“河南省黄河”的字形。`.AppleSystemUIFont` 和未安装字体返回明确回退说明。
- `layer_load_style`、`layer_load_styles` 同样处理字体回退，并新增可选 `scale`。加载后直接修改现有符号层的物理尺寸，保留铁路自定义虚线结构；当前 11 份公开 QML 的基本符号层受支持。非单一符号渲染器或其他复杂符号层需要缩放时明确告知保留原尺寸，不重建用户复杂渲染器。
- `layer_load_builtin` 给实际工程图层保留 `label_field/default_style` 属性；默认 QML 加载与预览同样使用中文字体回退。

## 返回契约与证据

`layer_set_symbology`：`data.items[*]` 包含 `layer_id/layer_name/request/requested/actual/warnings/differences`；`data.scale` 为整体比例。`request` 是原请求，`requested` 是经过单位、缩放和 auto 解析的期望，`actual` 通过 QGIS renderer/symbol layer/label settings 的 getter 独立读取，不复制请求。

`requested/actual.symbol` 包含 type 与 layers；尺寸以 `_mm` 为后缀，颜色是小写 `#rrggbb`，透明度为 0–1。`labels` 包含 enabled、field、size_mm、color、font、placement、merge_lines、repeat_mm、display_all、bold、obstacle、buffer。差异记录 path/expected/actual。

单 QML 加载返回同形 `data.requested/actual`；批量加载保留原 `data.items[*].data` 包装。Go 执行器负责以保留的原工具调用参数再次核验，并把不一致交回同一智能体。

- `D14-readback.json`：7 层 × A1/A4 的真实调用参数、返回、旧 QML 读取状态。
- `D14-symbols-A1-A4.png`：相同几何、相同范围、相同 DPI 的已存 QML / 参数 A1 / 参数 A4 三列图，已目视检查。
- 重现：使用 QGIS Python，项目根加入 PYTHONPATH，执行 `scripts/qgis/verify_symbology.py --output <新临时目录>`。

## 文档与原 QML 的实际差异

1. 7 层符号的颜色、线宽、虚线、偏移、空心驻地双圆与原 QML 一致。
2. 原省域面还有白色 0.7 mm 标注描边。按“保持 A1 图面”的目标，参数夹具显式提供该值，流程由 D40 同步写明，并非工具隐藏继承。
3. 原河流面 QML 事实上开启了 NAME 标注；方案要求不标注，新参数确实关闭。这是预期纠正，不能宣称完全像素一致。
4. 原 QML 使用 `.AppleSystemUIFont`，字体回退会改变部分字形。新字号、颜色、字段、放置方式与合并属性逐项核对；未声称 Windows/Linux 实机已经验收。
5. A4 河名字号 10 pt × 0.35 低于 1.8 mm，因此读回 1.8 mm；省名为 5.2 × 0.35 = 1.82 mm；铁路 0.4 mm 变为 0.14 mm，虚线 [4,4] 变为 [1.4,1.4]。

## 像素量化追加：未把诊断指标当成正式阈值

既有 `golden/compare_golden.py` 明确规定图像/dHash 只作诊断；`tolerance_mm=1.0` 是版面矩形位置容差，不能换用为像素阈值。v6 L51 同样没有规定像素验收阈值。本轮不依据实测结果临时选择一个能通过的数值，正式整图像素验收状态保留 **未判定通过**。

量化脚本为 `scripts/qgis/measure_symbology_pixels.py`，报告为 `D14-pixel-metrics.json`。整图不缩放、不配准、不遮罩，在原始分辨率上比较白底合成后的全部 RGB 通道；报告精确变化像素比例、MAE、RMSE、最大通道差及非白区域比例。另用同一几何、范围、96 DPI、800×600 尺寸做逐层控制对照，不修改生产样式或金样。

该检查真实发现原读回合同遗漏了省域的粗体（旧 Qt fontWeight=75，新默认50）和要素障碍开关（旧false，新默认true）。统一字体家族后仍有749/480000个标签像素不同。随后明确增加 `labels.bold` 和 `labels.obstacle`；仅省域传 true/false，其他仍标注的河流线、驻地保持普通体与 obstacle=true，河流面按方案关闭标注。旧观测保存在 `D14-pixel-metrics-before-label-fix.json`，没有覆写原始证据。

修复后的控制对照：7 层关闭标签时全部为 **0 差异像素、MAE=0、RMSE=0**；统一 CJK 字体和标注开关之后，7 层均 **0 差异像素**。每层重复渲染同样零差异。这是参数表达与已存 QML 的受控一致性证据，不能替代完整 A1 原图像素验收：完整地图还有明确修改的图层上下顺序、字体，以及具体标签避让交互。

### 最终完整 A1 图数值

最终候选来自 `/tmp/autocarto-v7-d14-acceptance-labels-final-20261029/{route-no-review,route-with-review}/preview.png`。参考是 v6 实际验收产物 `/tmp/enio2-v6-acceptance-routes-20261028/`；同时直接比较仓库未修改的 `golden/baseline/route/preview.png`。三个来源均为 2383×1683、72 DPI，源数据夹具摘要一致。报告保留每个实际 PNG 的 SHA-256 与比较路径。

两种路线场景的像素结果相同：

| 比较 | 变化像素/总像素 | 变化比例 | RGB MAE（0–255） | RGB RMSE（0–255） |
|---|---:|---:|---:|---:|
| v6 实际验收 → 最终 v7 A1 | 144,032 / 4,010,589 | 3.5913% | 1.63949 | 12.01311 |
| 仓库原金样 → 最终 v7 A1 | 148,264 / 4,010,589 | 3.6968% | 1.71037 | 12.30307 |
| 仓库原金样 → v6 实际验收 | 7,252 / 4,010,589 | 0.1808% | 0.13818 | 4.21052 |

v6 实际验收到最终 v7 的 dHash64 距离为 2。其非白像素并集为 546,202 个，变化像素占该并集 26.3697%，因此不能只引用整幅大面积白底稀释后的 3.59% 来声称肉眼无差别。最大通道差是 255。

修复粗体/障碍属性前，同一 v6 实际参考到当时 v7 A1 的变化比例为 3.7971%（152,286 像素），MAE=1.87440、RMSE=13.28923。这组前后数据只是诊断，不构成事后选阈值的依据。原金样与 v6 实际产物本身已有差异，也不能未经复验就把该数值当成随机噪声容差。

**结论：参数和原 QML 在明确统一字体/标注策略后的 7 层受控渲染逐像素一致；最终整图与原图并不相同。整图像素验收没有预设判定阈值，故本项仍记“未判定通过”，不写“阈值内通过”。** 结构、输入不变、导出和参数核验结果继续由 D50 分别陈述。
