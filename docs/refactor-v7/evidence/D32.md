# D32 计划卡与执行进度

## 结论
前端实现完成，v2 计划与历史 v1 显示、执行数据准备/台账/预算事件均有测试。

## 改动摘要
- v2 卡显示已知事实、假设、数据来源/所属包/理由/范围/样式缩略图和三态预检；来源可改为文件、工程图层、内置图层、检索方式，保存后使用服务端新预检。
- 自动检索展开方式顺序、取舍与预计耗时；没有实测耗时时明确显示暂无参考，不编造数字。
- 步骤仅显示标题、输入与产出；不新增“获取数据”计划步骤。核对事项单列“成图后请核对”。
- 详细数据准备与取数台账放在右侧任务与过程；账目显示方法、参数、开始/完成时间、结果、原因及文件。
- 分别显示整任务、当前步骤、取数的预算用量；接近限额提示。暂停时提供继续、修改具体数据来源、预算设置与停止。
- 预算事件按 `data_id` / `step_id` / 整任务正确归属，恢复使用最新 attempt 的预算。
- 旧 v1 计划只读，可用原任务与流程重新生成，不能直接开始或修改。
- 保留既有 v1 阅读兼容分支，未新增多层迁移适配。
