# D11 首批内置图层、导入与迁移

## 结论
完成系统八图层、导入/预览/只读加载链路和历史路径建议。真实 China_map 已在隔离验收目录中导入，原始目录内容哈希不变；未直接修改用户日常运行目录。

## 改动摘要
- `scripts/layers/build_system_layers.py` 从现有真实全国行政区生成省/市/县边界以及面内代表点；三种面直接引用原 GeoJSON。八项包含来源、许可待核实与岛屿完整性提示，全部附真实 PNG 预览。
- 要素数：省域面/省界 34，市域面/市界/地级近似驻地 375，县域面/县界/县级近似驻地 2891。近似驻地名称明确带“（近似）”，不会将精确驻地名称设为别名。
- 导入复用数据扫描及文件头读取；QGIS 提供真实字段、CRS、范围、省域相交、要素数与建议比例尺。缺少 CRS 或自定义 CRS 需要用户确认；不会写原 `.prj`。
- CRS 建议以样本顶点与匹配省界的距离比较，剔除数据裁切边界上的顶点。多个候选在该尺度无法分辨时说明不确定，不虚构唯一 EPSG 建议。
- 建立标准名称与 1:100 万公众版代码映射；旧流程输入记忆/资源绑定中存在的数据文件夹返回迁移建议。
- `layer_load_builtin` 按登记 CRS、样式及标注字段读取；大图层/明确裁剪要求生成会话派生副本；重复源复用已加载图层。加入 data-loading 能力手册的真实工具授权。
- 隐藏 `layer_inspect` 支持文件或现有工程 layer_id，工程图层用 clone 检查，兼容内存图层，不改原图层。
- 隐藏 `layer_remove_created` 按准确 ID 清理本次新建层；成功时可保留产出版面地图/图例实际引用的辅助层；不删文件。
- 打包与部署保留 `data/layers`，仍排除其他运行时数据。

## 与方案不一致之处

## 遗留问题
