# D22 读图设置界面补充

## 结论
前端完成。提取器与 OCR 实测、依赖安装检查由 D22 主记录说明。

## 改动摘要
- 数据获取设置支持独立取数模型，显示服务端 `reading_status` 的视觉模型 / 本机 OCR / 不可用状态和具体说明。
- OCR 高级设置支持 RapidOCR（默认）、Tesseract、解释器、语言和引擎路径；不修改用户已保存的模型或本机环境。
- 增加可选 shell 权限与五项执行预算：取数时长/调用数、单步时长/调用数、整任务时长。
- 保存后重新读取服务端配置，更新实际读图状态；只读 `reading_status` 不提交到写入接口。
- 与 D12 合并移除旧本地文件夹表单，在线方式仍可启停。
- 未新增兼容层。

## 运行的命令与结果
`npm test` 全量最后一次 416 通过、6 个 opt-in 用例跳过；`DataAcquisitionWorkspace.test.tsx` 覆盖模型、读图状态、OCR/预算配置保存与目录入口迁移。`npm run lint` 和 `npx tsc --noEmit` 通过。

## 计数与耗时
设置渲染和保存不调用模型。测试为 API 夹具，不测 OCR 实际速度。

## 跳过的测试及原因
实际 OCR 精度与跨平台安装不属于这个界面测试，见 D22 主记录。

## 与方案不一致之处
无。默认 RapidOCR 随后端实测选型同步，未静默安装到真实用户 Python。

## 修改了涉及范围以外的文件
无。
