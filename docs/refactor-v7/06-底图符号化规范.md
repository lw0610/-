# 06 底图符号化规范：流程写“怎么画”，只在复杂符号上引用样式

## 1. 行军路线图里“底图怎么画”的写法变化

| 时期 | 写在哪里 | 写法 | 证据 |
|---|---|---|---|
| 9 月及以前（流程架构重构前） | 技能 `print-layout-marching-route` 第 1 节“点、线、面标准符号化” | **逐层写操作**：哪个图层用哪个符号化工具、按什么类型、标注哪个字段、标注怎么放。例如：`省域 → layer_set_fill_symbol，layer_type: 省，label_field: NAME`；`河流线 → layer_set_line_symbol，line_type: 河流，label_field: NAME`，合并同名且首尾相接的短线段、水平放置完整河名、不重复；`公路 → line_type: 高速公路`（只复用视觉线型）；面图层只给主体分区层级开标注，China_map 的省域例外 | `git show 77710c4:autocarto/skills/system/print-layout-marching-route/SKILL.md`（第 39–199 行）；9 月会话 `5703b4b9` 制图专家调用 `layer_set_line_symbol` 5 次、`layer_set_fill_symbol` 2 次 |

需要说明的一点：9 月那些“操作”其实也是按类型读取内置的 QML 预设（`layer_set_line_symbol` 等工具的说明是“根据图层类型读取内置 QML 设置……”，实现见 `autocarto/tools/system/_shared/basemap_presets_impl.py`）。现在的 11 个样式就是从这些预设导出的（样式说明“由原预设导出的符号和标注”）。所以 9 月和现在的**图面是一样的**，区别在于：9 月的流程写明了对每个图层做什么、标注规则是什么；现在这些都藏进了样式文件，流程里只剩一个名字。

## 2. 分析：现在这种写法的问题

1. **流程看不出图怎么画。** 流程里只有 `样式「省界」`，作者和模型都不知道它是“蓝色 0.5 毫米实线、一侧再叠一条浅蓝线”。想改颜色或线宽，只能到 QGIS 里改样式文件再保存回库，流程本身表达不了制图意图。
2. **样式文件把数据细节写死了。**
   - 标注字段写死在样式里：省域面、河流线等写的是 `NAME`，驻地写的是 `name`。数据一换来源（内置行政区是 `name`，OSM 是 `name:zh`），标注就对不上。v6 为此给 `layer_load_style` 加了 `label_field` 补丁。
   - 样式说明和样式内容不一致：县域面、市域面、河流面的说明写“标注字段：无”，但样式文件里标注是开着的（`labelsEnabled="1"`，字段 `NAME`）。v6 验收发现“禁用标注的残留配置差异”就是这个原因（`docs/refactor-v6/evidence/L51-qgis-acceptance.md`）。
   - 字体写死成 `.AppleSystemUIFont`，这是 macOS 的系统界面字体；换到 Windows 或 Linux 就会回退成别的字体，中文可能显示不全。
3. **尺寸不随纸张变。** 流程允许 A0–A4，但样式里的线宽、字号都是固定毫米数（例如省名 5.2 毫米）。A1 合适的尺寸放到 A4 上就显得过大。
4. **为了这层间接引用付出了很多机制。** v2 到 v6 的样式集、对照表、资源句柄、锁定摘要、预览、迁移，相当一部分是为“流程引用样式”服务的。

样式也有它的长处，不能全部丢掉：一次调用就能精确还原；复杂符号（黑白相间的铁路、双色界线、双线公路）用文字描述既啰嗦又容易执行错；样式可以在资源库预览，也可以在多个流程之间复用。

## 3. 结论

**底图部分改回“逐层写怎么画”，只保留一个图层引用内置样式；图层数据按 v7 使用内置图层。**

- **逐层写操作**：每个底图图层写明用哪个内置图层、怎么画（填充、线色、线宽、线型、点符号）、标注什么、怎么放、上下顺序。数值取自现有样式文件，保证改写后图面不变（见 `05` §1.1 的表格）。
- **只有铁路保留 `样式「铁路」`**，理由有三：
  - 黑白相间是标准铁路符号，由两层线和自定义虚线组成，用文字描述容易执行错；
  - 铁路不标注，没有字段耦合问题；
  - 内置流程里保留一处样式引用，样式机制就一直有用例覆盖。
- **图层用内置**：`图层「省域」` 等，按 `01` 的规则确定来源。
- **标注字段不写死**：流程写“标注省名”“标注河名”，系统按内置图层清单的 `label_field`（China_map 是 `NAME`，内置行政区是 `name`）或按实际字段自动选。
- **尺寸随纸张缩放**：表中尺寸按 A1 写；其他纸张按纸张短边比例缩放（A0 ×1.41、A2 ×0.71、A3 ×0.5、A4 ×0.35），字号不小于 1.8 毫米，线宽不小于 0.1 毫米。
- **字体**：标注使用系统中可用的中文黑体（微软雅黑、苹方、思源黑体或 Noto Sans CJK 中第一个可用的）。

为什么不直接恢复 9 月那几个工具：它们只能按固定类型（省、市、县、河流；铁路、高速公路、国道、省界、河流；city、county）套预设，流程里还是改不了颜色和线宽，只是把“样式名”换成了“类型名”。要让流程里写的“怎么画”真正能执行，需要一个按参数设置符号和标注的工具（§4）。

## 4. 工具：按参数设置符号与标注

新增 `layer_set_symbology`（QGIS 端，`autocarto/tools/system/cartography/`），一次可以设置多个图层：

```json
{
  "items": [
    {
      "layer": "省域",
      "symbol": {"type": "fill", "layers": [
        {"fill": "#FFFFFF", "outline": "#707070", "outline_width": 0.5, "outline_style": "dash_dot"}
      ]},
      "labels": {"field": "auto", "size": 5.2, "unit": "mm", "color": "#242424", "placement": "horizontal"}
    },
    {
      "layer": "河流线",
      "symbol": {"type": "line", "layers": [{"color": "#A6CEE3", "width": 0.46}]},
      "labels": {"field": "auto", "size": 10, "unit": "pt", "color": "#A6CEE3", "placement": "line", "merge_lines": true, "repeat": 0}
    },
    {
      "layer": "地区界线",
      "symbol": {"type": "line", "layers": [
        {"color": "#2399E9", "width": 0.5},
        {"color": "#A6CEE3", "width": 0.5, "offset": 0.4}
      ]},
      "labels": null
    }
  ],
  "scale": 1.0
}
```

| 部分 | 支持的内容 |
|---|---|
| 面符号 `fill` | 填充色、透明度、边线色、边线宽、边线线型（实线、虚线、点划线、无） |
| 线符号 `line` | 多层叠加（自下而上）；每层颜色、线宽、虚线模式（如 `[4, 4]`）、偏移、端点样式。双线公路、双色界线、黑白铁路都能表达 |
| 点符号 `marker` | 形状（圆、方、三角、星）、大小、填充（可为空心）、描边色与宽；多层叠加 |
| 标注 `labels` | 字段（`auto` 时用内置图层清单的 `label_field`，否则依次尝试 `NAME`、`name`、`name:zh`、`名称`）、字号与单位、颜色、字体（`auto` 时按 §3 的中文黑体顺序选第一个可用的）、白色描边（可选）、放置方式（水平、沿线、点周围）、合并同名相连线段、重复间隔；`null` 表示关闭标注 |
| 整体缩放 `scale` | 线宽、点大小、字号、偏移统一乘以该值；字号不小于 1.8 毫米、线宽不小于 0.1 毫米 |

工具返回：实际写入的设置，以及从 QGIS 读回的渲染器与标注设置（颜色、线宽、字段、是否显示、放置方式、实际字体）。字段不存在、字体回退等写入警告。

**核验**：执行器把工具返回的“读回设置”与调用参数逐项比较（颜色完全一致，线宽误差不超过 0.01 毫米，标注字段与开关一致）。不一致按 `03` §5.3 交回同一执行智能体修复。模型把流程文字翻译成参数这一步，靠流程里写明具体数值来保证；需要时再做图面质量审查。

已有的 `layer_load_style`、`layer_load_styles` 保留，用于流程里引用样式的图层（如铁路），并在加载时同样按 §3 处理字体回退。9 月的 `layer_set_fill_symbol`、`layer_set_line_symbol`、`layer_set_marker_symbol` 不再给模型使用，等 D50 回归通过后删除。

## 5. 流程编写规则（写进 `docs/制图指南编写指南.md`）

1. 底图表格建议的列：图层 | 内置图层 | 怎么画 | 标注 | 上下顺序。
2. “怎么画”写清颜色（十六进制或常用色名加十六进制）、线宽或大小（毫米）、线型；多层符号按自下而上写。
3. “标注”写标注什么（省名、河名、地名）和放置方式，不写字段名；字段由系统按数据确定。
4. 复杂的标准符号可以写 `样式「名称」`，此时“怎么画”只写样式名和一句说明。
5. 写明尺寸对应的纸张（例如“以下尺寸按 A1”），其他纸张按 §3 缩放。
6. 流程里没写怎么画的图层，用内置图层清单里的 `default_style`；它也没有的，由执行智能体按图层类别给出简洁的默认表达，并在交付里说明。

## 6. 与其他部分的关系

- **资源库**：11 个样式保留，可以预览、引用、复用；它们是“现成的画法”，不再是流程的必需依赖。
- **内置图层清单**：`default_style` 保留，作为流程没写画法时的默认值（`01` §2）。
- **计划**：底图符号化仍是一个普通步骤，`instructions` 带上流程里该图层的“怎么画”和“标注”两列原文；计划格式不增加新的结构。
- **其他内置流程**：统计专题图的行政区面、交通线路图、通用数据成图，按同样的规则改写（D40）；专题层的分级设色本来就是操作描述，不变。你新写的《轨道交通站点服务覆盖图》已经是这种写法（大部分图层写怎么画，河流和水域引用样式），可以直接沿用。
