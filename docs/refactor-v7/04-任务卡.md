# 04 任务卡

每张卡可以单独交给一个执行智能体。交付时附上本卡、`README.md`，以及卡中“必读”列出的文档。

通用要求：

- 遵守 `README.md` §7 的约束；开工前对照 §3 文件归属表。
- v6 实际文件名以用户工作目录中的代码为准；与本卡不同时照实际修改，并在验证记录里写明对应关系。
- 完成后写 `docs/refactor-v7/evidence/<任务号>.md`（格式见 `evidence/README.md`），在 `refactor/v7` 分支提交（提交信息以任务号开头，不推送）。
- 命令约定：Go 命令在 `carto_agent/` 下执行；前端命令在 `autocarto-web/` 下执行；Python 命令在仓库根目录执行，`$PYTHON_BIN` 指能导入 QGIS 的解释器，`test_*_qgis.py` 每个模块单独进程运行。
- 测试使用临时运行目录，不读写真实 `autocarto_data/`，不访问真实网络；模型行为用脚本化测试模型模拟。D51 例外。

- **测试**：`./build.sh check`

## D10 内置图层库后端

- **目标**：内置图层的清单、库、匹配和接口。
- **必读**：`01` §1、§2、§3、§5、§9
- **涉及范围**：新建 `internal/layers/`（`manifest.go` 清单读写与校验；`library.go` 系统与用户两个根目录、名称唯一、别名；`match.go` 按 `01` §5 匹配与排序；`coverage.go` 覆盖率计算；`digest.go` 内容摘要与变化检测）；`internal/datasource/**`（把内置图层作为最高优先级的本机来源接入目录，替代原来需要在设置页登记的 `local_folder`）；新建 `internal/api/handlers_layers.go` 并在 `routes.go` 注册（列表、详情、预览地址、导入草稿、确认导入、修改名称/别名/标注字段/坐标系/建议比例尺、删除登记）；`internal/fileops/workspace.go`（内置图层原文件只读可读）；测试。
- **步骤**：
  1. 按 `01` §2 定义清单结构与校验（必填项、类别存在于 `categories.yaml`、几何合法、默认样式存在于样式库）。
  2. 库读取两个根目录；名称在全库唯一；别名与其他图层名称冲突时，名称优先；别名对应多个图层时标为歧义。

- **验收**：清单校验正反测试；名称唯一与别名歧义；匹配排序覆盖“流程点名、名称、类别、覆盖不足、用户导入优先、比例尺”六种情况；摘要变化检测；文件工具能读内置图层原文件但不能写。
- **测试**：`go test ./internal/layers/... ./internal/datasource/... ./internal/api/... ./internal/fileops/... -count=1`

## D11 首批内置图层、导入与迁移

- **目标**：系统自带全国行政区图层；China_map 能一键导入；1:100 万公众版有导入映射；旧版本使用过的底图文件夹能被发现。
- **必读**：`01` §4、§6、§7、§10
- **涉及范围**：`autocarto/data/layers/system/**`（系统图层包的清单与预览）；`scripts/layers/build_system_layers.py`（QGIS Python：由 `autocarto/tools/system/admin-boundaries/assets/中国行政区边界/data/` 生成省界、市界、县界和两个近似驻地图层，输出随程序发布的 GeoPackage；行政区面直接引用原 GeoJSON，不复制）；`internal/layers/`（导入：复用 `datasource/scan.go` 的扫描与 `dataservice` 的文件头读取；坐标系核验按 `01` §7.2；建议比例尺按 `01` §7.3；迁移：读取 `flow_input_memory.yaml` 与旧资源绑定，生成“建议导入”）；`autocarto/data/layers/mappings/webmap-1m.yaml`；`resource_preview` 扩展支持图层预览；新建工具 `layer_load_builtin`（按清单坐标系加载、套默认样式并传入标注字段、可按范围裁剪成派生副本）；Natural Earth 世界背景包在首次使用时下载并缓存；测试。
- **步骤**：
  1. 生成系统图层包：省域面、市域面、县域面、省界、市界、县界、地级城市驻地（近似）、县级城市驻地（近似），共 8 项，清单齐全并生成预览；来源与合规提示按 `01` §4.1。
  2. 导入：用夹具模拟 China_map 的 8 个文件（含 EPSG:4004、无 `.prj`、自定义坐标系三种情况），走“扫描 → 建议 → 确认 → 写清单 → 预览”。
  3. 坐标系核验：自定义或缺失的标为“请确认”，给出偏差最小的建议。
  4. 迁移：临时运行目录里放一份含 China_map 路径的 `flow_input_memory.yaml`，接口返回“建议导入”。
  5. `layer_load_builtin`：加载、坐标系指定、标注字段、裁剪副本；原文件哈希不变。
- **验收**：系统图层包 8 项都有预览；夹具 China_map 导入后，8 项的名称、类别、标注字段与 `01` §4.2 一致，坐标系问题被标出；原文件哈希不变；迁移提示出现且能一键进入导入；`layer_load_builtin` 在真实 QGIS 中加载并套样式成功。
- **测试**：`go test ./internal/layers/... ./internal/api/... -count=1`；`$PYTHON_BIN autocarto/tests/test_builtin_layers_qgis.py`（新建）；`$PYTHON_BIN autocarto/tests/test_resource_preview_qgis.py`

## D20 检索方式路由、取舍与数据仓语义键

- **目标**：没有的数据按路由表选对方式，结果按比例尺取舍，取过的能复用。
- **必读**：`02` §1–§4、§7
- **涉及范围**：`autocarto/tools/system/data-acquisition/assets/categories.yaml`（每个类别增加按比例尺档的方式顺序与取舍规则）、`assets/sources/*.yaml`（每种方式的最大范围、比例尺档、是否有中文名、典型耗时）；`internal/acquire/`（`EstimateScale` 加入版面主图框；数据仓键改为 `02` §7 的语义键，旧条目只读兼容）；`handlers/normalize.py`（按类别取舍、同名合并、简化、字段统一）；`internal/datasource/planning.go`（候选排序改为“内置 → 数据仓 → 路由表顺序”）；`internal/dataservice/candidates.go`（Overpass 超过 2 万平方千米不入选；需要中文名时排除无名来源）、`dataservice/fallback.go`（删除按冻结候选放行的判断，改为按设置统一判断）；`internal/datasource/**` 中与路由相关的部分；`internal/fileops/workspace.go`（数据仓目录只读可读）；测试。

  1. 把 `02` §3 的路由表写成数据（`categories.yaml` 的 `routing` 段），程序只读数据，不在代码里写死业务判断。
  2. 比例尺估算：输入范围与版面名称，输出比例尺分母与档位。

  4. 取舍：在 `normalize.py` 里按 `02` §3 的规则过滤、合并、简化，规则和统计写入来源说明。

- **验收**：四个路由用例的方式顺序与理由符合 `02` §3：湖南省河流和铁路 A4、河南省高速公路 A4、郑州市地铁 A3、全国铁路 A3；同一输入连续三次结果相同；Overpass 不会被选给省级范围；用夹具 OSM 数据验证取舍（高速公路按 `ref` 合并后要素数显著下降，记录前后数量）；数据仓按含义命中。
