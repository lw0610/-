# 01 内置图层规范

## 1. 内置图层是什么

内置图层是安装在本机、可以直接加载的地理数据。每一项是一个有名字的图层，例如“省域”“河流线”。

| | 内置图层 | 样式 / 版面 | 任务数据 |
|---|---|---|---|
| 是什么 | 本机长期可用的地理数据 | 图层怎么画、版面怎么排 | 本次任务用户给的、或检索取到的数据 |
| 谁提供 | 系统自带、用户导入 | 系统自带、用户保存 | 用户、自动检索 |
| 流程里怎么写 | `图层「省域」` | `样式「省域面」`、`版面「四角对齐版式」` | 不写，运行时确定 |
| 在哪看 | 资源库“内置图层”页签 | 资源库“样式”“版面”页签 | 计划卡、会话文件 |
| 随流程导出吗 | 只导出引用，不导出数据 | 导出 | 不导出 |

内置图层按**图层包**分组：一个包对应一个数据来源，例如“全国行政区（系统自带）”“China_map”“1:100 万公众版”。包记录来源、许可和合规提示，包里的每个图层可以再补充自己的说明。

## 2. 图层清单（`layer/v1`）

每个图层一份 `layer.yaml`：

```yaml
apiVersion: layer/v1
id: layer.user.china-map.province      # 稳定编号：layer.<system|user>.<包>.<图层>
name: 省域                              # 引用名称，在整个库里唯一
aliases: [省级行政区, 省域面]            # 别名；与其他图层的名称冲突时，名称优先
pack: China_map                         # 图层包
category: admin.division                # 数据类别，取自 categories.yaml
params: {level: 省}
geometry: polygon                       # point | line | polygon | raster
file: /Users/zw/研究生/QGIS-agent/数据/底图数据/China_map/省域.shp
sublayer: ""                            # GeoPackage 子图层名
declared_crs: EPSG:4004                 # 文件自身声明的坐标系
crs: EPSG:4490                          # 实际使用的坐标系；与声明不同时，加载时指定，不改原文件
coverage:
  bbox: [102.1, 28.9, 118.6, 37.8]      # 西、南、东、北，EPSG:4326
  regions: [河南省, 湖北省, 陕西省]       # 与内置省域面相交的省级单元
scale: {best_from: 1000000, best_to: 5000000}   # 建议适用的比例尺分母范围
fields: {name: NAME, code: "", class: ""}      # 标准字段 → 实际字段
label_field: NAME
default_style: 省域面                    # 资源库里的样式名称；只在流程没写画法时作为默认画法（06 §5）
feature_count: 11
source: {title: 用户底图 China_map, license: 用户自有, attribution: "", url: "", version: "", retrieved_at: ""}
compliance: 区域数据，不含国界与南海诸岛表达；向社会公开的地图按《地图管理条例》送审
digest: sha256:…                        # 主文件及附属文件的内容摘要；变化时提示重新确认
preview: preview.png
created_at: 2026-10-29T10:00:00+08:00
```

存放位置：

- 系统自带：`autocarto/data/layers/system/<包>/<图层>/layer.yaml`；数据文件随程序发布，路径相对清单目录。
- 用户导入：`<AUTOCARTO_HOME>/layers/<包>/<图层>/layer.yaml`。这里只保存清单和预览，数据留在用户原来的位置，以只读方式使用。

## 3. 标准图层名

导入时据此给出建议名称；流程里的常用说法也据此对应。名称与样式库里的 11 个样式一一对应，这样默认样式可以自动对上。

| 标准名称 | 常见别名 | 类别与参数 | 几何 | 标准字段 | 默认样式 |
|---|---|---|---|---|---|
| 省域面 | 省域、省级行政区 | `admin.division` level=省 | 面 | name、code | 省域面 |
| 市域面 | 市域、地级行政区 | `admin.division` level=市 | 面 | name、code | 市域面 |
| 县域面 | 县域、县级行政区 | `admin.division` level=县 | 面 | name、code | 县域面 |
| 省界 | 地区界线、线状省界 | `admin.boundary_line` level=省 | 线 | kind | 省界 |
| 市界 | 地级界线 | `admin.boundary_line` level=市 | 线 | kind | 省界（细） |
| 县界 | 县级界线 | `admin.boundary_line` level=县 | 线 | kind | 省界（细） |
| 河流线 | 线状河流、水系线 | `hydro.river_line` | 线 | name | 河流线 |
| 河流面 | 面状河流、水域面、湖泊水库 | `hydro.water_polygon` | 面 | name | 河流面 |
| 铁路 | 铁路线 | `transport.railway` | 线 | name、class | 铁路 |
| 高速公路 | 高速 | `transport.road.expressway` | 线 | name、ref | 高速公路 |
| 国道 | 普通国道 | `transport.road.national` | 线 | ref、name | 国道 |
| 公路 | 主要公路、干线公路 | `transport.road.major` | 线 | class、ref | 高速公路 |
| 地级城市驻地 | 城市驻地、地级驻地 | `settlement.prefecture_seat` | 点 | name | 地级城市驻地 |
| 县级城市驻地 | 县城驻地、县级驻地 | `settlement.county_seat` | 点 | name | 县级城市驻地 |
| 海岸线 | 海岸 | `hydro.coastline` | 线 | — | （无） |

“省界（细）”表示用省界样式，导入或套用时允许调细线宽；是否另建“市界”“县界”样式由 D11 决定，并在资源库里补齐。

## 5. 匹配规则

对计划中的每个图层，按下面的顺序在内置图层库里找：

1. **流程点名**：流程写了 `图层「X」` 时，先找名称为 X 的图层；没有则找别名唯一为 X 的图层。都找不到、别名对应多个图层，或者找到了但不覆盖本次范围时，继续按下面第 2–6 条找其他内置图层，再找不到就转自动检索。这种情况预检标“请确认”，计划卡写明“流程点名的「X」未安装（或不覆盖本次范围），改用 ……”，不悄悄替换。
2. **名称对应**：计划中图层的名称或别名与库中图层的名称或别名一致。
3. **类别对应**：类别与参数一致（例如 `admin.division` level=市）。
4. **过滤**：几何类型一致；需要的字段存在（例如要标河名，就必须有名称字段）；范围已知时，覆盖率不低于 90%。
5. **排序**：用户导入的优先于系统自带（用户特意装的）→ 当前比例尺落在建议范围内的优先 → 覆盖率高的优先。
6. **执行前复核**：范围要到执行时才知道（例如来自路线数据集）的，执行前再检查一次覆盖率。不足时按排序改用下一个候选，并在进度里说明；都不行就转自动检索。

计划卡显示选中的图层，并列出其他可用的候选，可以一键改。

## 6. 加载

- 新增工具 `layer_load_builtin`（QGIS 端），参数：`name`（图层名称）、可选 `layer_name`、`style`、`extent`、`clip`。工具负责按清单的 `crs` 加载、传入 `label_field` 套样式、返回工程图层 ID。执行智能体和系统都用这个入口，不需要知道文件路径。
- 默认整层只读加载。要素数超过 20 万、文件超过 200 MB，或计划要求裁剪时，按范围裁剪成会话派生副本（GeoPackage），原件不动。
- 显示坐标系与数据不同时，由 QGIS 动态投影，不另存重投影副本。
- 加载时自动在本次的数据来源说明里追加一条：图层名、包、来源、许可、合规提示。

## 7. 导入

### 7.1 流程

资源库 →“内置图层”→“导入文件夹”：

1. 选择文件夹。系统复用现有的扫描代码（`carto_agent/internal/datasource/scan.go:41` 的 `ScanLocalDraft`，以及 `dataservice` 读取文件头的 `InspectProvided`），列出其中的矢量和栅格文件。
2. 每个文件一行，系统给出建议：名称（按 §3 对应）、类别、几何、要素数、字段、标注字段、默认样式、声明坐标系、覆盖范围、建议比例尺。
3. 用户确认或修改每一行，可以不导入某些文件。
4. 系统写清单、生成预览（用 QGIS 的 `resource_preview`，扩展支持图层类型），计算内容摘要。

导入不复制、不修改原文件。原文件内容变化（摘要不同）时，资源库标“已变化，请重新确认”，在确认前该图层不参与自动匹配。

### 7.2 坐标系核验

以下情况标为“请确认”：

- 没有 `.prj`，或声明为自定义坐标系；
- 声明的坐标系下，图层范围与内置省域面中对应区域的偏差超过 1 千米。

系统把图层范围依次按 EPSG:4326、4490、4214、4610 和 CGCS2000 3 度带（4513–4554）解释，与内置省域面比对，给出偏差最小的建议。用户确认后写入 `crs`，加载时指定，原文件不变。

### 7.3 建议比例尺

线图层按相邻顶点间距的中位数估算：适用比例尺分母约等于“中位间距（米）÷ 0.0005”，建议范围取该值的 0.5 到 4 倍；面图层用边界线计算；点图层不估算。用户可以修改。

### 7.4 从旧版本迁移

启动时读取 `flow_input_memory.yaml` 和旧的资源绑定。发现以前用过的底图文件夹（例如 China_map）且还没导入时，在资源库“内置图层”页顶部提示“发现以前使用的底图文件夹，导入为内置图层？”，一键进入 §7.1 的确认步骤。

## 8. 资源库界面

资源库新增第三个页签“内置图层”：

- 分组：按图层包，组内按“行政区 / 水系 / 交通 / 居民地 / 其他”排列；支持搜索名称、别名和类别。
- 每项显示：用默认样式渲染的缩略图（QGIS 生成）、名称、包、几何、要素数、覆盖范围（区域列表和小地图）、建议比例尺、标注字段、默认样式、来源与许可、合规提示、坐标系（声明与实际）。
- 操作：查看大图；修改名称、别名、标注字段、坐标系、建议比例尺（仅用户导入的）；重新生成预览；删除登记（不删除文件）。
- 设置页“数据来源”只保留在线检索方式（OSM、Earth Engine、天地图、门户、联网搜索）的开关和状态；登记本机文件夹的入口移到这里。

## 9. 流程里的写法

- 写 `图层「省域」`，或 `内置图层「省域」`。保存流程时检查是否存在：不存在或有歧义时给出提示，但不阻止保存；运行时按 §5 第 1 条改用其他来源。
- 只写“用内置的省域图层”而不加书名号，模型也能按 §5 对应上，但保存时不做检查，也不锁定。
- `flow.lock` 增加 `layers:` 段，记录被引用图层的编号、名称和内容摘要；摘要变化时，计划卡提示“内置图层已变化”。
- 导出流程只带引用，不带数据。在另一台机器上导入时，列出“需要导入的内置图层”。

## 10. 合规

- 系统自带的行政区数据：上游声明来自天地图，许可待核实；南海诸岛、钓鱼岛等岛屿的完整性未核实。
- 向社会公开的地图按《地图管理条例》送审；涉及国界和南海诸岛表达时，应使用标准地图或经过审核的底图。
- 系统在成图的来源说明里如实写出来源与合规提示，不替用户判断能否公开。
