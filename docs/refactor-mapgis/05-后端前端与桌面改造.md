### 1.5 H14 系统内部的宿主调用与文字

Go 中按名称调用的宿主工具（完整清单见 `evidence/00-对比清单.md` §3）全部**保留原名**，由 MapGIS 插件实现同名同结构的工具。本卡的工作：

1. **集中登记**：新建 `internal/hostops/registry.go`，列出系统依赖的宿主操作与其回执的必需字段，例如 `get_layers_info` 必须有 `layers[].layer_id/name/type`，`layout_get_items_properties` 必须有 `data.layout_snapshot_path`。
   - 调用后先校验必需字段，缺失时报“宿主插件回执不完整”，不让执行器把结构问题当成内容问题处理。
   - 宿主包缺少某项操作时，启动日志与诊断页列出缺项，相关功能提示不可用。
2. **按契约 runtime 分发**：下列调用不再假设在宿主执行，改为调用工具注册表，由契约 runtime 决定在哪执行。MapGIS 包中这些工具为 `geo`，宿主离线时也能处理文件。
   - `internal/acquire/executor.go:264,332,348,745`（`archive_extract`、`data_normalize`、`data_derive`）；
   - `internal/acquire/provided.go:71`；
   - `internal/acquire/adapter_tianditu.go:68,76`；
   - `internal/acquire/adapter_offline.go:15`（`admin_boundary_extract`）；
   - `internal/integrations/osm_clip.go:215`（OSM 精裁）。
3. **脚本工具名**：同时认 `pyqgis_*` 与 `geo_*`。
   - `internal/hitl/guard.go:47`：对 `pyqgis_submit_script` 的守卫同样作用于 `geo_submit_script`；
   - `internal/agentruntime/plan_main.go:42`：Plan 只读工具中增加 `geo_get_context`、`geo_get_task_status`。
4. **私有瓦片**：`internal/middleware/bridge/private_tiles.go` 的“密钥进入工程须确认”规则不变。QGIS 认证配置编号只在 QGIS 宿主下检查；MapGIS 宿主按 M02 第 6 项实现，不支持时 `data_load_tiles` 不在目录中。
5. **文字**：下列提示中的“QGIS”改为宿主显示名：
   - `internal/dataservice/candidates.go:159`、`get.go:24`；
   - `internal/acquire/adapter_tianditu.go:44`、`extent.go:123`；
   - `internal/shared/toolutils/toolutils.go:109,114`；
   - `internal/knowledge/pipeline.go:162`；
   - `internal/deepagent/knowledge_review.go:75`；
   - `internal/control/shared_error_dictionary.go`；
   - `internal/flowrun/verify_symbology.go:93`。
