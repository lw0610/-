# 08 任务卡

共 53 张卡，分 7 条泳道。卡号前缀：

- M：基线与环境
- H：后端
- W：前端、桌面与构建
- P：插件骨架
- T：宿主工具
- G：geo
- R：内容
- V：验收

规模：S 不超过 1 天；M 2–3 天；L 约 1 周；XL 2 周以上，可再拆分。“环境”写“Windows+MapGIS”的卡，只能在装有 MapGIS 的 Windows 上做。
