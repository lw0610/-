## 2. 一致性门禁（V70）

`check_consistency.py` 依次检查以下内容，任何一项失败都使 `build.bat check` 失败：

1. **覆盖**：`autocarto/tools/system` 中的每份契约，在 `tool-mapping.yaml` 中都有一行；反过来，`tool-mapping.yaml` 中除“不支持”外的每一行，在 `autocarto_mapgis/tools/system` 中都有契约。
2. **参数**：MapGIS 契约的参数名、类型、必填、缺省值、枚举与 QGIS 版逐项相同，例外须在 `tool-mapping.yaml` 中写明。
3. **实现**：
   - `runtime: mapgis` 的契约，`execution.backend_tool` 在插件 `[HostTool]` 注册表中存在。插件编译后，导出注册表 JSON 供检查。
   - `runtime: geo` 的契约，`execution.handler` 指向的 Python 函数可以导入。
4. **回执结构**：`autocarto_mapgis/spec/contracts/*.json` 中每个宿主工具都有期望回执结构，并且覆盖 Go 侧 `internal/hostops` 登记的必需字段。
5. **工具包**：每个工具包的 `tools` 都在 MapGIS 包中存在；不支持的工具不出现在任何工具包、流程或提示词中。
6. **流程与资源**：MapGIS 包中流程引用的样式、版面、图层都存在，`flow.lock` 摘要有效。
7. **写死场景扫描**：`plugin/AutoCarto.MapGIS.Plugin/Handlers/**/*.cs` 中不得出现以下内容。例外登记在 `autocarto_mapgis/spec/hardcode-allowlist.yaml`。
   - 毫米纸张尺寸字面量，例如 `1360`、`940`、`1000`、`855`；
   - 中文业务名字面量，例如“红25军”“革命根据地”；
   - 字段值到符号名的字典。
8. **文字**：MapGIS 包的契约、工具包、流程、提示词中不出现 QGIS、QML、QPT、PyQGIS 字样。说明“仅 QGIS 版支持”的报错文字除外。

## 3. geo 对照（V71）

- 按 `04` §11 运行全部 geo 测试。生成对照报告 `evidence/V71-geo-parity.md`：每个工具的用例数、通过数、最大差异，以及“近似”项的差异说明。

## 4. 真机冒烟（V72）

`scripts/mapgis_host_harness.py --suite smoke` 按工具族依次执行。每个场景 YAML 写明前置数据、调用序列和期望回执结构：

| 场景 | 覆盖 |
|---|---|
| 工程 | 新建、打开、保存、另存为（上报 `previous_path`）、多地图、工程信息、关闭（视 M02 第 8 项） |
| 加载 | GeoJSON、Shapefile（GBK 与 UTF-8）、GeoPackage、GeoTIFF、内置图层、同源复用、编码检查、坐标系声明、图层组、移除、物化导出、数据替换 |
| 画布 | 比例尺、缩放到范围或图层、读取范围 |
| 选择 | 按属性或表达式选择、清除、随机、读取选中 OID |
| 符号 | 面线点单层与多层、虚线、点形状、标注各属性、分类、分级、规则、透明度、色带、样式资源导入导出、读回比对 |
| 版面 | 创建、页面、全部元素类型、查询、移动、缩放、对齐、分布、层级、分组、锁定、删除、坐标换算核对 |
| 合成与导出 | 两个内置版式、PDF、PNG、JPG、SVG（经 PDF）、快照文件 |
| 图文标注 | 数据集标注表、避让、移动 |
| 路线 | 红蓝对比与单色两种样式、分叉与汇入、点符号、Flox 可用与不可用两种情况 |
| 预览 | 样式、版面、内置图层的预览 |

通过标准：

- 每个工具至少一次成功；
- 回执结构校验通过；
- 全程没有宿主崩溃，也没有超过 60 秒无响应的调用；
- 结束后宿主文档仍可正常保存。

截图与回执存入 `evidence/V72/`。

## 5. 固定场景（V73）

不经模型，按固定角色顺序调用工具；同一场景在 QGIS 版上的结果作为对照。

| 场景 | 数据 | 产出 | 核对 |
|---|---|---|---|
| 行军路线 A1 | 红二十五军史料对应的已确认数据集（v7 D50 使用的同一份）；China_map 内置图层 | PDF、PNG | 8 层底图逐层读回与流程画法一致；路线数、点数、图文框数与 QGIS 版相同；版面元素位置与 QGIS 版相差不超过 0.5 毫米 |
| 行军路线 A4 | 同上，A4 横向 | PDF、PNG | 尺寸按 0.35 缩放，并受下限约束（字号不小于 1.8 毫米、线宽不小于 0.1 毫米） |
| 统计专题图 | 河南省各市 2023 年常住人口（统计库中已入库的那份） | PDF、PNG | 分级断点与 QGIS 版相同；图例项相同 |

记录每个场景的耗时、工具调用次数与失败次数，与 QGIS 版对比，写入 `evidence/V73.md`。

## 7. 安装包（V75）

在干净的 Windows 10/11 虚拟机上验证。MapGIS 预先安装，其余全部按 `autocarto_mapgis/README.md` 操作：

1. 安装桌面应用。
2. 运行 `geo_env.ps1 install`。
3. 在 Ribbon 工程中引用插件 DLL，生成 `AutoCarto-MapGIS.exe`。
4. 在设置中填写可执行文件路径。
5. 启动并连接。
6. 运行县域坡度分级流程出图。

逐步记录耗时与遇到的问题。总时长不超过 30 分钟，不含 MapGIS 本身的安装。

## 8. 证据格式

每张卡写 `evidence/<卡号>.md`，格式同 v7 的证据：

```markdown
# <卡号> <标题>

- 日期、执行环境（操作系统、MapGIS 版本、.NET、conda 环境锁文件摘要）
- 改动文件清单（与卡片“涉及范围”对照，超出范围的说明原因）
- 测试命令与结果（原样粘贴摘要，失败项保留）
- 真机验证（如有）：场景、截图路径、回执路径
- 与 QGIS 版的差异：保真度变化须同步 tool-mapping.yaml
- 遗留问题
```

不把跳过的测试写成通过，不用手工调用工具的成功顶替自动场景。
