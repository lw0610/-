## 每张卡的验证记录

```markdown
# <卡号> <标题>

- 日期与执行环境：操作系统、MapGIS 版本、.NET SDK、Go、Node、conda 锁文件摘要
- 基于的提交与分支
- 改动文件：与卡片“涉及范围”对照，超出范围的写明原因
- 测试命令与结果：原样粘贴摘要，失败项和跳过项保留，不把跳过写成通过
- 真机验证（如有）：场景名、截图路径、回执路径、耗时
- 与 QGIS 版的差异：保真度有变化时，同一提交中修改 tool-mapping.yaml，并在这里写明理由
- 依赖探查：用到了 M02 的哪几项结论；结论不足时补了哪些探查
- 遗留问题与对后续卡的影响
```

## 规则

1. 截图、回执、日志等大文件放在 `evidence/<卡号>/` 子目录，正文只写路径与摘要。
2. 不写密钥、令牌、用户数据内容；本机路径可以写，但不要写用户名以外的个人信息。
3. 失败的尝试同样记录，写明原因与处理方式；不用手工调用工具的成功顶替自动场景。
4. 真实模型回放（V74）单独成文件，记录模型名称、调用次数（日志能统计时）、工具调用次数、耗时与失败次数。
