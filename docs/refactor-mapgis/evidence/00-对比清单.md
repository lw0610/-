## 5. 可被 geo 运行时复用的纯 Python 模块

在没有安装 QGIS 的 Python 3 中执行（仓库根目录）：

```sh
python3 -I -c "import sys; sys.path.insert(0,'.'); import importlib
for m in ['autocarto.knowledge','autocarto.knowledge.handler','autocarto.tools.system._shared.statistical_data_impl','autocarto.core.paths']:
    importlib.import_module(m); print('ok', m)
print('qgis loaded:', any(k.startswith('qgis') for k in sys.modules))"
```

结果：4 个模块全部 `ok`，`qgis loaded: False`。这些模块的 `autocarto.*` 依赖只有 `autocarto.core.paths`、`autocarto.knowledge.*`，以及 `autocarto.tools.system._shared` 下的 `resource_handle`、`statistical_data_impl`、`tool_assets`、`tool_presets`；`autocarto/__init__.py` 只在 `classFactory` 中延迟导入 QGIS 插件类。对应地，第一版 MapGIS 用 C# 重写了路线校验（`RouteValidator.cs` 1619 行）、路线编译（`RouteCompiler.cs` 905 行）、专题数据准备（`DataPrepareThematicTool.cs` 1178 行）。
