# 06 资源、工具包与流程迁移

## 1. 样式资源

### 1.1 为什么用 `style.yaml`

QML 是 QGIS 专有格式，MapGIS 无法读取。现有 11 个内置样式全部是单一符号渲染，只用到 `SimpleFill`、`SimpleLine`、`SimpleMarker` 三种符号层，标注都是简单标注（解析结果见 `evidence/00-对比清单.md` §6）。v7 以后，流程中的底图画法也已改成参数（`layer_set_symbology`）。所以 MapGIS 版的样式资源改为参数化的 `*.style.yaml`：

- 结构与 `layer_set_symbology` 的 `items[]` 相同，模型和人都能读懂；
- QGIS 版以后也可以直接套用（不在本轮范围内）；
- 复杂的标准符号不用参数描述，而是引用 MapGIS 符号包中的符号名，保证外观与规范一致。

### 1.2 格式

```yaml
apiVersion: style/v1
name: 高速公路
geometry: line                       # fill | line | marker
description: 高速公路，双线：深灰外边加橙黄内芯
renderer:
  type: single                       # single | categorized | graduated | rule
  symbol:
    layers:                          # 自下而上，键与 layer_set_symbology 的 symbol.layers 相同
      - {color: '#4D4D4D', width: 1.2, style: solid, cap: round}
      - {color: '#F2B134', width: 0.8, style: solid, cap: round}
  # categorized：field + categories[{value, label, symbol}]，可选 default
  # graduated：field + method + classes + breaks? + ramp，或直接给 ranges[{min, max, label, symbol}]
  # rule：rules[{label, expression, symbol}]（表达式方言见 04 §7）
labels: null                         # 与 layer_set_symbology 的 labels 相同；null 表示不标注
size_basis: A1                       # 尺寸按 A1；套用时由流程或工具的 scale 统一缩放
mapgis:                              # 可选；只在 MapGIS 宿主中生效
  symbol: AutoCarto-高速公路          # 系统库符号名；有它时优先使用，layers 作为读回比较与 QGIS 的依据
  symbol_pack: symbols/AutoCarto-线符号.xml
preview: preview.png
```

- JSON Schema 放在 `carto_agent/internal/resource/schema/style.v1.json`，由 H15 校验。
- 样式资源目录沿用现有结构：`resource.yaml` 加正文文件加 `preview.png` 和 `preview.digest`。`resource.yaml` 的 `entry` 指向 `*.style.yaml`。

### 1.3 QML 转换规则（`scripts/mapgis_pack/qml_to_style.py`，R61）

| QML 内容 | 转为 |
|---|---|
| `renderer-v2 type=singleSymbol` | `renderer.type: single` |
| `categorizedSymbol` / `graduatedSymbol` / `RuleRenderer` | `categorized` / `graduated` / `rule`；`attr` 写入 `field`；QGIS 表达式检查是否在方言范围内，超出时报错并人工处理 |
| `SimpleFill` | `fill`（颜色 `color` 的 RGBA）、`opacity`、`outline`（`outline_color`）、`outline_width`、`outline_style`；`style=no` 时 fill 写 `null` |
| `SimpleLine` | `color`、`width`、`style`（`line_style`）、`dash`（`use_custom_dash` 加 `customdash`，单位换成毫米）、`offset`、`cap` |
| `SimpleMarker` | `shape`（circle/square/triangle/star，其余形状报错并人工处理）、`size`、`fill`、`outline`、`outline_width` |
| 单位 | `MM` 直接用；`Point` 乘以 0.3528；`MapUnit`、`Pixel` 报错，人工处理 |
| 标注 `labeling type=simple` | `labels.field`：v7 规则为“标注字段由数据决定”，所以写 `auto`，原字段名放进 `labels.field_hint`；字号、颜色、粗体、描边、放置方式、合并线、重复、全部显示 |
| 字体 `.AppleSystemUIFont` 等系统专有字体 | `font: auto`（v7 已有的中文黑体回退规则） |
| 数据定义属性（`data_defined_properties`） | 逐项报告；能转为字段规则的转为规则样式，不能转的人工处理 |

转换器输出转换报告：每个 QML 一节，列出已转换项、丢弃项和需人工处理项，写入 `evidence/R61-qml-conversion.md`。

### 1.4 11 个内置样式

| 样式 | QML 结构 | MapGIS 版 |
|---|---|---|
| 省域面、市域面、县域面、河流面 | 两层 `SimpleFill`（填充加轮廓），简单标注 | 参数直接转换 |
| 河流线 | `SimpleLine` 加标注 | 参数直接转换；标注沿线、合并同名 |
| 省界 | 两层 `SimpleLine`（虚线） | 参数直接转换；虚线用生成的 `AutoCarto-dash-*` 线型。另设 `mapgis.symbol: AutoCarto-省界线`（第一版符号包中已有），在 V73 中逐项对照 |
| 高速公路 | 两层 `SimpleLine`（外边加内芯） | 参数加 `mapgis.symbol: AutoCarto-高速公路` |
| 国道 | `SimpleLine` | 参数转换；第一版已有 `AutoCarto-国道` 可选 |
| 铁路 | 两层 `SimpleLine`（黑底加白色虚线） | 参数转换，并设 `mapgis.symbol: AutoCarto-铁路`。第一版已制作黑白相间加外框发丝线的符号，流程里唯一仍引用样式的就是铁路，必须保证外观 |
| 地级城市驻地、县级城市驻地 | 两层 `SimpleMarker`，简单标注 | 参数转换；形状落到符号包的 `AutoCarto-marker-*` |

### 1.5 MapGIS 符号包

位置在 `autocarto_mapgis/symbols/`，文件为 gb2312 编码。

| 文件 | 内容 | 来源 |
|---|---|---|
| `AutoCarto-线符号.xml` | 铁路、高速公路、国道、河流线、省级行政区界线、地级行政区界线、国界线、省界线，共 8 个 | 第一版 `assets/AutoCarto-线符号.xml`，规格见第一版 README §6 |
| `AutoCarto-点符号.xml` | 省级、市级政府驻地，路线点（出发地、战斗地、会议地、会师地、经过点），图例箭头 | 第一版 `assets/AutoCarto-点符号.xml` 与路线 SVG |
| `AutoCarto-基础点形状.xml` | `AutoCarto-marker-circle`、`-square`、`-triangle`、`-star` | R61 新制作，供 `layer_set_symbology` 的点形状使用 |
| 运行时生成 | `AutoCarto-dash-<段长列表>` | `SymbolPacks` 按需生成（`03` §4.6），不进仓库 |

制作和维护规则沿用第一版 README §6 的硬约束：

- 颜色写色号；
- 线符号周期 10000 设计单位；
- 厚度用几何表达；
- 不用 `<Circle>`；
- 多色带时后画者在上；
- `SymbolHead.DataLen` 等计数字段必须正确；
- 点符号按锚点归一到 85% 设计框。

### 1.6 预览

- 样式、版面、内置图层的预览都按宿主描述的 `preview_renderer` 生成（T49），渲染器版本写进 `preview.digest`。
- 版本与 QGIS 版不同，所以 MapGIS 包中的预览全部重新生成，不复用 QGIS 生成的 PNG。

## 2. 版面资源

两个内置版面（四角对齐版式、统计专题版式）本来就是声明式 `*.layout.yaml`，内容可以直接复用。R62 只处理下面几项：

| 项 | 现状 | MapGIS 版 |
|---|---|---|
| 指北针 | `north_arrow.svg: arrows/NorthArrow_03.svg`（QGIS 自带 SVG 库） | 增加 `north_arrow.mapgis_style: <MapGIS 指北针样式名>`，由 M02 第 10 项确认可用样式；QGIS 版忽略这个字段。没有合适样式时，用项目自制的指北针 PNG（不带入 QGIS 的 SVG 文件） |
| 字体 | `font_family: Noto Sans CJK SC`，图例 `Arial` | 名称保留，由 `FontLibrary` 解析；Windows 上缺字体时按 `host.yaml` 的候选回退，回执写明实际字体 |
| 坐标 | 毫米，左上角原点 | 不变；插件内部换算（`01` §7.3） |
| 格网、综述、图例框 | 声明式参数 | 不变；由 `Core/Layout` 计算（T46） |

用户的 QPT 版面不能用于 MapGIS 版。资源页导入 QPT 时，提示改用“从当前工程保存”，或在 QGIS 版中先另存为 `.layout.yaml`。R62 写一个转换脚本，覆盖常见项：地图、标题、图例、比例尺、指北针、图片、矩形；不能转换的项列入报告。

## 4. 内置图层库（R64）

- **数据文件**：`autocarto/data/layers/system/china-admin/*` 是 GeoJSON 和 GeoPackage，与宿主无关。MapGIS 包通过 `layer.yaml` 的相对路径引用同一份文件（同仓库），发行时复制进去。
- **清单**：`default_style` 写的是样式名（省域面、省界、县域面等），MapGIS 包中有同名的 `style.yaml` 资源，名称不变。
- **导入映射**：`data/layers/mappings/{standard,webmap-1m}.yaml` 与宿主无关，原样复用。
- **预览**：按 §1.6 重新生成。
- **China_map 用户导入**：导入逻辑在 Go 中，与宿主无关；坐标系确认流程不变（v7 D11）。
