# 02 工具转换总表

> 由 `tool-mapping.yaml` 生成（同目录）。`tool-mapping.yaml` 是转换的唯一依据：R60 用它生成 MapGIS 工具契约，V70 用它检查覆盖。改动以 YAML 为准，再重新生成本表。

## 1. 口径

| 保真度 | 含义 |
|---|---|
| 等价 | 参数、返回结构与语义和 QGIS 版一致；结果在容差内相同 |
| 近似 | 目的与参数不变，算法或表现有可说明的差异；差异写进 MapGIS 版契约说明 |
| 降级 | 只支持部分参数或部分输入；不支持的部分明确报错或返回说明，不静默忽略 |
| 不支持 | MapGIS 版不提供；从工具包移除，能力清单写明原因 |
| 不变 | Go 内建或独立进程工具，实现不动，只改宿主相关文字 |
| 新增 | MapGIS 模型特有，或 geo 运行时需要的系统内部工具 |

执行位置：**MapGIS 宿主**＝C# 插件在 MapGIS 进程内执行（runtime `mapgis`）；**geo 运行时**＝Go 管理的独立 Python 地理处理进程（runtime `geo`，见 04）；**Go 内建**＝后端进程内（runtime `internal`）；**独立 Python 进程**＝契约里的 `execution.cli`。
