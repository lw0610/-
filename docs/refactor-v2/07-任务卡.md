# 07 任务卡

每张卡可以单独交给一个执行智能体。交付时附上本卡、`README.md`，以及卡中"必读"列出的文档。

通用要求（每张卡都适用，不再重复）：
- 遵守 `README.md` §6 全局执行约束；开工前对照 §3 文件归属表，确认要改的文件没有被进行中的任务占用。
- 完成后写 `docs/refactor-v2/evidence/<任务号>.md`（格式见 `evidence/README.md`），并提交（提交信息以任务号开头，不推送）。
- 命令约定：Go 命令在 `carto_agent/` 下执行；前端命令在 `autocarto-web/` 下执行；Python 命令在仓库根执行


，`$PYTHON_BIN` 指能导入 QGIS 的解释器（见 `build.sh`），`test_*_qgis.py` 每个模块单独一个进程运行。
- 新增兼容层时，在 `carto_agent/defaults/architecture/removal_ledger.yaml` 追加条目（`05` §5 有建议编号），并跑 `go test ./internal/control -run TestCompatLayerRequiresRemovalCriteria -count=1`。

## R00 建立检查点（提交当前重构）

- **目标**：把当前未提交的重构整理成可回滚的提交，作为 v2 基线。
- **必读**：`README.md` §6
- **涉及范围**：git 操作；仅在发现运行数据未被忽略时修改 `.gitignore`。
- **步骤**：
  1. 从当前状态新建分支 `refactor/v2-baseline`，不在 `main` 上提交。
  2. 用 `git status --porcelain` 检查：`autocarto_data/`、`.runs/`、`.tmp-test/`、`tmp_gcc_test/`、`autocarto/tests/golden/.runs/`、`*.db`、`.master_key`、`node_modules/`、构建产物都被忽略；发现未忽略的运行数据，补充 `.gitignore`，不要提交这些文件。

  4. 运行 `./build.sh check`，把结果写入验证记录；失败项只记录，不在本卡修复。
  5. 打本地标签 `v2-baseline`（是否推送由用户决定）。
- **验收**：`git status` 只剩被忽略的文件；标签存在；验证记录写明 `./build.sh check` 的结果与失败项。
