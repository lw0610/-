## 4. 绑定迁移示例

开发运行目录现有 `autocarto_data/config/resource_bindings.yaml`：

```yaml
bindings:
  flow:marching-route/resource_6d294f11b03f: ../数据/底图数据/China_map
```

R31 迁移后（假设项目根为 `/Users/<用户>/研究生/QGIS-agent/enio2`）。旧键已验证：`resource_6d294f11b03f` = `sha256("data_list" + "\x00" + "中国底图")` 的前 12 位十六进制——FLOW.md 中写的类型词是"底图数据"，旧算法用的是映射后的类型 `data_list`：

```yaml
apiVersion: resource-bindings/v2
bindings:
  "flow:marching-route/path:data/中国底图.csv": /Users/<用户>/研究生/QGIS-agent/数据/底图数据/China_map
orphaned: {}
```

迁移前备份到 `autocarto_data/config/backups/resource_bindings-<时间戳>.yaml`。
