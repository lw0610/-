## 2. 表格读取规则（所有表格型资源通用）

### 2.1 CSV

- 编码 UTF-8，允许 BOM；非 UTF-8 报 `FLOW_RESOURCE_INVALID`"CSV 必须使用 UTF-8 编码"。
- 第一条非空行是表头。表头按 `canonical(列名) = 小写(去首尾空白(去 BOM))` 后与 `key` 或 `aliases`（同样规范化）匹配；同一规范列出现两次报"表头列重复"。
- 规范中没有的列保留在 `Extra` 里，不报错（便于用户写备注列）。
- 空行跳过；数据行列数多于表头且多出的单元格非空 → 报错；少于表头 → 缺的列按空值处理。
- 单个表格文件上限 16 MiB。

### 2.2 XLSX

- 按工作表顺序，使用**第一张表头包含全部必填列的工作表**；只校验这一张（不会因为它有错误行就跳到下一张）。没有任何工作表满足 → 报"工作簿中没有包含必填列 …… 的工作表"。
- 公式单元格必须有缓存值；错误值单元格（`#N/A` 等）报错。
- 该规则替代现状：Go 取"第一张能成功解析的表"、Python 只读第一张（D4）。R01/R02 先让两边都按此规则实现，R10 之后只剩 Go。

### 2.3 文件夹型资源的对照表

按 `mapping_files` 顺序取第一个存在的普通文件。对照表中的文件列（`kind: relative_file`）必须是资源文件夹内的相对路径：绝对路径、`..` 越界、符号链接均报错；扩展名必须在 `extensions` 中。

### 2.4 取值规范化

- `kind: boolean`：按 `booleans` 表转换；其他值报"只能填写是或否"。
- `kind: number`：有限数值；违反 `minimum_exclusive` 等约束报错。
- `kind: list`：按 `list_separators` 拆分并去空白；`item_values` 存在时逐项转换。
- `values`：只能取映射表中的键（规范化后比较）；转换为映射值。

## 3. 数据清单的条目

- `path` 为绝对路径时直接使用（体检提示 `FLOW_RESOURCE_PATH_EXTERNAL`）；相对路径按 `01` §7.5 的基准目录解析。
- `type` 为空时按扩展名判定：`vector`/`raster` 表中的扩展名可判定；`list_only`（`.csv`、`.json`）必须显式写"类型"，否则报"请填写类型：矢量或栅格"。
- 文件必须是普通文件，不能是符号链接。
- `.shp` 条目检查附属文件：缺 `required` 中任一个 → `FLOW_DATA_SIDECAR_MISSING`（必需条目为错误，可选条目为警告）；缺 `recommended` → 同码警告。附属文件参与链接指纹（`04` §3）。

## 4. 数据文件夹的扫描

- 递归扫描，跳过隐藏文件/目录与 `skip_dirs`。
- 只识别 `data_extensions.vector` 与 `data_extensions.raster` 中的扩展名；**`.json`、`.csv` 永不识别**（修复 D2：`upstream-manifest.json`、`meta.json` 被当成矢量）。
- 条目名为文件名去扩展名；同名条目（不同子目录）报警告并以相对路径区分。
- `.shp` 同样检查附属文件。

## 5. 版式

- `.layout.yaml`：YAML 可解析；必须有 `required_keys`，`elements` 必须含 `main_map`，元素名只能取 `allowed_elements`（与 `autocarto/tools/system/_shared/layout_compose_impl.py` 的 `ROLES` 一致；两处不一致时以 Python 为准并同步本文件）。完整的数值校验仍由 `layout_compose` 执行时完成，体检只做结构检查。
- `.qpt`：XML 根元素 `Layout`，存在 `id="main_map"` 的项。
- 同一目录同名 `.qpt` 与 `.layout.yaml` 并存 → `RESOURCE_NAME_CONFLICT`（见 `01` §1.1）。

## 6. 样式、符号与文档

- `.qml`：XML 根元素 `qgis`；读取 `layerGeometryType`（0 点、1 线、2 面）写入 `geometry`。
- 符号文件：`.svg` 为根元素 `svg` 的 XML；`.png` 能读出宽高。**不接受 JPEG**（现 `symbols/图例/` 中的 `路线箭头.jpg` 在 R30 删除）。
- 文档：`.md`/`.txt` 必须 UTF-8；`.pdf` 校验文件头 `%PDF-`。

## 7. 文档示例校验

- 用户文档中的资源示例代码块，在代码块前一行加标记：`<!-- resource-example: <类型> -->`，例如：

  ````markdown
  <!-- resource-example: symbols -->
  ```csv
  符号类型,文件,大小,优先级,锚点X,锚点Y
  waypoint,站点.svg,3.5,10,0,0
  ```
  ````

- Go 测试 `TestGuideResourceExamples`（R10）扫描 `docs/*.md`，对每个带标记的代码块按对应类型解析表头与取值（文件存在性不检查），必须零错误。
- 示例里的列名一律使用规范中文列名（`文件`而不是 `SVG路径`），别名只在说明文字中列出。
