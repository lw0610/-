# G4 工具目录与遗留契约

## 实现与依据

`LoadCanonicalDefinitions` 只有 RegistryGovernance 调用；它和 `LoadAuthorityDefinitions` 都仅在正本为空时才使用 11 份 embedded 旧契约。因此删除 `defaults/tool_contracts`、embed 和私有转换函数；两入口直接读取配置的工具正本，空目录保持空，不静默回落到分叉定义。

新增 `TestToolsBelongToToolkits`：公开工具必须有工具包归属，可见工具包唯一，隐藏与可见归属不能混用，不允许引用不存在的工具。实际发现并修复：
- 三个旧样式预设已被 R12 从公开包移除，但定义仍默认公开；现在显式 hidden 并登记到 `legacy-style-presets` 隐藏包，仍供旧回归使用。
- `get_selected_features_info` 同属工程状态与要素筛选，保留工程状态归属；原角色已挂载工程状态包，权限回归通过。

在《新增工具与工具包》中加入 33 个工具域的对照表。`skills` 目录重命名仍按方案留给以后。

## R73 全门禁发现后的补充修复

完整 Python 门禁发现隐藏兼容包缺少 `domain`、`system` 元数据，同时旧 Python 覆盖测试只接受系统域等隐藏包，把已登记的旧预设兼容包排除。现补齐 `domain: 制图`、`system: false`、空 `auto_mount`；保留 `hidden: true`、`enabled: false`，不增加公开权限或自动挂载。

`test_definition_validation.py` 去掉空白名单和按包域猜覆盖资格的分支，分别统计可见/隐藏归属：每工具恰好一个可见包或明确隐藏登记，可见包不得重复，可见/隐藏不得混用。原中文/域/system/hidden/auto_mount 元数据和不存在工具引用检查保留，没有对三个兼容工具写名称白名单。

定向验证：QGIS Python 执行该模块，6 passed、676 subtests passed；`go test ./internal/skill -run '^TestToolsBelongToToolkits$' -count=1` 通过；本次 diff check 通过。两项均使用 enio2 资产和临时运行目录。完整门禁由 R73 统一重跑，本补充不宣称全门禁已通过。
