# R22 数据与样式工具改用句柄

## 结论
完成。数据清单、样式集及单个 QML 样式的工具入口已使用 Go 资源服务交付的句柄；Python 不再查找公共样式集或解析这两类资源表。

## 改动摘要
- 新增 `resource_handle.py`：校验句柄版本、类型、格式、完整条目数量及绝对路径，提供入口路径、条目与 `{id,name,version}` 摘要读取，不接受未解析的名称或路径。
- `data_load_list` 使用 `data_list` 资源参数，直接消费 `path/kind/required/exists`。保留图层复用、筛选、分组、CRS 汇总及严格检查；解析后必需文件消失时仍在加载任何图层前返回失败。`base_dir` 在 Go 解析前应用，Python 不再拼接基准目录。
- `style_set_apply` 使用 `style_set` 资源参数，默认编号在 YAML 中声明为 `style_set.gb-basemap`。消费规范化的 `label_mode`，保留精确匹配优先、别名歧义检查、QML 几何与渲染器检查、字段检查及加载失败后的完整回滚。
- `layer_load_style` 使用 `style` 资源参数；`layer_save_style` 仍使用导出路径。三个读取入口成功结果均带资源摘要和资源警告。
- 删除 Python 的 `read_data_list`、`read_style_set`、`builtin_style_dir`；旧隐藏预设仅保留 R12 登记的私有资产读取。
- 更新工具 YAML、两个工具包说明和黄金新驱动的样式调用。普通与 QGIS 测试均通过 R20 的静态样例或真实 Go 动态 helper 获取句柄。

## 跳过的测试及原因
无。黄金路线只读现有外部底图和渲染器插件，所有输出写入临时目录。

## 与方案不一致之处
无实现偏离。以下旧接口差异按新合同明确调整：
- 样式集属于文件夹型资源，模型传名称、编号或资源目录，不再把对照表 CSV 路径当作独立样式集；对照表可在资源清单的 `entry` 中指定。
- 资源表错误由 Go 返回统一资源诊断，Python 测试不再要求旧本地解析器的错误码。
- 原 XLSX 测试构造缺少共享字符串的 OOXML relationship，已补为合规工作簿；不依赖旧 Python 对不完整工作簿的隐式读取。
- PNG 数据清单样例明确填写 `raster`，类型推断遵从唯一 Go 规则，不保留 Python 额外的后缀推断。

## 修改了涉及范围以外的文件
`autocarto/tests/test_resource_handle.py`：新增句柄辅助模块的边界测试，对应本卡步骤 1。未修改 R20 的 helper 或生成样例。
