# R20 工具资源参数与句柄展开

## 结论
完成。Go 执行引擎统一展开资源参数，Python 测试句柄由生产解析器生成。

## 改动摘要
- ToolParameter/SkillParameter 增加 resource_type/default_resource，加载时校验类型、格式限定和默认编号前缀。
- 默认参数之后、工具验证之前展开名称/编号/路径；仅受信任执行器上下文可传已有句柄，仍按编号重新解析。
- 数据清单 base_dir 覆盖在 Go 文件检查之前生效，不持久化绑定。调用方原始参数不变；工具诊断记录不携带展开后的条目。
- main_deep 创建共享资源库，注入所有运行引擎和 API，内部工具上下文使用同一解析器。
- 新增 16 个跨语言句柄样例及真实 GeoJSON/QML/QPT/符号样例；load_handle 只加载 JSON，动态 resolve_handle 调用生产 Go resolver。
- 无新增兼容层。

## 跳过的测试及原因
无；跨语言实际 QGIS 工具消费由 R22/R23/R71 验收。

## 与方案不一致之处
保留的 base_dir 参数由 Go 解析前消费，避免 Python 再拼接路径造成体检与实际执行不一致。

## 修改了涉及范围以外的文件
- integration/resource-fixture/main.go：为动态生成的 Python 测试资源调用真实 Go 解析器，避免测试重新实现资源解析。
- skill/runtime_build_options.go：把同一解析器传到运行引擎工厂。
