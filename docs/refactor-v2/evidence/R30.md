# R30 场景资源迁入流程包与执行器资源契约

## 结论
完成资源搬迁和执行器契约实现。内置公共资源目录只剩国标底图样式、单色路线样式、四角对齐版式、统计专题版式四项。四个内置流程在三个内置方案下编译通过；行军自动与审阅两项离线验收、路线工具与四项黄金回归通过。

## 改动摘要
- 军标、路线箭头图例和红蓝路线样式移到行军流程的 `resources/symbols`、`resources/styles`，清单随行、资源编号保持；删除路线箭头 JPG，只留 PNG。FLOW 本卡仅改三条资源位置，步骤正文不变。
- 删除 `route-defaults.json` 和执行器默认资源查找、默认引用注入。`route_knowledge` 要求本步显式引用一个路线样式和一个符号资源；符号必须包含知识编译器使用的 `start_flag`、`waypoint`。
- 链接时检查缺少引用、多义引用、缺符号条目，分别输出 `FLOW_EXECUTOR_RESOURCE_MISSING`、`FLOW_EXECUTOR_RESOURCE_AMBIGUOUS`、`FLOW_RESOURCE_CONTRACT_UNSATISFIED`。仅声明未在步骤引用仍判缺失。修改资源后重新链接即可恢复，不调用模型，不改变编译键或编译时间。
- 国标样式对照表删除四个河南特定别名，保留通用规则和 QML。路线样式说明的有效内容并入资源制作指南，再删除旧说明页；明确资源表与工具私有渲染配置的边界。
- 不为中国底图 CSV 增加 manifest，以保持 R31 已使用的路径绑定键。
