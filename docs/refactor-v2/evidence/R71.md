# R71 体检—执行一致性契约测试

## 范围与断言

- Go `contract_test.go` 覆盖八类资源的显式覆盖、精确管理读取、条目路径、数据清单顺序/数据文件夹扫描顺序，以及八类错误资源不能生成句柄。
- 四类表格资源分别对英文 CSV、中文 CSV、第一张说明页的 XLSX 比较实际交付条目，验证布尔、数字、列表、字段标注、路线样式编号/参照编号和符号大小。无表头的单样式、版式和文档不做无意义的表头组合。
- 样式集和符号集覆盖相对越界、绝对路径、符号链接；数据清单覆盖必需/可选 shapefile 缺 `.dbf` 与 `.prj` 的错误/警告区别。
- 新增四个带说明页 XLSX 资源，`TestResourceHandleFixtures` 用生产 Go 解析器生成 `contract-*-xlsx.json`。Python 只读取 Go 句柄；动态坏资源也交给 Go 命令检查，没有在 Python 解析资源表构造句柄。
- 独立 QGIS 七项测试实际加载矢量与栅格、应用单样式及样式集、设置标注、读取符号文件/大小、导入 QPT、执行 YAML 排版和绘制路线。逐项比较文件集合、顺序、标注字段、样式编号和符号路径。链接后改坏原数据清单并切换工作目录，工具仍按交付条目与绑定目录加载。
- `data_folder` 的交付条目通过通用数据加载工具逐项执行；文档按交付文件读取。现有协议没有专用的文件夹或文档 QGIS 工具，未虚构此类入口。
