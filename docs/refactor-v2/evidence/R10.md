# R10 资源格式规范单一来源

## 结论
完成。八类资源的类型词、扩展名、列名与别名、取值、默认值、列表分隔符、唯一性规则和对照表候选均由嵌入的 `resource_formats.yaml` 定义。

## 改动摘要
- 新增格式规范与自检接口，Go 解析器、资源库分类、流程类型词、执行器对照表定位共用规范。
- CSV 允许短行与空白尾列，保留额外列，拒绝非 UTF-8、重复表头及有效额外单元格。
- XLSX 选择首个必填表头匹配工作表，仅验证该表；拒绝错误单元格和没有缓存值的公式。
- 规范化布尔值、列表、数值和枚举；校验数据名、样式图层名、符号类型、事件类型、路线拓扑/阵营展开组合及预设引用唯一性。
- 版式按格式规范检查必需键和元素；文件夹同名数据以相对路径区分并提示。
- 新增 `GET /api/resources/types`，为前端提供类型词来源。
- 文档 CSV 示例添加 `resource-example` 标记，并由 `TestGuideResourceExamples` 使用真实表格解析器验证。

## 跳过的测试及原因
无。

## 与方案不一致之处
- 规范 YAML 位于 `resource/formats/`；Go 嵌入与访问函数在资源包的 `formats.go`，避免无必要子包及循环依赖。
- XLSX 资源层额外读取已缓存的原始工作表 XML 检查公式缓存，不修改共享 XLSX 读取器，避免影响运行产物导入。

## 修改了涉及范围以外的文件
- 既有资源测试的最小版式夹具补齐规范必填的 `fonts_mm`；并非放宽验证。

## 遗留问题与后续任务需要知道的事
