## 结论

## 改动摘要
- 版式声明与 QPT 模板分别消费 `layout:layout_yaml` 和 `layout:qpt` 句柄，删除 Python 按资源名或路径查找的入口。
- 路线绘制使用 `route_style` 句柄，YAML 默认资源为 `route_style.mono`；保留数据集显式 `style_id` 优先、参照样式及自动线宽。规范化条目的空线宽为 `null`，工具按未设置处理。
- 专题点的 `symbols` 可接收显式符号资源；省略时仍使用运行数据集的 `symbol_mapping.csv`。符号图例说明来自资源 `description`，不再读取私有配置里的场景标签映射。
- 图例附加项使用 `legend_symbols` 与 `symbol_type`，仍支持调用者明确提供的 `image_path`。删除 `include_military_arrow`、默认图片回退和 `autocarto/resources/legend_arrow.jpg`。
- `visual_presets.py` 只把规范化句柄条目转成绘图配置；删除默认公共资源指针、资源对照表解析及模块导入时的默认资源读取。渲染器私有配置仍从工具 `assets` 读取。
- 知识编译必须接收路线与符号句柄，将选中符号复制进六表数据集。不同子目录中的同名符号不会互相覆盖。`symbol_mapping.csv` 追加 `description`；原列、其他五表和符号字节保持回归一致。
- Go 执行器通过 `Handle()` 交付资源。知识智能体仅接受后端作用域已链接的句柄编号，忽略输入中的伪造路径；可信编译调用加 `WithInternalHandles` 标记。
- 知识审阅保存后端生成的必要资源作用域（流程目录、锁与路线/符号快照），恢复时核对 Session、资源编号与类型。缺失作用域或跨会话均明确失败，不回落到默认资源。运行快照保持冻结，是否重新链接由 Controller 恢复门禁决定。
- 兼容层 `legend_legacy_layer_properties` 已登记：只读识别旧图层属性用于清理，不再写入或读取旧默认图片。

## 与方案不一致之处
无目标偏离，以下兼容差异按新合同落实：
- 无 `main_map` 的纯标签 QPT 在 Go 资源体检阶段拒绝；测试从旧“允许标签模板”改为“明确拒绝且不改工程”。自定义地图编号的模板仍保留规范要求的主地图，再验证指定自定义地图的范围操作。
- 旧黄金六表没有符号说明，原代码用场景标签常量补中文。黄金及行军配方改为显式选择军标资源，从其说明恢复相同图例，不修改基线、不引入隐藏回退。
- Python 数据集符号 CSV 仍可读取；它是运行产物，不是公共资源解析入口。

## 修改了涉及范围以外的文件
- `autocarto/knowledge/compiler.py`、`vocabulary.py`、`validator.py`、`extraction.py`：去除模块导入时的隐式公共资源依赖，把句柄实际传到六表和符号复制逻辑。
- Go `deepagent/knowledge_agent.go`、`knowledge_review.go`、`knowledge/executor` 相关测试及 `knowledge/review_types.go`、`review_store.go`：持久化可信资源作用域，验证 checkpoint/resume 和实际 Skill Engine 交付；只改工具入口无法完成审阅恢复链路。
- `deepagent/statistical_skill_integration_test.go`、`websocket/integration_flow_qgis_test.go`：新资源参数要求测试构造的 Engine 注入资源服务；WebSocket 编译器与 Engine 共用同一 Library。
- `integration/acceptance/main.go`、Python `tests/integration/acceptance/qgis_worker.py` 及场景配方：实际传递 StepRequest 的 Go 资源句柄与 authority 参数定义；worker 按本步资源引用选择句柄，不解析 CSV、不猜文件路径。
- 人口密度验收包 `resources/data/输入清单.csv`：CSV 数据必须显式声明矢量类型，对齐资源格式规范。
- `test_resource_handle.py`：补充图例符号选择、互斥参数和非法尺寸验证。
