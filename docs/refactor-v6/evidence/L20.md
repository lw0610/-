# L20 资源收敛、拆分与迁移

状态：已实现并通过资源定向测试，2026-10-28。

公共资源格式与扫描仅提供 `style` 和 `layout`；旧 `data_list/data_folder/style_set/route_style/symbols/doc` 不再通过公共名称或工具资源参数解析。旧格式描述保留于 `legacy_formats.yaml`，供迁移及历史快照测试读取，已登记删除台账。

内置库为 11 个独立样式（省域面、县级城市驻地、铁路、高速公路、国道、省界、河流线、河流面、县域面、市域面、地级城市驻地）与 2 个版面。每项独立目录含主文件、resource.yaml、preview.png、preview.digest。样式有 geometry/label_field/description/tags/source；声明式与 QPT 版面本地提取纸张、方向与元素。QML 符号原文没有重绘。

原始资产完整备份为 `builtin-resource-v5-backup.tar.gz`；逐项说明见 `builtin-resource-migration.json`。运行时迁移映射正本位于 `autocarto/resources/migrations/v6.json`，Library.LegacyMigrationItems 合并内置和用户迁移报告，流程转换器不写死国标名或样式数量。

用户迁移先原子完成整库备份 `<home>/.backups/resources-v5`，再拆分旧样式集，名称为“原样式集名-图层名”；冲突加（2）等后缀。旧原件移到隐藏归档，报告保留旧名、新名和新位置。单元失败回滚、已完成单元分段记录；重复执行不重复创建。用户流程的资源另有完整 `.resources-v5-backup`，转换错误时不删原件。迁移专用 ReadLegacyContent 仅依本库报告读取受控隐藏原件，CSV 原文含未知列全部保留，XLSX 首工作表全部列转 CSV，参考 MD/TXT 原文回填；无法读取的非文本格式明确报告，原件保留。

路线与符号预设迁入 home/presets/route-cartography，CSV/XLSX 规范化为私有 CSV；内置红蓝对比、军标和图例已迁入路线工具 assets。

导入只接受样式/版面；文件夹逐个导入，批量任一成员无效则回滚本批新增资源，避免前端只见失败而库中留下半批。内置和用户名称跨类型唯一；复制默认生成唯一“（我的）”名称。编辑元数据保持 ID，改名接口返回对旧正文名称的影响提示。替换有备份；导出 ZIP 拒绝覆盖已有文件。flow.lock 支持新 deps/ 路径，旧 resources/_deps/ 仅兼容迁移；DocumentFormat 用于区分旧指南和新正文。

验证：`go test ./internal/resource -count=1` 全包通过；最终 resource/skill/control/API 资源定向见 `resource-logs/v6-resource-freeze-go.log`。新增测试覆盖完整备份、重复执行、失败回滚、同名冲突、元数据稳定身份、ZIP、QPT 本地元数据。所有测试使用临时目录；没有运行真实用户 autocarto_data 的迁移。
