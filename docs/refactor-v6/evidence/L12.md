# L12 内置流程与旧格式迁移

## 内置内容
四份内置主文件改为 FLOW.md（版本 5.0.0）：行军路线图逐字采用规范 05 §1；统计专题图、交通线路图、通用数据成图改为自由业务说明，保留数据优先级、适用范围、字段/统计口径、制图要求、默认纸张、成果与实际质量核对约束。没有固定角色、资源文件路径或工具英文参数。

删除旧 GUIDE.md 及流程 resources/。数据清单要点写入正文；八种底图需求以自然表格说明。国标样式拆成独立样式由资源泳道管理；路线样式/符号迁工具预设。删除前的完整原资源备份及迁移映射由资源泳道写入 builtin-resource-v5-backup.tar.gz 和 builtin-resource-migration.json。四份 flow.lock 只含 style/layout，并附自由文档格式标识。

## 自动转换
v4 旧流程与 v5 结构化 GUIDE 由迁移专用解析器转换为自由文字。角色指派不继续执行；条件、默认值、能力描述、成果及未知补充章节保留为普通说明。旧数据清单 CSV/XLSX 的名称、类型、类别、字段、说明及未知业务列（如年代、精度、用途）转写成正文；仅路径/绑定/旧执行定位列剔除并在报告列出，不把原文件路径当运行约定。旧参考文档正文并入补充说明。本地包资源和旧公共资源均覆盖；公共内容通过资源库受控 ReadLegacyContent 读取隐藏迁移原件，以旧明确 ID 优先，兼容正文别名。外部路径不访问，报告需要检查。

转换前完整保存 FLOW.md.bak/GUIDE.md.bak，冲突时不覆盖旧备份；resources 保存在 .resources-v5-backup，迁移记录与 conversion-report.json 保留核对项。样式集及预设名称改写使用 Library.LegacyMigrationItems/MigrateFlowResources 数据映射，不写死业务名称。资源迁移记录在文档发布前落盘，避免重试重复导入。新包标记 flow/v6 防止自由正文被重复解释。

覆盖 v4/v5、旧本地样式集拆分、公开迁移名称映射、旧公共 CSV/参考文档、未知业务列保留、原始数据/旧绑定文件不变、旧 GUIDE 备份、二次迁移无写入，以及恰好含旧标题/字段的新自由流程不转换。

## 限制与差异
外部独立 Markdown 或无旧包证据的目录无法凭相同标题/字段可靠判定新旧，因此原文保留并报告需核对，不强猜后改写；明确 GUIDE 文件与旧 lock/resources 包仍自动转换。新保存的 flow/v6 标识防止后续歧义。

普通 Python 与 QGIS 安装本身未装 pytest；使用仓库已有忽略目录 .runtime/deps 提供测试依赖，无安装/联网。QGIS 回归验证实际矢量数据与样式行为，不是视觉布局截图验收；版面预览和 golden 截图由资源泳道验收。没有运行真实在线模型、公共网络下载或真实用户会话。
