# L23 图层、版面、内联数据与工具预设

状态：已实现并通过真实 QGIS 定向回归，2026-10-28。

layer_load_style 增加 label_field；显式字段先校验再变更，避免失败时污染图层。未指定且原字段不存在则按 NAME/name/name:zh/名称/地名回退；返回实际字段；无可用字段关闭标注并说明。QML 表达式默认保留；显式“无”同时禁用并清除 labeling。增加 layer_load_styles，按输入顺序返回每项成功或失败，允许不同几何样式批量处理。Go JSON Schema 的 x-resource-type 递归解析嵌套 style 名称并保持原始调用记录不含本机完整句柄。

data_load_list 接受 items[{name,path,kind?,required?,layer_id?}]；项目相对路径解析、严格缺失检查、分组、源复用、混合 CRS 保留。layer_id 用于复用数据服务已经加载的在线图层；不重新读取携密钥 URL，结果继续脱敏。旧 data_list 资源参数不再接受。版面工具按实际 QPT/layout_yaml 句柄格式自动转发，名称解析交统一 Go 资源服务。

路线与符号参数改为私有工具预设名称，内置默认行为保持；用户/内置预设同名时报歧义，迁移时自动分配唯一名。支持迁移后规范 CSV，解析限制目录、符号链接与条目数量。红蓝/单色字段逐项对照原句柄一致。

运行目录删除 style_set_apply/style_set_export YAML、style_sets handler、旧样式集执行与导出模块。必要字体和选层 helper 已移入独立共用模块。旧实现仅冻结在 tests/support/legacy_style_* 作为历史渲染对照，不由生产代码导入；守卫防止重新暴露旧入口。golden 新路径使用 layer_load_styles，保留 v5 oracle 比对。
