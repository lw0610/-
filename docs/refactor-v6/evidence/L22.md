# L22 样式与版面资源界面

## 结论
完成。最终整体验证见 L50/L51。

## 改动摘要
- 仅样式/版面两个页签；以真实 QGIS 缩略图展示，可放大。
- 几何、来源和名称/标签/说明筛选；资源详情显示元数据及引用流程。
- 用户资源支持重命名、说明/标签编辑、替换、导出、删除；替换和删除先显示引用。
- 单文件导入可命名，文件夹批量逐项导入；多个图层保存为多个独立样式。
- 去掉版本展示、覆盖内置和旧资源类型入口。深色模式和选中颜色已实屏检查。
