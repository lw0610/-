# L10 后端：自由流程文档

## 目标与实施
程序只读 YAML 元信息，以及正文中精确名称对应的样式、版面引用。GuideDoc 只保留 meta/body/resources/diagnostics；任意标题、表格、编号做法均作为完整正文提供给模型。删除 v5 数据表、图层处理、信息表单、制作阶段、成果检查解析；转换专用 AST/table 代码移至 convert_markdown.go。

保留 `/api/guides` 与 `guide_md` JSON 字段兼容现有 HTTP 契约，界面称“流程”。新增 GET `/api/guides/{id}/context` 与 `GuideStore.ReadContext`，供选定流程直接读取全文；附带已解析样式、版面的类型、几何、说明、标注、纸张、方向及元素摘要。全部为本地读取，无模型或在线请求。能力后端删除 DataPreview。

## 锁定、保存、导入与导出
新保存以 FLOW.md 为主文档；兼容读取旧 GUIDE.md，保存前保留原文件为 GUIDE.md.bak；已有不同备份不覆盖，追加编号备份。flow.lock 只保留正文引用的 style/layout；资源副本在 deps/<id>/。导出只写 FLOW.md、flow.lock 与引用的视觉依赖；旧 include_data_files 参数仅兼容接收，true 也不打包数据或历史备份。导出写入稳定流程编号，避免 ZIP 文件名改变流程身份。

flow.lock 增加可选 document_format: flow/v6（资源泳道提供字段）。新建、保存、复制、导出、导入和旧包转换完成后均保留该标识；启动迁移跳过已标识文档。收紧未标识 v4/v5 识别。外部独立 Markdown、没有旧 lock/resources 证据的目录即使恰好使用旧标题和字段，也原文保留并提示核对；GUIDE 文件及有明确旧包证据者才进入转换。单独出现“步骤”“适用任务”等标题不触发转换。回归覆盖正文故意使用旧步骤字段，经复制、导出、导入、启动检查后全文仍不变。

## 提示与回归
只保留 FLOW_META_MISSING、FLOW_RESOURCE_NOT_FOUND、FLOW_RESOURCE_AMBIGUOUS、FLOW_ROLE_MENTION、FLOW_PATH_MENTION 五类轻提示，各有正反测试；不因提示阻止保存。规范 05 正文零提示。HTTP context、停用保护、保存引用锁定、隔离导入、篡改/路径越界拒绝、锁定身份与内置只读、GUIDE 备份均保留回归。

## L40 同泳道清理
