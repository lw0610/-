# L21 独立 QGIS 资源预览

状态：已实现；13 个内置缩略图实际渲染并已写入资产目录，2026-10-28。

系统隐藏工具 resource_preview 在 2026-10-28 用户反馈后调整为两种预览：默认通过 QGIS 原生符号接口展示样张与分类图例；可选克隆当前工程图层至私有工程，查看样式作用在真实数据上的效果。单一符号为 960×520；多类别逐项显示符号、名称和比例尺条件，超过 48 项明确说明截断。栅格显示实际颜色节点；无法独立展示的栅格样式提示选择图层，不伪造梯度数据。QPT 和声明式版面继续通过真实布局实现渲染，宽度提升为 1600 像素。工具不进入用户任务公开发现。

导入/从工程保存/替换/元数据变化后后台检查摘要并生成。未连接时 GET 预览返回 SVG 占位与 pending 状态；后台等待连接。显式离线重建持久化 .preview-pending，重启后仍会补生成。HTTP 预览只读取按稳定 ID 解析出的安全路径，拒绝符号链接；query entry 不能选外部文件。

preview.png/preview.digest 不参与内容摘要。预览戳额外记录 qgis-symbol-legend/v2，旧图自动失效，资源身份不变。渲染完成重新核对内容 digest，过期结果不发布；PNG 校验通过才原子替换。内置原文件始终只读：包括强制重建一个已有内置预览，仍写用户 .previews/<id>/<digest>，读取优先有效用户缓存。预览戳原子写，离线请求标志生成成功后清除。

实际图层预览通过 POST /api/resources/by-id/{id}/preview-layer 提交 instance_id 和 layer_id，路径由后端分配。图片只作为本次响应返回，不覆盖符号缩略图。几何、字段、有效数据和可见比例尺不匹配时返回具体原因；名称字段回退共用正式样式应用的 helper，表达式保留。关闭/取消会清理临时目录，迟到的渲染不得重建该目录。预览不改变原图层样式、选择状态和工程 dirty 状态。

验证：真实 QGIS-LTR 独立进程成功渲染全部 11 样式+2 版面；抽查省域面、河流线、版面图片。test_resources_v6_qgis.py 共 11 项包括样式/栅格/QPT/声明式版面预览，断言用户图层 ID、既有版面、dirty 状态完全不变。Go 覆盖无效 PNG、摘要变化、渲染中并发修改、强制重建只写用户缓存、离线队列跨 Library 实例恢复、HTTP 原始 PNG/占位/路径隔离。日志见 resource-logs。内置 preview.png 文件受原 gitignore 影响，提交时需显式加入。
