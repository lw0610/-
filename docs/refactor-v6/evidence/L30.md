# L30 数据确定与模型工具契约

日期：2026-10-28。所有验证使用临时会话目录；没有读取或改写真正的 autocarto_data，没有调用公网、真实模型或用户 QGIS。

## 已实现

- `data_find.need.what` 以 `{description: ...}` 为主要写法，仍支持 `{category: ...}`；移除 list 与 GuideListResolver。流程资料通过 GuideStore.ReadContext 全文直接注入；未选中时真实 skill 参数为 `{skill: "guide-..."}`。
- `provided` 优先匹配实际本机文件与目录。GeoJSON 有界读取前 16 个要素，Shapefile/DBF 读头部，GeoPackage 使用只读 SQLite 按子图层匹配；也保留 CSV/TSV/XLSX/TIFF 头部核验。目录遍历有深度/条数限制并跳过内部符号链接，不复制或修改原件。
- 当前明确 @ 的工程图层与 provided 优先于历史绑定；名称及几何匹配为 high，类别相关但名称较弱为 confirm。明确提供的单文件核验失败时不会自动改用下载。文件夹缺项仍列真实自动获取候选。
- 计划保留 `layer` 为工程图层 ID，新增 `layer_name` 展示名称、`style`、`geometry`。用户来源保留原路径，GeoPackage 带 `|layername=`；用户文件夹选项保留 find_id/choice，弱匹配必须确认。禁止将用户/工程候选冒充 acquire。计划卡显式选文件属于用户授权；模型猜测的路径不会扩展授权。
- 样式存在性错误 `PLAN_STYLE_NOT_FOUND`；流程引用样式没有图层使用时返回非阻塞 `PLAN_FLOW_STYLE_UNUSED` 警告，保存在 Snapshot.Diagnostics。
- 嵌套 JSON Schema 完整经过 Tool → toolcontract → skill registry → adapter → Eino ToolInfo；what 的 properties/oneOf、provided items、计划 data/steps 等均实际可见，不只修改 YAML 文案。
- 错参返回中文说明、明确路径、正确示例和剩余次数；同一上下文连续第三次 data_find 参数错误为终止错误，越过普通工具错误映射停止 ADK 回路，并记录失败 OnToolEnd。正确参数可在前两次纠正。
- planexec/flowrun 使用流程全文，不再读取固定章节或把逐行数据清单合并到执行输入。
