# 02 样式与版面库规范

## 1. 只有两类资源

| 类型 | 文件 | 说明信息 | 用途 |
|---|---|---|---|
| **样式** | 单个图层的 QML | 名称、适用几何（点 / 线 / 面 / 栅格）、标注字段说明（如“NAME：名称”，无标注写“无”）、说明、标签、来源 | 给某个图层套用符号与标注 |
| **版面** | QPT 模板，或现有声明式 `.layout.yaml` | 名称、适用纸张与方向、包含的元素（标题、图例、比例尺、指北针、说明栏等）、说明、标签、来源 | 生成打印版面 |

两类资源都在流程正文中以 `「名称」` 引用，工具按名称加载；名称在资源库内唯一（内置与用户合计）。

## 2. 存放

| 范围 | 位置 |
|---|---|
| 内置 | `autocarto/resources/system/styles/<名称>/`、`autocarto/resources/system/layouts/<名称>/` |
| 用户 | `<AUTOCARTO_HOME>/resources/styles/<名称>/`、`<AUTOCARTO_HOME>/resources/layouts/<名称>/` |

每个资源一个目录：资源文件、`resource.yaml`（沿用 `resource/v1` 清单，类型只允许 `style`、`layout`）、`preview.png`。

## 3. 预览

| 类型 | 生成方式 |
|---|---|
| 样式（点、线、面） | 用 QGIS 以该 QML 渲染一组示例几何（面：两三个相邻多边形；线：几条曲线；点：几个点），标注字段填示例文字，输出约 480×270 的 PNG |
| 样式（栅格） | 渲染色带或分类图例 |
| 版面 | 用 QGIS 生成一页：QPT 直接加载；`.layout.yaml` 走现有排版工具；主图用内置的简化中国省界作为占位，标题、说明栏用示例文字；输出宽约 600 的 PNG |

- 新建 QGIS 端工具 `resource_preview`（不修改当前工程，不加载到工程图层树）。
- 导入、从工程保存、替换文件时生成；文件摘要变化时重新生成；未连接 QGIS 时显示占位图，连接后在后台补生成（README §8 第 5 项）。
- 内置资源的预览随程序附带（生成后提交到仓库）。

## 4. 导入与从工程保存

- **导入**：接受 `.qml`、`.qpt`、`.layout.yaml` 文件或包含它们的文件夹，自动识别类型；名称默认取文件名，与已有名称冲突时提示改名（批量导入时自动加“（2）”等后缀并列出）。
- **从当前工程保存**：
  - “保存图层样式”：选择一个或多个图层，每个图层保存为一个样式；名称默认取图层名；适用几何与标注字段从图层与 QML 自动识别。
  - “保存版面”：选择一个打印版面，保存为 QPT（沿用 v3 的主图标识处理）。
  - 删除“保存为样式集”。

## 5. 相关工具调整

| 工具 | 调整 |
|---|---|
| `layer_load_style` | 增加可选参数 `label_field`：给出时把 QML 中的标注字段替换为该字段；未给出且样式的标注字段在图层中不存在时，依次尝试 `NAME`、`name`、`name:zh`、`名称` 等常见名称字段，返回实际使用的字段；都没有时不标注并给出警告 |
| 新建 `layer_load_styles` | 一次套用多组“图层 → 样式（可带 `label_field`）”，返回逐项结果（README §8 第 6 项） |
| `style_set_apply` | 删除（样式集取消）；内置流程改为逐层套用或用 `layer_load_styles` |
| 版面工具（`layout_compose`、`import_layout_template`） | 参数接受版面名称，按版面文件格式分别处理（`.layout.yaml` 走 `layout_compose`，QPT 走模板导入），调用方无需区分 |
| `data_load_list` | 不再接受“数据清单”资源；改为接收内联列表 `items: [{name, path}]`，供数据服务返回的多个图层一次加载 |
| `route_draw`、`route_points_build`、`marching_route_compile_dataset`、`layout_set_legend_style`、`layout_compose` 的符号参数 | 路线样式与符号参数改为“工具预设名称”（§6），默认值不变 |

## 6. 其他资源类型的去向

| 原类型 | 去向 | 说明 |
|---|---|---|
| 样式集（如“国标底图样式”） | 拆成单个样式 | 对照表每一行成为一个样式：名称取“图层”列（省域面、县级城市驻地、铁路、高速公路、国道、省界、河流线、河流面、县域面、市域面、地级城市驻地，README §8 第 2 项）；“标注字段”写入样式说明；“别名”写入标签。用户样式集同样拆分，名称为“<样式集名>-<图层>” |
| 数据清单、数据文件夹 | 取消 | 需要哪些图层写在流程正文里；数据在运行时确定（`03`） |
| 路线样式 | 路线工具预设 | 内置“单色”已在 `autocarto/tools/system/route-cartography/assets/resources/styles/`；行军路线图的“红蓝对比”迁入同一目录；用户流程中自带的路线样式迁入 `<AUTOCARTO_HOME>/presets/route-cartography/styles/` |
| 符号（军标、图例等） | 路线工具预设 | 迁入 `autocarto/tools/system/route-cartography/assets/resources/symbols/`；用户流程自带的迁入 `<AUTOCARTO_HOME>/presets/route-cartography/symbols/` |
| 参考文档 | 取消 | 内容写进流程正文 |

- 预设不在资源库界面显示，由工具按名称查找（内置与用户预设名称唯一）；流程正文中写“路线样式用‘红蓝对比’”“专题点用‘军标’符号”即可。
- 迁移前完整备份原资源目录；迁移可重复执行；每个被迁移项在迁移报告中列出新位置。
- `internal/resource/formats/resource_formats.yaml` 只保留 `style`、`layout` 两类供资源库使用；旧类型的解析只保留给迁移程序，并在 `carto_agent/defaults/architecture/removal_ledger.yaml` 登记删除条件。

## 7. 资源库界面

| 区域 | 内容 |
|---|---|
| 页签 | 样式、版面 |
| 筛选与搜索 | 样式按点 / 线 / 面 / 栅格筛选；内置 / 用户；按名称、标签、说明搜索 |
| 列表 | 缩略图网格，图下显示名称与适用几何（或纸张） |
| 详情 | 大图预览；说明信息；“被哪些流程引用”；操作：重命名、编辑说明与标签、替换文件、重新生成预览、导出、删除（用户资源，被引用时提示） |
| 入口 | 导入；从当前工程保存（图层样式 / 版面） |

资源库作为“流程”页中的一个入口保留（与 v3、v5 相同位置），也可以在流程详情的“引用的样式与版面”中直接点开。
