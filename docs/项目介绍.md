# 项目介绍

AutoCarto 把自然语言制图任务、智能体和 QGIS 工具连接起来。当前开发副本为 `enio2`，原 `Eino` 保留。当前设计见 [v6 方案](refactor-v6/README.md)，验证范围见 [执行状态](refactor-v6/evidence/00-执行状态.md)。

## 流程、资源、数据与计划

流程是一份 `FLOW.md`，用自然语言写清需要什么图层、如何处理、使用什么样式和版面、交付什么成果。正文可自由组织，程序只解析头部与 `「名称」` 形式的样式/版面引用，其余交给模型理解。流程里不放数据、不指定角色、不写工具参数。

资源库只有两类：QML 样式，以及 QPT/声明式版面。每项有预览和说明；样式说明适用几何与标注字段，版面说明纸张和元素。内置与用户资源名称唯一，内置只读。路线样式、军标和图例是工具预设。

数据每次运行确定。优先用本次对话明确给出的文件、附件、工程图层，其次按用户指示复用会话或记忆；文件夹交给数据服务按名称、类别和实际几何匹配。符合要求的工程图层可直接复用，处理产物来自对应步骤，剩余缺项才获取。用户原文件保持只读，计划卡列出来源、理由和需要确认的匹配。

制图计划属于一次任务：包含事实、默认值、假设、数据、步骤、能力和产出。模型提出计划，系统确定性校验引用和能力、核验数据与资源后保存版本。用户在同一张卡里查看来源和样式预览、修改选择，或直接在对话中要求调整。

## 从对话到结果

直接描述任务，可添加文件或文件夹、用 `@` 选工程图层、用 `/` 指定流程。明确指定流程时系统读取全文并附资源摘要，模型不需要猜文件路径。

简单查询、加载和样式调整可直接委派；适用流程、需要取数或多步骤任务先提出计划。Plan 只读与提计划，Build 执行同一计划。需要确认时点“开始”；执行与联网继续遵守现有设置，不新增每会话下载授权。

执行器按能力选择角色，缺少普通能力可在本次运行临时补齐。数据获取与路线知识抽取是系统能力，不依赖用户给角色起的名字。工具包由开发人员维护，用户方案文件不会因临时分配被改写。

常规步骤失败重试一次，仍失败则交给模型修订未完成部分或等待用户决定，最多三次修订。工具参数结构完整传给模型，格式错误提供可纠正说明；前期连续无效参数受到限制。每步检查真实回执和产出，不能把“调用过”当成“制作成功”。

任务与过程仍在一个区域，文件独立。下载总量已知时显示百分比，否则显示已下载量、速度和阶段。同一产物修正后替换，文件区与实际结果保持一致。

## 数据服务

`data_find` 是本地确定性查询，不联网、不调用模型。`provided` 接收文件或文件夹，匹配 GeoJSON、Shapefile、GeoPackage 等实际元信息；不确定项标“请确认”，不能匹配的项保留获取候选。

`data_get` 仅由系统获取能力或计划执行器调用，使用真实候选编号，核验后入数据仓并登记来源。兜底下载必须通过 `data_register` 登记。来源手册、范围、许可、选择和排除理由随结果保留。

联网策略默认 direct，仍受用户设置、扩展服务状态和凭据约束。公开网络和在线模型是否能完成具体任务，不能用离线脚本验收代替。

## 管理、迁移与恢复

流程页只有一页正文、引用资源预览和具体提示。用户流程可编辑、导入、导出、复制、停用、删除。保存不调用模型，不提供重新编译。旧 GUIDE.md 和结构化 FLOW.md 备份转换；旧资源同样先备份再迁移，报告说明新位置，重复执行不重复搬移。

样式/版面可导入单文件或文件夹，也可从 QGIS 工程保存。多文件、多图层分别成为独立样式。导入或替换后在独立 QGIS 工程生成预览，不修改当前工程；未连接时补生成排队。详情显示引用流程，修改时明确影响。流程包只携带被引用样式与版面，不携带任务数据。

```text
enio2/
├── autocarto/
│   ├── tools/system/          工具实现与路线预设
│   ├── skills/system/         能力手册
│   ├── flows/system/          内置 FLOW.md
│   └── resources/system/      样式、版面及预览
├── carto_agent/               Go 数据服务、计划、执行与本地接口
├── autocarto-web/             Web 界面和 Tauri 桌面端
├── autocarto_data/            项目内本机配置、数据仓、会话、流程、资源
└── docs/                      方案、编写说明与验证记录
```

会话 `plans/` 保存计划版本，`flows/<运行编号>/run.json` 保存执行快照、回执和结果。恢复时核验原文、能力和资源，旧运行记录保持只读可查。快照不备份外部数据字节。

开发仍可在 `autocarto-web/` 执行 `npx tauri dev`，自动构建 Go 后端；`./build.sh dev` 另负责插件部署。默认路径相对固定项目根。完整命令见 [README](../README.md)。日常门禁为 `./build.sh check`；[流程编写指南](制图指南编写指南.md)与[资源制作指南](资源制作指南.md)说明使用方式。
