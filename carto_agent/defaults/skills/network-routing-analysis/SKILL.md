# 路网分析与最短路径计算

## 概述

本 skill 提供基于路网的空间分析能力，包括最短路径、服务区和可达性计算。

## 前置条件

- 路网线要素图层已加载（需具备拓扑连通性）
- 路网使用投影坐标系
- 如需时间成本计算，路网需包含速度或成本字段

## 工作流步骤

### 1. 路网准备

- 确认路网图层的线要素连通性
- 检查速度/成本字段是否存在
- 确认坐标系为投影坐标系
- **判断标准**：路网几何有效，CRS 为投影坐标系

### 2. 选择分析类型

- `shortest_path_point_to_point`：两点间最短路径
- `shortest_path_point_to_layer`：点到图层最短路径
- `shortest_path_layer_to_point`：图层到点最短路径
- `service_area_from_point`：单点服务区
- `service_area_from_layer`：多点服务区
- **判断标准**：分析类型匹配需求

### 3. 参数设置

- 设置速度字段或默认速度
- 设置成本类型（距离/时间）
- 设置服务区阈值（距离或时间）
- **判断标准**：参数完整合理

### 4. 执行分析

- 调用对应的网络分析工具
- 生成路径或服务区图层
- **判断标准**：输出图层已生成

### 5. 结果输出

- 路径长度和行程时间
- 服务区覆盖范围
- 可达性统计
- **判断标准**：统计结果已输出

## 常见问题处理

- 路径计算失败 → 检查起终点是否在路网附近，路网是否连通
- 服务区形状异常 → 路网存在断头路，检查连通性
- 计算结果不合理 → 检查速度字段单位和值域

## 输出检查清单

- [ ] 路网连通性良好
- [ ] 分析参数正确
- [ ] 路径/服务区已生成
- [ ] 距离/时间统计已输出
- [ ] 结果合理性已验证
