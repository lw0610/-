# 点云数据处理与转换

## 概述

本 skill 提供点云数据（LAS/LAZ）的处理和转换能力，用于生成 DEM/DSM 等栅格产品。

## 前置条件

- 点云文件格式为 LAS/LAZ/PLY 等 PDAL 支持的格式
- 点云数据包含有效的 CRS 信息
- 如需生成 DEM，点云应包含地面点分类（Classification = 2）

## 工作流步骤

### 1. 元数据查看

- 使用 `pdal_info` 查看点云元数据
- 确认点数、CRS、分类信息、范围和点密度
- **判断标准**：元数据完整，CRS 有效

### 2. 数据处理

- `pdal_clip`：按范围或多边形裁剪点云
- `pdal_merge`：合并多个点云文件
- `pdal_convert`：格式转换（LAS/LAZ/PLY 等）
- **判断标准**：处理后点云完整，无数据丢失

### 3. 栅格化

- 使用 `pdal_to_raster` 将点云转为栅格
- 生成类型选择：
  - DEM（数字高程模型）：仅使用地面点（Classification = 2）
  - DSM（数字表面模型）：使用最高点（包含建筑、植被）
- 设置输出分辨率：通常为平均点间距的 2-3 倍
- **判断标准**：栅格已生成，分辨率合理

### 4. 结果验证

- 使用 `raster_info` 检查输出栅格的范围和分辨率
- 使用 `raster_statistics` 检查值域合理性
- 确认无大面积数据空洞
- **判断标准**：栅格完整，值域合理

## 常见问题处理

- 点云无 CRS 信息 → 使用 `pdal_convert` 时指定 CRS，或联系数据提供方确认
- 生成 DEM 有大量空洞 → 点密度不足或地面点分类缺失，尝试增大栅格化分辨率
- 生成 DSM 出现异常高值 → 可能存在噪声点，需先滤波处理
- 合并后点云范围异常 → 检查各文件 CRS 是否一致
- 栅格化速度慢 → 点云数据量过大，先裁剪到目标区域再栅格化

## 输出检查清单

- [ ] 点云元数据已确认
- [ ] CRS 信息有效
- [ ] DEM/DSM 类型选择正确
- [ ] 输出分辨率合理
- [ ] 无大面积数据空洞
