# 栅格代数运算与波段计算

## 概述

本 skill 提供栅格数据的数学运算能力，支持波段计算、指数计算和多栅格代数运算。

## 前置条件

- 输入栅格已加载到工程中
- 多栅格运算时，各栅格的 CRS 应一致
- 已明确计算表达式和预期输出

## 工作流步骤

### 1. 输入检查

- 使用 `raster_info` 确认各栅格的波段数、数据类型和 CRS
- 使用 `raster_statistics` 检查值域范围和 NoData 值
- 多栅格运算时检查范围和分辨率是否一致
- **判断标准**：栅格元数据已确认，CRS 一致

### 2. 栅格对齐（多栅格时）

- 使用 `gdal_warp` 统一范围和分辨率
- 重采样方法选择：连续数据用双线性（bilinear），分类数据用最近邻（nearest）
- **判断标准**：所有输入栅格范围和分辨率一致

### 3. 编写计算表达式

- 使用 `raster_calculator` 编写栅格代数表达式
- 常用表达式示例：
  - NDVI = (NIR - RED) / (NIR + RED)
  - 坡度分级 = slope > 25
  - 高程差 = DEM_A - DEM_B
  - 归一化 = (value - min) / (max - min)
- 波段引用格式：`"layer_name@band_number"`
- **判断标准**：表达式语法正确，引用的图层和波段存在

### 4. NoData 处理

- 明确 NoData 传播策略：默认任一输入为 NoData 则输出为 NoData
- 必要时在表达式中显式处理 NoData 值
- **判断标准**：NoData 策略已确认

### 5. 结果验证

- 使用 `raster_statistics` 检查输出值域
- 确认计算结果合理性（如 NDVI 应在 -1 到 1 之间）
- **判断标准**：输出值域在预期范围内

## 常见问题处理

- 表达式语法错误 → 检查图层名引用格式和波段编号，确认运算符正确
- 输出全为 NoData → 检查输入栅格是否有有效值，NoData 值是否正确设置
- 除法运算出现 inf → 分母可能为零，在表达式中添加条件判断
- 多栅格范围不一致 → 先用 `gdal_warp` 对齐再计算
- 输出数据类型溢出 → 指定输出数据类型为 Float32 或 Float64

## 输出检查清单

- [ ] 输入栅格元数据已确认
- [ ] 多栅格已对齐（如适用）
- [ ] 计算表达式正确
- [ ] NoData 处理策略明确
- [ ] 输出值域在预期范围内
