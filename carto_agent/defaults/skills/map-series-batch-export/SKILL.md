# 地图系列批量导出

## 概述

本 skill 提供基于分幅依据的地图系列批量生成和导出能力，适用于图集制作和区域覆盖输出。

## 前置条件

- 待制图的数据图层已加载并完成符号化
- 分幅依据图层已准备（行政区划/网格/自定义范围）
- 分幅依据图层包含可用于命名的标识字段

## 工作流步骤

### 1. 确认分幅依据

- 确定分幅方式：按行政区划、网格、自定义范围
- 使用 `get_active_layer_info` 获取分幅要素列表和范围
- 确认分幅标识字段（用于文件命名）
- **判断标准**：分幅要素列表和标识字段已确认

### 2. 创建模板布局

- 创建标准布局模板（参考 `print-layout-standard` skill）
- 设置固定元素：图例、比例尺、指北针、标题
- 标题可使用表达式引用分幅标识字段实现动态更新
- **判断标准**：布局模板包含所有必备要素

### 3. 添加鹰眼图（按需）

- 使用 `layout_add_overview` 添加鹰眼图
- 显示当前分幅在全局中的位置
- **判断标准**：鹰眼图正确显示当前范围

### 4. 批量导出

- 遍历分幅要素
- 逐一使用 `layout_set_map_extent` 设置当前分幅范围
- 使用 `export_layout_pdf` 导出每张地图
- 文件命名包含分幅标识（如 `地图_北京市.pdf`）
- **判断标准**：所有分幅均已导出

### 5. 输出清单

- 生成导出文件清单
- 包含文件名、分幅标识、导出状态
- **判断标准**：清单完整，无遗漏

## 常见问题处理

- 部分分幅范围内无数据 → 检查数据图层范围是否覆盖所有分幅，跳过空白分幅或标记
- 比例尺不一致 → 统一设置固定比例尺，或按分幅范围自适应
- 标题未动态更新 → 检查表达式语法，确认引用了正确的分幅标识字段
- 导出文件过大 → 降低 DPI 或简化符号化
- 鹰眼图范围不对 → 检查鹰眼图关联的地图项是否正确

## 输出检查清单

- [ ] 分幅依据和标识字段正确
- [ ] 布局模板包含所有必备要素
- [ ] 每张地图范围正确
- [ ] 文件命名包含分幅标识
- [ ] 导出文件清单完整
