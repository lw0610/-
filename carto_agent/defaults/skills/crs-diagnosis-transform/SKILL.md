# 坐标系诊断与批量转换

## 概述

本 skill 提供坐标参考系统诊断、推荐和按需转换能力。多个有效 CRS 同时存在不等于数据错误；QGIS 可在显示和制图时动态转换。

## 前置条件

- 至少一个图层已加载到工程中
- 用户明确要求转换，或任务需要不能依赖动态转换的空间分析、量算或数据交付

## 工作流步骤

### 1. CRS 状态扫描

- 使用 `get_layers_info` 获取所有图层的 CRS 信息
- 列出各图层 EPSG 代码和投影名称
- 区分 CRS 缺失/无效与“CRS 均有效但不同”两种状态
- **判断标准**：所有图层 CRS 状态已记录

### 2. 转换必要性判断

- 如果任务只是加载、浏览、叠加显示或地图制图，并且涉及的图层 CRS 都有效：只报告差异，依靠 QGIS 动态坐标转换，流程在此结束。
- 只有用户明确要求统一 CRS，或后续算法、面积/距离量算、固定格式交付明确要求共同投影坐标系时，才继续执行转换。
- CRS 缺失或无效时先查明原始 CRS；无法可靠确定时停止并报告，不得猜测后直接定义。
- **判断标准**：已经说明“无需转换”或给出可验证的转换理由

### 3. 目标 CRS 推荐（仅在确需转换时）

- 根据数据范围推荐合适的投影坐标系
- 中国区域常用：CGCS2000（EPSG:4490）、UTM 分带
- 全球数据：WGS84（EPSG:4326）
- 目标 CRS 必须能被 QGIS 解析；不得只传显示名称代替有效的 EPSG、WKT 或 PROJ 定义
- **判断标准**：目标 CRS 已确定且有效

### 4. 执行转换

- 使用 `reproject_layer` 或 `crs_reproject_vector` 执行坐标系转换
- 缺失 CRS 的图层使用 `crs_define_projection` 定义投影
- 仅转换任务所需图层，不因工程中存在其他有效 CRS 就批量转换所有图层
- **判断标准**：转换工具返回成功，且输出图层有效、CRS 有效并与目标 CRS 一致

### 5. 验证结果

- 重新检查转换输出，而不是要求工程内所有图层 CRS 一致
- 确认输出 CRS、数据范围、要素数和位置正确；任何一项无效都不得加载或继续交接
- **判断标准**：所需转换结果有效，数据位置正确

## 常见问题处理

- 转换后数据偏移 → 原始 CRS 定义错误，需先正确定义再转换
- 缺失 CRS 不知道原始坐标系 → 用 `crs_find_projection` 尝试识别
- 转换后面积/距离不准 → 确认目标 CRS 为投影坐标系

## 输出检查清单

- [ ] 所有图层 CRS 已扫描
- [ ] 已判断本任务是否真的需要持久化转换
- [ ] 仅用于显示/制图且 CRS 均有效时，已明确选择 QGIS 动态转换
- [ ] 如确需转换，目标 CRS 可解析且转换理由明确
- [ ] 如确需转换，输出图层及其 CRS 已验证
- [ ] 转换后数据位置正确
