# 条件要素提取

## 概述

本 skill 提供多维度的要素筛选和提取能力，支持属性条件、空间关系和复合条件的灵活组合。

## 前置条件

- 目标图层已加载到工程中
- 已明确筛选条件（属性条件/空间条件/组合条件）

## 工作流步骤

### 1. 图层信息确认

- 使用 `get_active_layer_info` 或按图层名查询图层详细信息，确认字段结构和要素数量
- 了解可用的筛选字段和值域
- **判断标准**：字段结构已了解，条件可构建

### 2. 选择筛选方式

- 简单过滤优先使用 `selection_by_attribute` / `selection_by_expression` 在当前 QGIS 图层上完成，再用 `extract_selected_features` 固化结果
- `extract_by_attribute`：按单字段属性值提取要素
- `extract_by_expression`：按复杂表达式提取要素（支持多字段组合）
- `extract_by_location`：按空间关系筛选（相交/包含/邻近等）
- **判断标准**：筛选方式匹配条件类型

额外约束：

- 不要把尚未出现在 `get_layers_info` 结果中的“猜测图层名”作为后续输入
- 当上一步只是做了选择而没有生成新图层时，下一步应继续针对原图层或选中要素操作，不能凭空假设中间图层已经存在
- 只有在交互式筛选工具无法满足需求时，才回退到脚本或 compute 提取工具

### 3. 组合条件（按需）

- 多条件分步执行：先属性筛选，再空间筛选
- 或使用表达式组合多个条件
- **判断标准**：条件逻辑正确

### 4. 执行提取

- 调用对应提取工具
- 生成满足条件的要素子集图层
- **判断标准**：输出图层已生成

### 5. 结果统计

- 输出匹配要素数 / 总要素数 / 匹配比例
- 确认提取结果符合预期
- **判断标准**：统计结果已输出

## 常见问题处理

- 提取结果为空 → 检查条件表达式语法，确认字段名和值是否正确
- 表达式语法错误 → 字段名用双引号，字符串值用单引号
- 空间筛选结果不符预期 → 检查空间关系类型（相交 vs 包含 vs 在...内）

## 输出检查清单

- [ ] 筛选条件正确
- [ ] 提取结果非空
- [ ] 匹配比例合理
- [ ] 输出图层已命名
- [ ] 统计结果已报告
