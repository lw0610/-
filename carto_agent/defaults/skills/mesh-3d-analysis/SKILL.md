# 网格数据分析与曲面提取

## 概述

本 skill 提供网格（Mesh）数据的分析和提取能力，用于三维曲面分析和时序数据处理。

## 前置条件

- 网格数据文件格式为 QGIS 支持的格式（如 NetCDF、GRIB、UGRID 等）
- 已明确需要提取的数据集或时间步
- 如需栅格化，已确定输出分辨率

## 工作流步骤

### 1. 数据加载

- 加载网格数据文件到工程
- 使用 `get_layers_info` 确认网格图层已加载
- 确认网格结构（顶点数、面数）和可用数据集
- **判断标准**：网格图层已加载，结构信息已确认

### 2. 组件提取

- `export_mesh_vertices`：提取顶点为点图层
- `export_mesh_faces`：提取面为多边形图层
- `export_mesh_edges`：提取边为线图层
- **判断标准**：所需组件已提取为矢量图层

### 3. 栅格化

- 使用 `rasterize_mesh_dataset` 将网格数据集栅格化
- 设置输出分辨率和插值方法
- 选择目标数据集和时间步
- **判断标准**：栅格已生成，值域合理

### 4. 曲面转换

- 使用 `mesh_surface_to_polygon` 将网格曲面转为多边形
- 适用于提取等值面或边界
- **判断标准**：多边形图层已生成

### 5. 时序分析（按需）

- `export_time_series_values`：导出指定位置的时序值
- `export_cross_section_dataset_values`：导出剖面数据
- **判断标准**：时序/剖面数据已导出

## 常见问题处理

- 网格文件无法加载 → 检查文件格式是否受支持，尝试指定驱动
- 栅格化结果有大量 NoData → 输出范围可能超出网格覆盖范围，调整输出范围
- 时序导出数据为空 → 检查时间步索引是否正确，确认数据集名称
- 提取的顶点/面数量与预期不符 → 确认网格层级（多层级网格需指定层级）
- 栅格化分辨率不当 → 参考网格面的平均尺寸设定分辨率

## 输出检查清单

- [ ] 网格数据已正确加载
- [ ] 所需组件已提取
- [ ] 栅格化结果值域合理
- [ ] 时序数据完整（如适用）
- [ ] 输出图层已命名
