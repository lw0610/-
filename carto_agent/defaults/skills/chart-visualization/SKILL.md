# 统计图表可视化

## 概述

本 skill 提供基于 GIS 数据的统计图表生成能力，用于数据探索和成果展示。

## 前置条件

- 数据源图层已加载到工程中
- 统计字段存在且类型正确（数值型或分类型）
- 如需嵌入布局，布局已创建

## 工作流步骤

### 1. 数据确认

- 使用 `get_active_layer_info` 确认数据源图层和字段结构
- 检查字段类型：数值字段用于连续统计，分类字段用于分组
- **判断标准**：字段存在且类型匹配图表需求

### 2. 选择图表类型

- `bar_chart`：柱状图 — 分类数据对比（如各区域面积、各类型数量）
- `scatter_plot`：散点图 — 两变量关系（如面积 vs 人口）
- `vector_layer_histogram`：直方图 — 单变量数值分布（如高程分布）
- `box_plot`：箱线图 — 数据分布特征和异常值（如各区域收入分布）
- `polar_plot`：极坐标图 — 方向性数据（如风向、坡向分布）
- **判断标准**：图表类型匹配数据特征和展示目的

### 3. 参数设置

- 设置 X/Y 轴字段
- 设置分组字段（按需）
- 设置颜色和标题
- **判断标准**：参数完整

### 4. 生成图表

- 调用对应图表工具
- `bar_chart` 返回的主输出是 HTML，同时会提供可直接嵌入布局的 `svg_path` / `picture_path`
- 需要嵌入布局时，优先把返回的 SVG 文件直接交给 `layout_add_picture`，不要再用 `pyqgis_execute_script` 把 HTML 转成 PNG
- **判断标准**：图表文件已生成，且布局嵌入优先使用现成 SVG 资源

### 5. 嵌入布局（按需）

- 使用 `layout_add_picture` 将图表嵌入打印布局
- 调整图表在布局中的位置和大小
- **判断标准**：图表在布局中显示正确

## 常见问题处理

- 图表为空或无数据 → 检查字段名是否正确、是否有 NULL 值
- 柱状图类别过多导致拥挤 → 筛选 TOP N 类别或合并小类为"其他"
- 散点图看不出趋势 → 检查数据量是否足够、是否存在极端值
- 直方图分箱不合理 → 调整分箱数量（通常 10-30 个）
- 图表嵌入布局后模糊 → 提高输出图片分辨率（DPI ≥ 150）

## 输出检查清单

- [ ] 数据字段类型正确
- [ ] 图表类型匹配展示目的
- [ ] 图表标题和轴标签清晰
- [ ] 输出文件路径已确认
- [ ] 嵌入布局后显示正常（如适用）
