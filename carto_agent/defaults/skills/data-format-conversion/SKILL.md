# 多格式数据互转

## 概述

本 skill 提供 GIS 数据格式之间的转换能力，处理各格式的特殊限制并确保数据完整性。

## 前置条件

- 源数据已加载到工程中
- 已明确目标格式和输出路径

## 工作流步骤

### 1. 确认转换需求

- 明确源格式和目标格式
- 支持格式：SHP、GeoJSON、GPKG、DXF、CSV、KML 等
- **判断标准**：源格式和目标格式已确认

### 2. 格式限制检查

- SHP：字段名最长 10 字符，单文件 2GB 限制
- GeoJSON：仅支持 WGS84（EPSG:4326）
- DXF：不保留属性表完整结构
- CSV：仅适用于点要素或属性导出
- **判断标准**：已识别并处理格式限制

### 3. 预处理

- 必要时使用 `reproject_layer` 转换坐标系（如导出 GeoJSON 需转 WGS84）
- 字段名超长时使用 `rename_table_field` 截断
- **判断标准**：数据满足目标格式要求

### 4. 执行转换

- 矢量数据：使用 `data_export_vector` 导出目标格式
- 栅格数据：使用 `data_export_raster` 导出目标格式
- DXF 导出：使用 `export_layers_to_dxf`
- **判断标准**：导出文件已生成

### 5. 验证

- 重新加载转换后的文件
- 检查要素数量、属性完整性和几何正确性
- **判断标准**：要素数一致，属性完整

## 常见问题处理

- SHP 字段名被截断 → 导出前用 `rename_table_field` 缩短字段名
- GeoJSON 坐标系不对 → 导出前先 `reproject_layer` 转 WGS84
- 导出文件为空 → 检查输出路径是否存在，图层是否有要素
- 中文属性乱码 → 指定编码为 UTF-8

## 输出检查清单

- [ ] 格式限制已处理
- [ ] 坐标系满足目标格式要求
- [ ] 导出文件已生成
- [ ] 要素数量和属性完整
- [ ] 输出路径已报告
