# DEM 地形衍生分析

## 概述

本 skill 提供基于 DEM 的地形衍生产品生成能力，用于地形特征提取和可视化。适用于地形评估、选址分析、水文分析前处理等场景。

## 前置条件

- DEM 栅格数据已加载到工程中
- DEM 使用投影坐标系（地理坐标系下坡度计算结果不准确）
- DEM 无明显数据空洞或异常值（如需预处理，先用 `raster_calculator` 填补）

## 工作流步骤

### 1. DEM 质量检查

- 使用 `raster_info` 确认 DEM 元数据：
  - 分辨率（像元大小）：影响衍生产品精度
  - CRS：必须为投影坐标系（米制单位），地理坐标系需先用 `gdal_warp` 重投影
  - 数据类型：Float32/Float64 为佳，整型 DEM 精度较低
- 使用 `raster_statistics` 检查高程范围和 NoData 值：
  - 高程范围是否合理（如陆地 DEM 不应有 -9999 以外的大负值）
  - NoData 值是否正确设置
- **判断标准**：CRS 为投影坐标系，高程范围合理，NoData 已正确标记

### 2. 地形衍生产品生成

根据需求选择衍生产品：

| 产品 | 工具 | 关键参数 | 用途 |
|------|------|----------|------|
| 坡度 | `slope` | 单位（度/百分比） | 地形陡缓评估 |
| 坡向 | `aspect` | 输出 0-360° | 朝向分析、光照评估 |
| 山体阴影 | `hillshade` | 方位角（315°）、高度角（45°） | 地形可视化底图 |
| 粗糙度 | `terrain_ruggedness` | 无 | 地表起伏程度 |
| 地形位置指数 | `terrain_tpi` | 无 | 山脊/山谷识别 |

- **参数推荐**：
  - 坡度：默认输出单位为度，工程应用常用百分比
  - 山体阴影：方位角 315°（西北方向光源）、高度角 45° 为标准设置
  - 多产品生成时建议按顺序：坡度 → 坡向 → 山体阴影 → 粗糙度

### 3. 等高线生成（按需）

- 使用 `raster_contour` 或 `gdal_contour` 生成等高线
- **等高距推荐**：
  - 平坦地区（高差 < 100m）：等高距 5-10m
  - 丘陵地区（高差 100-500m）：等高距 10-20m
  - 山区（高差 > 500m）：等高距 20-50m
- 可同时生成主曲线和计曲线（如主曲线 10m，计曲线 50m）
- **判断标准**：等高线连续无断裂，间距均匀

### 4. 结果验证与统计

- 使用 `raster_statistics` 验证各衍生产品值域：
  - 坡度：0°-90°（度）或 0%-∞（百分比）
  - 坡向：0°-360°（-1 表示平坦区域）
  - 山体阴影：0-255
- 坡度分布统计：平坦（0-5°）/ 缓坡（5-15°）/ 中坡（15-25°）/ 陡坡（25-45°）/ 极陡（>45°）
- 坡向分布统计：北/东北/东/东南/南/西南/西/西北 各方位比例
- **判断标准**：值域在合理范围内，无大面积 NoData

## 常见问题处理

- 坡度值异常大 → 检查 DEM 是否为地理坐标系（度单位导致计算错误），需先重投影
- 山体阴影全黑或全白 → 检查方位角和高度角参数，确认 DEM 值域正常
- 等高线断裂 → DEM 存在 NoData 空洞，需先填补再生成
- 衍生产品出现条带状伪影 → DEM 质量问题，尝试先用 `raster_resample` 平滑

## 输出检查清单

- [ ] DEM 使用投影坐标系
- [ ] DEM 高程范围合理，NoData 正确
- [ ] 衍生产品值域在合理范围内
- [ ] 等高线连续无断裂（如生成）
- [ ] 统计报告已输出
