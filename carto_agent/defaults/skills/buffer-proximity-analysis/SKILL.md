# 缓冲区与邻近性分析

## 概述

本 skill 提供多种缓冲区生成方式和距离计算能力，用于邻近性评估和影响范围分析。适用于服务范围划定、安全距离评估、设施选址等场景。

## 前置条件

- 输入图层已加载到工程中
- 明确缓冲距离值和单位
- 建议使用投影坐标系（米制单位），地理坐标系下缓冲距离单位为度

## 工作流步骤

### 1. 坐标系确认

- 用 `get_active_layer_info` 检查输入图层 CRS
- **坐标系单位判断**：
  - EPSG:4326 / EPSG:4490 等地理坐标系 → 单位为度，1度 ≈ 111km
  - UTM / 高斯-克吕格等投影坐标系 → 单位为米
- 地理坐标系下需先用 `reproject_layer` 转为投影坐标系，再执行缓冲
- **判断标准**：CRS 单位为米（投影坐标系）

### 2. 选择缓冲类型

根据需求选择缓冲方式：

| 需求 | 工具 | 适用场景 |
|------|------|----------|
| 固定距离缓冲 | `buffer` | 安全距离、服务半径 |
| 按字段值变宽 | `variable_width_buffer` | 不同等级不同缓冲距离 |
| 线要素单侧缓冲 | `single_sided_buffer` | 河流一侧保护带 |
| 线要素锥形缓冲 | `tapered_buffer` | 河流上下游宽度渐变 |

- **决策指南**：
  - 所有要素相同距离 → `buffer`
  - 不同要素不同距离（字段控制）→ `variable_width_buffer`
  - 仅线要素一侧 → `single_sided_buffer`

### 3. 执行缓冲

- 设置缓冲距离（正值外扩，负值内缩，仅面要素支持负值）
- 端点样式：round（圆头，默认）、flat（平头）、square（方头）
- 段数（segments）：控制圆弧平滑度，默认 5，精度要求高时增大
- **判断标准**：输出图层几何类型为 Polygon/MultiPolygon

### 4. 融合处理（按需）

- 使用 `dissolve` 融合重叠缓冲区（适用于服务范围合并）
- 融合后面积 = 实际覆盖面积（消除重叠计算）

### 5. 距离计算

- `distance_matrix`：多对多距离矩阵（输出表格）
- `distance_to_nearest_hub`：到最近设施的距离（输出线或点图层）
- 距离类型：直线距离（欧氏距离），单位取决于 CRS

### 6. 缓冲区统计

- 使用 `analysis_point_in_polygon` 统计缓冲区内要素数量
- 输出影响范围内的要素统计

## 常见问题处理

- 缓冲结果异常大 → 检查 CRS 是否为地理坐标系（度单位），距离值是否合理
- 负值缓冲结果为空 → 面要素太小，缓冲距离超过要素宽度
- 缓冲区有锯齿 → 增大 segments 参数值（如 16 或 32）
- 距离矩阵结果量太大 → 限制输入要素数或使用 `distance_to_nearest_hub` 替代

- [ ] 缓冲距离和单位正确
- [ ] 缓冲类型匹配需求
