# 随机抽样与样本选择

## 概述

本 skill 提供空间数据的随机抽样能力，用于统计分析、精度验证和样本采集。

## 前置条件

- 总体图层已加载到工程中
- 已明确抽样目的和数量/比例

## 工作流步骤

### 1. 确认总体

- 确认总体图层和要素数量
- 明确抽样目的（精度验证/统计分析/训练样本）
- **判断标准**：总体信息已确认

### 2. 选择抽样方式

- `random_selection`：随机选择要素（标记选中状态）
- `random_extract`：随机提取要素到新图层
- `random_points_in_polygons`：在多边形内生成随机点
- `random_points_in_extent`：在范围内生成随机点
- **判断标准**：抽样方式匹配需求

### 3. 参数设置

- 抽样数量或比例
- 随机种子（可选，用于可重复性）
- **判断标准**：参数合理

### 4. 执行抽样

- 调用对应抽样工具
- 生成样本图层或选择集
- **判断标准**：样本已生成

### 5. 样本统计

- 输出样本数量和空间分布
- 确认样本代表性
- **判断标准**：样本数量符合预期

## 常见问题处理

- 样本数量不足 → 增大抽样比例或数量
- 样本空间分布不均 → 考虑分层抽样（先按区域分组再各组抽样）
- 需要可重复结果 → 设置固定随机种子

## 输出检查清单

- [ ] 抽样方式正确
- [ ] 样本数量符合预期
- [ ] 样本空间分布合理
- [ ] 输出图层已命名
- [ ] 统计结果已报告
