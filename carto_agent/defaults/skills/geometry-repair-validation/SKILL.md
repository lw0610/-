# 几何修复与有效性验证

## 概述

本 skill 提供矢量数据几何质量的完整检测与修复流程，确保几何数据满足空间分析要求。

## 前置条件

- 目标矢量图层已加载到工程中
- 后续需要执行空间分析操作（叠加、缓冲等对几何有效性敏感）

## 工作流步骤

### 1. 有效性检测

- 使用 `check_validity` 检测无效几何
- 记录无效几何数量、类型和位置
- **判断标准**：无效几何数量和比例已记录

### 2. 自动修复

- 使用 `fix_geometries` 自动修复无效几何（自交、环方向等）
- 记录修复成功/失败的要素数量
- **判断标准**：修复后无效几何数显著减少

### 3. 去重与清理

- 使用 `delete_duplicate_geometries` 去除重复几何
- 使用 `remove_null_geometries` 清除空几何要素
- **判断标准**：无重复和空几何

### 4. 几何拆分（按需）

- 使用 `multipart_to_singleparts` 将多部件几何拆分为单部件
- 适用于需要逐要素分析的场景
- **判断标准**：所有几何为单部件

### 5. 重建索引

- 使用 `create_spatial_index` 重建空间索引
- 提升后续空间查询和分析性能
- **判断标准**：索引创建成功

### 6. 最终验证

- 再次使用 `check_validity` 验证修复结果
- 输出修复报告：修复前后无效几何数量对比
- **判断标准**：无效几何数为 0 或接近 0

## 常见问题处理

- fix_geometries 后仍有无效几何 → 尝试 `grass_v_clean` 进行更深度的修复
- 修复后要素数变化 → 检查是否有要素被合并或拆分
- 空间索引创建失败 → 检查图层是否为可编辑格式

## 输出检查清单

- [ ] 无效几何已检测并记录
- [ ] 自动修复已执行
- [ ] 重复和空几何已清除
- [ ] 空间索引已重建
- [ ] 最终验证通过
