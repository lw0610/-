# 轨道交通站点服务覆盖图

适用于城市地铁、轨道交通站点的服务范围和人口覆盖分析。默认 A3 横向，800 米直线服务半径，导出 PNG 和 PDF；用户明确指定的城市、参数和材料优先。只要求线路分布时省略人口格网和第 3 阶段的服务范围、人口分析，其余图层保持原有先后关系。

本流程不安排质量反馈智能体，不进行额外审图评分或反馈修订循环。制图角色完成排版和文件导出后交付，流程结束。

图层加载统一由当前智能体方案中的数据角色负责。空间分析角色只生成分析结果并交回，制图角色只对已加载图层进行符号化、标注和排版。主智能体按下面步骤交接任务，不把加载工作拆给多个角色。

## 先明确所需图层与加载顺序

下表规定的是数据角色将图层首次显示到地图的顺序，不是读取或计算数据的先后。边界和站点需要提前用于取数、裁剪和缓冲，可以先准备为后台对象或文件，按后文步骤再显示。数据角色从底层向上逐个加载，前一层加载成功再加载下一层，实例中同步显示；人口等底层不必等待全部分析结束。原始全国数据、临时投影、初始缓冲、分区片段、检查结果等无关或中间图层不上图。QGIS 新加载的图层自然在最上面，无需最后再排序或清理。

| 加载先后（从底层向上） | 图层 | 来源与用途 |
|---|---|---|
| 1 | 人口格网 | 约 100 米人口数据，限定真实市域形状，作为最下层背景 |
| 2 | 水域 | 优先使用适用的内置图层，否则自动检索，作为弱化背景 |
| 3 | 河流 | 优先使用适用的内置图层，否则自动检索，作为弱化背景 |
| 4 | 主要道路 | 优先使用适用的内置图层，否则自动检索，作为弱化背景 |
| 5 | 站点服务范围 | 站点缓冲的并集，按市域裁剪 |
| 6 | 区县边界及区名 | 从内置「县域面」或用户数据提取该市下辖区县，包括市辖区，只显示边线和名称 |
| 7 | 市域边界 | 优先复用用户或工程数据，否则从内置「市域面」提取目标城市，只显示边线 |
| 8 | 地铁线路 | 用户提供或自动检索，按真实线路名称或编号区分 |
| 9 | 地铁站点 | 用户提供或自动检索，显示真实运营站点和站名 |

图层与成果名称使用任务中的实际城市名，优先沿用工具返回的明确业务名称。例如任务城市为武汉市时，使用“武汉市边界”“武汉市区县边界”“武汉市地铁站点”等；换城市时随实际地区命名，不把示例中的城市固定下来。处理方法记录在执行过程，不作为图层业务名称。

## 按以下顺序执行

完成当前阶段的成果交接后再进入下一阶段。同一阶段内独立的数据可并行准备，所有上图操作均由数据角色按同一顺序逐个执行。每次交接说明实际图层 ID、文件路径、已显示的图层顺序，以及已准备但尚未显示的图层；空间分析返回后由数据角色继续加载，不能交给制图角色补加载。下文的交接顺序均省略本次无需或已说明缺失的图层。出现错误时修正发生错误的步骤，继续使用此前已经完成的成果。

### 1. 确定本次任务

明确城市、服务半径、人口年份、纸张和输出格式，已有材料和用户回答直接沿用，未指定时使用上述默认值。800 米直线缓冲表示几何邻近范围，不等同于道路步行距离、实际通勤时间或客流。城市确实没有运营地铁时说明情况，不生成空覆盖结论。

### 2. 数据角色一次准备完整输入

先准备计算所需的边界和地铁数据，再依次显示人口、水域、河流、道路四类底层。本阶段准备完整输入，但只显示这四类底层；市界、区县边界、地铁线路和站点稍后再上图。数据已读取、已有可计算的图层 ID，不代表需要立即显示。

1. 从市域数据提取目标城市，从县域数据提取该市下辖区县，分别保存为文件或后台可计算对象，关闭本次提取的显示结果选项，暂不加入图层面板。全国市域面、县域面改名不会变成目标城市，必须实际筛选；市辖区属于县级行政区，不能省略。保留两层的实际文件路径、可用图层 ID 和区县数量，供后续裁剪、统计及显示使用。
2. 准备地铁线路与站点，同样仅供后续计算，暂不显示到地图。使用已提取的市域范围外扩 5%，保留线路关系、真实名称、编号和来源提供的线路色。只使用运营地铁，不把铁路站、公交站或规划站当作地铁站。300 米内同名站合并，保留原站点对应关系；整理后仍不提前上图。
3. 准备人口格网并首先加载显示。优先复用已有正确数据或可用 WorldPop 获取模板，按实际研究区和可用年份选择数据，再按真实市域多边形限定范围。市界外为无数据，保留市内原有无数据和真实零值，记录年份、单位、来源；不能只按年份取跨国集合的第一张影像，也不能用外接矩形代替市域。人口服务或数据不可用时说明具体缺项。
4. 接着按“水域 → 河流 → 主要道路”的顺序逐个准备并加载显示，每一层加载成功后再显示下一层。使用范围与比例尺适合的内置数据或自动检索；确实不存在某类数据时说明并省略该层，其余保持先后关系，不能静默漏掉这一类。核实河名等后续标注字段。
5. 交接时，图层面板从上到下应是“主要道路、河流、水域、人口格网”（不含已说明缺失或本次无需的层）；同时交接尚未显示的市界、区县边界、线路和站点，以及全部输入的实际 ID、路径、用途、坐标系和字段。已有字段能满足分类和标注时直接使用，仅名称写法不一致时才整理，不要求另建固定名称的字段。沿用已有对象，保存后不创建副本，不在本阶段追加显示线路和站点。

已有材料优先复用，只有缺失数据才获取。分析需要时才转换坐标系，普通显示叠加使用 QGIS 动态投影。

若本次只要求线路分布，无须等待服务范围，数据角色在道路之后直接继续加载“区县边界 → 市域边界 → 地铁线路 → 地铁站点”，再将已加载图层交给制图角色。

### 3. 空间分析生成结果，交回数据角色接续加载

空间分析角色沿用数据角色交接的后台站点和边界，将参与距离分析的站点及必要边界转换到适合当地、以米为单位的投影，原始文件保留。生成 800 米缓冲，合并重叠区域，再按市域裁剪，得到一份用于成图的站点服务范围。分析角色只生成结果，不加载服务范围或其他图层到地图。服务范围通常小于市域，不要求覆盖整个城市。

接着统计市域人口和服务范围人口，按需给出区县统计。格网数值为人口数时汇总，为人口密度时先按像元实际面积换算；采用一致的边界像元取舍方法，记录无数据范围，避免重复计算。没有完成的统计不编造数值或比例。

投影副本、初始缓冲和统计用的分区片段留在后台，不进入图层面板或画布。分析角色返回最终服务范围的实际图层 ID、文件路径、统计结果、距离单位、人口年份和方法限制。此时地图上仍是数据角色已经加载的“主要道路、河流、水域、人口格网”。几何检查仅用于判断输入能否分析；检查产生的有效、无效、错误记录不作为地图图层。

主智能体将分析结果交回同一个数据角色。数据角色沿用已有图层和文件，从道路之后继续逐个加载“站点服务范围 → 区县边界 → 市域边界 → 地铁线路 → 地铁站点”，前一层成功再加载下一层；不重复加载前四层，不重新取数或重做分析。加载完成后，将整张地图的实际图层 ID、顺序和统计结果交给制图角色。

### 4. 制图角色符号化与标注

直接使用数据角色已按顺序加载的图层，应用下表的样式与标注。制图角色不承担图层加载，不重新取数、复制图层或改变已有层序；若交接缺少应显示的图层，说明缺项并交回数据角色处理。只要求线路分布时省略人口和服务范围，确实缺失的图层按前面说明省略。

以下尺寸按 A1；默认 A3 统一乘 0.5 一次，其他纸张按短边比例缩放（A0 ×1.41、A2 ×0.71、A4 ×0.35），字号不小于 1.8 毫米、线宽不小于 0.1 毫米。区县名使用加粗宋体，其他文字使用系统可用的中文黑体。

| 图层 | 画法 | 标注 |
|---|---|---|
| 地铁站点 | 白色实心圆，直径 1.2 毫米，深灰 #242424 描边 0.2 毫米；A3 为直径 0.6、描边 0.1 毫米 | 真实站名，3 毫米，深灰 #242424，点周围放置，不压住站点 |
| 地铁线路 | 按真实线路名称或编号分类，优先官方线路色，没有官方色时用可区分分类色，实线 0.8 毫米 | 线路名，3 毫米，深灰 #242424，沿线放置 |
| 市域边界 | 面不填充，边线用深灰 #202020、不透明实线 1.2 毫米，下衬白色实线 1.8 毫米；A3 为深色线 0.6、白衬 0.9 毫米 | 城市名放入地图标题，不重复标注 |
| 区县边界 | 面不填充，深灰 #707070 点划线 0.4 毫米，下衬白色实线 0.8 毫米 | 实际区县名，5.6 毫米，加粗 Songti SC 或宋体，深灰 #242424，白描边 0.8 毫米，面内水平；A3 字号为 2.8 毫米 |
| 站点服务范围 | 蓝色 #2399E9 填充，透明度 70%，无边线 | 不标注 |
| 主要道路 | 浅灰 #C0C0C0 实线 0.3 毫米 | 不标注 |
| 河流 | 使用样式「河流线」，作为弱化背景 | 根据真实字段沿线标河名 |
| 水域 | 使用样式「河流面」，作为弱化背景 | 不标注 |
| 人口格网 | 按实际数值分级，使用浅黄到橙色的有序渐变，无数据透明，背景为白色 | 不标注 |

线路名称采用精确分类，避免“1号线”匹配“11号线”；不能识别归属的线段保留中性表达，不猜造线路名称。人口格网和线路保留各自分类渲染，不套统一填充。市界和区界是面图层的边线，不将其当作线图层处理。

### 5. 使用已加载图层完成排版

使用版面「四角对齐版式」，默认 A3 横向。主图显示真实市域及必要留白，标题包含实际城市名和“轨道交通站点服务覆盖图”。配置标题、图例、比例尺、指北针、来源和说明；图例注明缓冲距离、人口单位与年份，说明栏给出已完成的覆盖统计、直线缓冲假设和数据时点差异。

此时实例图层面板从上到下应为“地铁站点、地铁线路、市域边界、区县边界、站点服务范围、主要道路、河流、水域、人口格网”，与前述逐层加载自然形成的顺序一致。“图层全部已加载”不代表顺序正确，应以实际面板顺序为准。版面直接沿用实例中这组图层和顺序，不能只在版面中另设正确顺序而忽略主画布。不在排版阶段补加载中间结果或执行工作图层清理，原始数据文件保留。

### 6. 导出并交付，结束流程

制图角色确认所选最终图层、标题、图例和导出路径，导出 PNG、PDF 与实际服务范围数据，说明站点数、服务半径、人口年份及统计限制。文件成功导出后交付，不再追加质量反馈任务或重新取数。数据没有准备完整或导出失败时如实说明，不能把早期缺层的试导出作为最终成果。
