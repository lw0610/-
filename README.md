# AutoCarto 源码交接

这是 Eino / AutoCarto 工作区在 **2026-10-07（北京时间）** 整理的源码快照，用于交接 10 月 6 日至 7 日的功能改动。仓库同时包含 Go 后端、Web / Tauri 前端和 QGIS 插件；不是已经验收的 Windows MapGIS 安装包。

**队友请先阅读 [功能移植交接说明](docs/TEAM_HANDOFF_2026-10-07.md)**，其中列出 GEE、浏览器、在线取数的模块对应、依赖、授权、配置、验证方法和未完成事项。

## 目录

| 目录 | 内容 |
| --- | --- |
| `carto_agent/` | Go / Eino 后端、配置与默认模板、GEE / 浏览器 / 网页运行时 |
| `autocarto-web/` | React / Next.js / Tauri 界面及在线数据设置 |
| `autocarto/` | QGIS 插件、工具、工作流程、公开行政区资产及来源许可 |
| `docs/` | 功能和迁移文档 |
| `scripts/` | 插件同步与开发辅助脚本 |

## 交付内容与配置

- 包含当前工作区中的源码和未提交改动，并保留工具契约、技能附件、行政区公开数据、默认配置、测试及依赖锁文件。
- **不包含 `autocarto_data/`。** 其中是用户配置、密钥存储、会话记录、日志、下载及运行数据；接收方需使用自己的运行目录和账号重新配置。
- 同时排除旧 `autocarto/config/`、`autocarto/data/`、私钥与认证文件、本地环境文件、缓存、依赖安装目录、平台编译产物、测试输出、个人论文材料和压缩包。
- 文档中的 `<YOUR_WORKSPACE>`、`<YOUR_DATA_DIR>`、`<YOUR_HOME>` 是待替换的本机路径；行军等既有流程引用的数据不会由源码自动提供。
- `carto_agent/defaults/` 内的默认结构是功能的一部分，已保留；不要把接收方已有的模型密钥或全部智能体配置覆盖为另一台机器的配置。

## Windows 队友注意

后端及 Web 改动可以按模块合并到对应工程。QGIS 的 Python 图层、标注和布局工具需要映射为 Windows MapGIS 的 C# 实现，不能直接覆盖。先合并并验收 GEE / 浏览器 / 在线取数，再接 GIS 数据检查和加载。

GeoCode 的右侧文件树与交互地图预览仍未接入；它们不是本次已完成功能。重复图层、双重标注也不能因下载文件可复用而视为已解决。

本次上传已检查提交范围、敏感配置与必要资源；上传副本执行 `go test -run '^$' ./...` 通过全部 Go 包的编译检查（未执行功能测试）。历史功能验证条件见交接文档。接收方仍需在自己的系统、账号和 GIS 环境中进行真实验收。

根目录 `build.sh`、`build.bat` 包含本项目的 QGIS 部署流程，Windows 构建脚本还有原环境目录设置，执行前请按交接说明适配。不要将完整构建脚本直接应用于 MapGIS 工程。
