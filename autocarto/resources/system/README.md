# 内置样式与版面

此目录随程序发布，只读。公共资源只有两类：单图层 QML **样式**与 QPT/声明式模板 **版面**。用户资源位于项目运行目录 `autocarto_data/resources/`；路线配色、符号预设在工具私有 `assets/` 或用户 `presets/` 中，不列入公共库。

内置提供 11 个独立样式（省域面、省界、河流面、河流线、高速公路、国道、铁路、地级城市驻地、县级城市驻地、市域面、县域面）和 2 个版面（四角对齐版式、统计专题版式）。目录中每项包含资源清单、模板文件和真实 QGIS 生成的预览。目录/资源名称沿用原资产名称，“版面”是统一的界面类别。

数据不属于资源库，也不装入流程包。用户在对话中提供文件、文件夹或工程图层；不足的部分由数据服务获取。流程是普通 Markdown，正文以 `「资源名称」` 引用视觉资源，保存时用稳定编号与摘要写入 `flow.lock`。导出流程可携带这些资源的 `deps/` 快照，导入不会自动覆盖公共库内容。

内置资源可复制为不同名称的用户资源；全库名称唯一，不提供覆盖内置的入口。文件夹批量导入会分别创建样式/版面，重名自动加后缀。重命名保留编号与已锁定引用，并提示更新流程正文名称。

旧样式集、数据清单和符号的迁移说明及制作方法见 [资源制作指南](../../../docs/资源制作指南.md)。旧原件先备份，迁移过程可重复执行。
