# 内置模板与样式库

此目录随 QGIS 插件和桌面应用发布，只读。用户公共资源位于项目运行目录 `autocarto_data/resources/`；流程专用资源在各流程的 `resources/`，工具私有文件在 `tools/system/<工具域>/assets/`，两者不列入公共库。

公共库只接受版式、样式、样式集。当前发布三项通用资源，均含 `resource/v1` 清单：

| 编号 | 类型 | 内容 |
|---|---|---|
| `style_set.gb-basemap` | 样式集 | 国标底图样式 |
| `layout.four-corner` | 版式 | 四角对齐版式 |
| `layout.statistical` | 版式 | 统计专题版式 |

当前分组目录为 `styles/`、`layouts/`。编号 `route_style.mono` 保持不变，已作为路线工具资产提供，不显示在公共库，也不随流程作为公共依赖导出。场景专用符号与配色由具体流程携带；行政区边界数据属于行政区工具资产。用户数据通过流程的文件或文件夹输入选择。

修改内置资源时，在界面复制为用户资源，或明确“作为覆盖”。普通同名用户资源不会自动取代内置项：无锁定且有多个同类型同名候选时报歧义。覆盖通过用户清单的 `overrides` 指向内置编号，删除覆盖项后恢复内置。

公共引用由流程 `flow.lock` 记录编号、版本与摘要。资源内容变化会在计划生成或运行时给出提示；导出流程默认携带锁定公共依赖，导入不会静默写入用户公共库。自动导入、从工程保存、制作与覆盖方法见 [资源制作指南](../../../docs/资源制作指南.md)。
