# 空间插值与曲面生成

## 概述

本 skill 提供从离散点数据生成连续曲面的插值能力，用于空间预测和曲面建模。

## 前置条件

- 输入为点要素图层，且已加载到工程中
- 插值字段存在且为数值类型（非 NULL）
- 点分布密度足够覆盖目标区域（稀疏区域插值不可靠）
- 图层使用投影坐标系（距离计算更准确）

## 工作流步骤

### 1. 输入检查

- 使用 `get_active_layer_info` 确认输入为点要素图层
- 确认插值字段存在且为数值类型
- 使用 `raster_statistics` 或属性统计检查值域范围
- 检查点分布密度和空间覆盖范围
- **判断标准**：点要素图层，数值字段，分布合理

### 2. 选择插值方法

- `idw_interpolation`：反距离加权插值
  - 适用于均匀分布的采样点
  - 参数：权重指数（通常 2，越大越局部化）、搜索半径
  - 特点：不会超出采样值范围，计算快
- `tin_interpolation`：TIN 不规则三角网插值
  - 适用于地形建模和不规则分布的采样点
  - 保留原始采样点值（精确插值）
  - 特点：三角面内线性插值，边缘可能有伪影
- **判断标准**：方法匹配数据分布特征和精度要求

### 3. 参数设置

- 输出分辨率（像元大小）：根据点密度设定，通常为平均点间距的 1/2 ~ 1/3
- 输出范围（默认为点图层范围，可自定义）
- IDW 搜索半径和最小/最大采样点数
- **判断标准**：参数合理，分辨率与点密度匹配

### 4. 执行插值

- 调用对应插值工具
- 生成连续栅格曲面
- **判断标准**：输出栅格已生成

### 5. 结果验证

- 使用 `raster_statistics` 检查输出值域是否在合理范围
- 对比插值结果与原始采样值
- 检查是否存在明显的"牛眼效应"（IDW）或边缘伪影（TIN）
- **判断标准**：值域合理，无明显插值伪影

## 常见问题处理

- 插值结果出现"牛眼效应" → IDW 权重指数过大，减小到 1.5-2.0
- 边缘区域值异常 → 采样点未覆盖边缘，考虑裁剪输出范围或增加边缘采样点
- 输出栅格有大面积 NoData → 搜索半径过小，增大搜索半径
- 插值结果过于平滑 → IDW 权重指数过小，适当增大；或换用 TIN
- 分辨率设置不当 → 过高导致文件过大且无意义，过低丢失细节；参考点间距设定

## 输出检查清单

- [ ] 输入为点要素且字段为数值类型
- [ ] 插值方法和参数合理
- [ ] 输出值域在合理范围内
- [ ] 无明显插值伪影
- [ ] 输出栅格已命名和保存
