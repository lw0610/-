# 批量出图

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先确认分幅依据、唯一标识字段、覆盖范围和命名规则，固定实际输出目录与文件格式。模板由 layout_compose 或 import_layout_template 创建；版式参数和字号由所选版式提供，不引用旧流程技能作为工具前置条件。

逐幅设置 layout_set_map_extent 前，把范围转换到地图框 CRS；固定图层列表，更新标题或占位符，核查图例和比例尺随分幅变化。需要位置示意时使用 layout_add_overview 并关联正确地图项。比例尺固定或随范围自适应须事先确定，不能让批次无意中混用规则。

每幅导出后检查返回状态、真实文件、页面完整性和分幅标识。空白范围明确跳过或报告，失败记录保留并仅重试受影响分幅。输出清单包含分幅标识、路径、范围、状态和错误；文件数量应与成功记录相符。
