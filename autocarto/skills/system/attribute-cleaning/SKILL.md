# 属性表清洗与标准化

## 概述

本 skill 提供属性表的系统化清洗流程，将原始属性数据转化为规范、可分析的状态。适用于数据入库前的标准化处理。

## 前置条件

- 目标图层已加载到工程中
- 已通过 `get_active_layer_info` 了解字段结构
- 明确清洗目标（去重/空值/类型/命名）

## 工作流步骤

### 1. 字段结构检查

- 使用 `get_active_layer_info` 检查字段名称、类型和统计信息
- 识别问题字段：空值过多、类型错误、命名不规范
- **判断标准**：问题字段已识别并记录

### 2. 去重处理

- 使用 `delete_duplicates_by_attribute` 按关键字段去除重复记录
- 记录去重前后要素数量变化
- **判断标准**：无重复记录

### 3. 空值处理

- 使用 `field_calculator` 填充空值（默认值/插值/删除）
- 根据字段语义选择合适的填充策略
- **判断标准**：关键字段无空值

### 4. 类型修正

- 使用 `text_to_float` 将文本型数值字段转为数值类型
- 使用 `field_calculator` 处理日期格式统一
- **判断标准**：字段类型与数据语义匹配

### 5. 字段标准化

- 使用 `refactor_fields` 批量调整字段结构
- 使用 `rename_table_field` 规范化字段命名
- 使用 `delete_column` 删除无用字段
- **判断标准**：字段命名规范，无冗余字段

### 6. 建立索引

- 使用 `create_attribute_index` 为常用查询字段建立索引
- 提升后续查询和分析效率
- **判断标准**：索引创建成功

## 常见问题处理

- 字段名含特殊字符导致操作失败 → 先用 `rename_table_field` 重命名
- 类型转换失败 → 检查字段中是否有非数值文本，先清理再转换
- 去重后要素数大幅减少 → 确认去重字段选择是否正确

## 输出检查清单

- [ ] 重复记录已清除
- [ ] 关键字段无空值
- [ ] 字段类型正确
- [ ] 字段命名规范
- [ ] 索引已创建
