# GPS/外业数据导入与处理

## 概述

本 skill 提供 GPS 和外业采集数据的导入与预处理能力，将野外数据转化为可分析的 GIS 图层。

## 前置条件

- GPS 数据文件已准备（GPX/CSV/KML 等格式）
- 已明确数据内容类型（航点/轨迹/路线）
- 如需与其他图层叠加，已确认目标坐标系

## 工作流步骤

### 1. 数据导入

- `gps_import_gpx`：导入 GPX 文件（航点/轨迹/路线）
- `gps_download`：从 GPS 设备下载数据
- 导入时选择需要的要素类型（waypoints/tracks/routes）
- **判断标准**：数据已导入为图层，要素数量正确

### 2. CRS 检查

- GPS 数据通常为 WGS84（EPSG:4326）
- 使用 `get_active_layer_info` 确认导入后 CRS 正确
- **判断标准**：CRS 为 EPSG:4326 或已知坐标系

### 3. 坐标系转换（按需）

- 使用 `reproject_layer` 转换到项目坐标系
- 确保与其他图层 CRS 一致
- **判断标准**：CRS 与项目一致

### 4. 轨迹处理（按需）

- 使用 `points_to_path` 将航点连接为轨迹线
- 按时间字段或序号字段排序
- 可按分组字段拆分为多条轨迹
- **判断标准**：轨迹线已生成，连接顺序正确

### 5. 坐标字段

- 使用 `add_xy_fields` 添加 X/Y 坐标字段
- 便于后续属性查询和导出
- **判断标准**：坐标字段已添加且值正确

## 常见问题处理

- GPX 导入为空 → 检查文件是否包含所选要素类型（waypoints/tracks/routes），尝试其他类型
- 导入后位置偏移 → CRS 可能不是 WGS84，检查原始数据坐标系
- 轨迹连接顺序错误 → 检查排序字段（时间戳或序号），确认排序方向
- 坐标转换后精度损失 → 使用七参数转换而非三参数，或选择更合适的投影
- CSV 坐标导入失败 → 检查经纬度字段名和分隔符，确认坐标值格式（十进制度 vs 度分秒）

## 输出检查清单

- [ ] 数据已成功导入
- [ ] CRS 正确（WGS84 或已转换）
- [ ] 要素数量与原始数据一致
- [ ] 轨迹连接顺序正确（如适用）
- [ ] 坐标字段已添加（如需要）
