# 选址适宜性分析

## 概述

本 skill 描述跨智能体协作的选址适宜性分析流程，通过多因子加权叠加评估空间适宜性等级。适用于设施选址、土地评价、生态敏感性评估等场景。

## 前置条件

- 各评价因子数据已准备（矢量或栅格格式）
- 已明确评价因子列表和权重分配方案
- 已确定适宜性等级划分标准（如 5 级：最适宜/适宜/一般/不适宜/极不适宜）

## 工作流步骤

### 1. 需求确认 [orchestrator]

- 确认评价因子（地形、交通、土地利用、环境等）
- 确认各因子权重（所有权重之和 = 1.0）
- 确认适宜性等级划分标准
- **因子权重指南**：
  - 核心约束因子（如生态红线）：设为排除条件，不参与加权
  - 主要影响因子：权重 0.2-0.4
  - 次要影响因子：权重 0.05-0.15
  - 权重不确定时，建议使用等权重作为基线
- **数据传递**：将因子列表、权重和分级标准传递给后续步骤
- **判断标准**：因子列表完整，权重之和为 1.0，分级标准明确

### 2. 数据准备 [data_processing]

- 加载各因子数据
- 统一 CRS（所有因子必须同一投影坐标系）
- 统一空间范围（用 `gdal_clip_raster_by_extent` 或 `clip` 裁剪到分析区域）
- 属性清洗和标准化
- **数据传递**：输出统一 CRS 和范围的因子图层列表
- **判断标准**：所有因子 CRS 一致，空间范围对齐

### 3. 因子处理 [raster_terrain]

- 矢量因子转栅格：用 `vector_to_raster` 转换，分辨率与其他栅格因子一致
- 栅格对齐：用 `gdal_warp` 统一所有因子的范围和分辨率
- 因子重分类：用 `raster_reclassify` 将各因子重分类为统一评分（如 1-5 分）
  - 示例：坡度 0-5° → 5分，5-15° → 4分，15-25° → 3分，25-35° → 2分，>35° → 1分
- 加权叠加：用 `raster_calculator` 执行
  - 表达式示例：`factor_A * 0.3 + factor_B * 0.25 + factor_C * 0.25 + factor_D * 0.2`
- **数据传递**：输出适宜性评分栅格
- **判断标准**：评分栅格值域在预期范围内（如 1.0-5.0）

### 4. 结果提取 [vector_spatial]

- 用 `raster_reclassify` 将连续评分重分类为等级（如 1-5 级）
- 用 `raster_to_vector` 将适宜性栅格转为矢量
- 用 `add_geometry_attributes` 计算各等级面积
- 统计各等级面积和比例
- **数据传递**：输出适宜性等级矢量图层和面积统计
- **判断标准**：各等级面积之和 ≈ 分析区域总面积

### 5. 成果制图 [cartography_layout]

- 用 `cartography_graduated_style` 或 `cartography_rule_based_style` 符号化适宜性等级
- 推荐配色：红（极不适宜）→ 黄（一般）→ 绿（最适宜）
- 制作标准布局，添加图例、比例尺等要素
- 导出成果地图

## 常见问题处理

- 因子分辨率差异大 → 统一到最粗分辨率（保守）或最细分辨率（精确但计算量大）
- 权重分配不确定 → 先用等权重运行，再做敏感性分析调整
- 加权叠加结果集中在某一等级 → 检查重分类评分是否合理，调整分级断点
- 排除区域未生效 → 在加权叠加后用 `raster_calculator` 将排除区域设为 NoData

## 输出检查清单

- [ ] 所有因子 CRS 和分辨率一致
- [ ] 因子重分类评分合理
- [ ] 权重之和为 1.0
- [ ] 适宜性等级面积统计完整
- [ ] 成果地图已导出
