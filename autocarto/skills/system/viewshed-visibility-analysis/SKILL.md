# 视域与可视性分析

## 概述

本 skill 描述跨智能体协作的视域分析流程，评估观察点的可视范围和通视性。适用于景观评估、基站选址、军事瞭望、风电场视觉影响评估等场景。

## 前置条件

- DEM 栅格数据已加载（分辨率影响分析精度）
- 观察点位置已确定（点要素或坐标）
- DEM 使用投影坐标系
- DEM 覆盖范围大于分析半径

## 工作流步骤

### 1. 需求确认 [orchestrator]

- 确认 DEM 数据和观察点位置
- 确认观察参数：
  - **观察高度**（observer height）：观察者眼睛离地面的高度（如人 1.7m，瞭望塔 15m）
  - **目标高度**（target height）：被观察目标的高度（如建筑 10m，默认 0m 为地面）
  - **分析半径**：最大观察距离（如 5km、10km、20km）
  - **角度范围**（可选）：水平起止角度（0-360° 为全方位）
- **参数设置指南**：
  - 分析半径不宜过大（> 30km 时大气影响显著，结果不可靠）
  - DEM 分辨率应 ≤ 分析半径的 1/100（如 10km 半径需 ≤ 100m 分辨率）
- **数据传递**：将 DEM 图层名、观察点、观察参数传递给后续步骤
- **判断标准**：参数完整合理，DEM 覆盖分析范围

### 2. 数据准备 [data_processing]

- 加载 DEM 和观察点数据
- 确认 CRS 一致性（DEM 和观察点必须同一坐标系）
- 检查 DEM 分辨率是否满足分析精度要求
- 如 DEM 范围过大，用 `gdal_clip_raster_by_extent` 裁剪到分析区域（观察点 + 分析半径的外接矩形）
- **数据传递**：输出预处理后的 DEM 和观察点图层
- **判断标准**：CRS 一致，DEM 覆盖分析范围

### 3. 视域计算 [vector_spatial]

- **单点视域**：使用 `viewshed` 计算
  - 输入：DEM、观察点、观察高度、目标高度、分析半径
  - 输出：二值栅格（1=可视，0=不可视）
- **两点通视**：使用 `line_of_sight` 计算
  - 输入：DEM、起点、终点
  - 输出：通视线（标注可视/不可视段）
- **多点累计视域**：
  - 对每个观察点分别计算视域
  - 用 `raster_calculator` 叠加所有视域栅格（求和）
  - 结果值 = 该像元被多少个观察点可见
- **数据传递**：输出视域栅格
- **判断标准**：视域栅格已生成，值域合理

### 4. 结果统计 [raster_terrain]

- 用 `raster_statistics` 统计视域栅格：
  - 可视面积 / 总面积 = 可视率
  - 多点累计：各可见次数的面积分布
- 用 `raster_zonal_statistics` 按区域统计可视率（如按行政区）
- **数据传递**：输出统计结果
- **判断标准**：可视率计算完整

### 5. 成果制图 [cartography_layout]

- 单点视域：用绿色（可视）和红色（不可视）二值渲染
- 累计视域：用渐变色渲染（深色=多点可见，浅色=少点可见）
- 叠加 DEM 山体阴影作为底图
- 标注观察点位置和可视率
- 导出视域分析报告

## 常见问题处理

- 视域结果全部可视 → 检查分析半径是否过小，或 DEM 地形过于平坦
- 视域结果全部不可视 → 检查观察高度是否设置正确（不应为 0）
- 计算耗时过长 → 减小分析半径或降低 DEM 分辨率
- 边缘效应 → 确保 DEM 范围大于分析半径，避免边界截断
