# 属性清洗

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先用工程与图层信息核实真实字段、类型、主键、要素数量、空值和重复情况，再制定清洗规则。保留原始文件和清洗前统计；字段空值、零和空字符串含义不同，不能默认补零或删除。

按关键字段用 delete_duplicates_by_attribute 去重，核对减少记录是否符合主键规则；用 field_calculator 按已知语义处理缺失和日期，用 text_to_float 转换数值前检查千分位、单位和非法文本。批量结构调整用 refactor_fields，单字段重命名用 rename_table_field，删除列前确认后续表达式与关联不再依赖它。

字段计算应先在小样本检查，转换失败保持可追溯的错误名单。连接字段两侧类型和规范化规则一致，重复键应明确一对多或聚合方案，不能任取一个值。按查询需求用 create_attribute_index 建索引。最终报告字段变更、前后数量、重复/空值/非法值统计和输出位置；不能仅以工具成功作为清洗完成。
