# 多格式互转

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

明确源格式、目标格式、目标用途、编码和独立输出路径。优先使用 data_export_vector、data_export_raster 或 export_layers_to_dxf；只有确需改变几何类型才使用对应格式转换工具，不能把改扩展名当转换。

SHP 字段名长度、字段类型、编码和单文件容量有限；导出后核对截断或重命名映射，并保持配套文件完整。GPKG 可含多个子图层，显式选定目标子图层。按目标格式或接收规范需要选择 CRS，例如符合 RFC 7946 的 GeoJSON 应输出 WGS84 经度纬度；不要把它扩展成所有任务的重投影要求。DXF 和 CSV 可能丢失部分属性、几何或样式，先说明损失范围。

重新加载产物检查有效性、要素/像元数量、字段类型、字符编码、范围和 CRS。空文件、路径存在或工具正常退出不能单独证明转换完成。避免覆盖原始数据，报告真实文件及必要的格式限制。
