# 可达性与服务区

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先核实真实路网、起点、成本类型、速度或成本字段和阈值。路网连通、方向限制及起点到线网的匹配容差会影响结果；几何有效不代表拓扑连通。按需检查无效几何、断头节点和速度字段的缺失或非法值，不把默认速度当实测数据。

单起点用 service_area_from_point，多起点用 service_area_from_layer。距离成本和时间成本必须分别确认单位；速度字段单位也以工具定义为准，不能把分钟、秒或公里直接混传。需要多个阈值时逐级记录结果。输出可能是可达线段而非服务区面，先检查真实几何类型，再决定是否生成面和进行覆盖统计。

覆盖统计须说明分母、重叠去重方式和数据年份。多起点重叠范围不能重复计人口或要素；覆盖率超过百分之百时检查重复计数。路径断裂先检查连通性，范围异常先检查成本单位与速度，不盲目扩大阈值。交付起点、成本规则、阈值、可达结果和统计依据。
