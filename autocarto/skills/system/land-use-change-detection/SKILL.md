# 土地利用变化检测

## 概述

本 skill 描述跨智能体协作的土地利用变化检测流程，通过两期数据对比识别变化区域和变化类型。适用于城市扩张监测、耕地保护评估、生态变化分析等场景。

## 前置条件

- 两期土地利用数据已准备（矢量或栅格格式）
- 两期数据的分类体系已知（类别编码和名称）
- 已明确分析区域范围

## 工作流步骤

### 1. 需求确认 [orchestrator]

- 确认两期数据的时间节点（如 2015 年 vs 2020 年）
- 确认分类体系是否一致（类别编码和名称需对齐）
- 确认关注的变化类型（如耕地→建设用地、林地→耕地）
- **分类体系对齐指南**：
  - 两期分类体系相同 → 直接对比
  - 分类体系不同 → 需先建立映射关系，将两期统一到同一分类体系
  - 分类粒度不同 → 统一到较粗的分类粒度
- **数据传递**：将时间节点、统一分类体系、关注变化类型传递给后续步骤
- **判断标准**：两期分类体系已对齐，关注变化类型已明确

### 2. 数据准备 [data_processing]

- 加载两期土地利用数据
- 统一 CRS（两期数据必须同一坐标系）
- **分类编码统一**：
  - 如分类体系不同，用 `field_calculator` 重新编码
  - 确保两期使用相同的类别编码值
- 确保空间范围对齐（用 `clip` 裁剪到共同分析区域）
- **数据传递**：输出统一编码、CRS 和范围的两期数据
- **判断标准**：两期数据 CRS 一致，分类编码一致，空间范围对齐

### 3. 变化分析 [raster_terrain / vector_spatial]

- **栅格数据方案**：
  - 用 `raster_calculator` 构建变化矩阵：`T2 * 100 + T1`（如 T2=3, T1=1 → 301 表示从类别1变为类别3）
  - 变化编码规则：百位=后期类别，个位=前期类别
  - 未变化区域：T1 == T2 的像元
- **矢量数据方案**：
  - 用 `intersection` 叠加两期数据
  - 结果包含两期的分类字段，可直接对比
  - 用 `field_calculator` 添加变化类型字段：`concat(T1_class, ' → ', T2_class)`
- **数据传递**：输出变化图层（含变化编码或变化类型字段）
- **判断标准**：变化图层包含前期类别、后期类别和变化标识

### 4. 变化提取 [query]

- 提取特定变化类型区域：
  - 用 `extract_by_expression` 筛选关注的变化类型
  - 示例：`"change_code" = 301`（从类别1变为类别3）
- 统计各变化类型面积：
  - 用 `add_geometry_attributes` 计算面积
  - 汇总变化转移矩阵（各类别间的转换面积）
- **数据传递**：输出变化统计表和提取的变化区域图层
- **判断标准**：变化面积统计完整，各类型面积之和 ≈ 分析区域总面积

### 5. 成果制图 [cartography_layout]

- 用 `cartography_rule_based_style` 分类渲染变化类型
- 推荐配色：未变化用灰色，增加用绿色系，减少用红色系
- 制作变化检测专题图
- 导出变化检测报告

## 常见问题处理

- 两期分类体系不一致 → 建立映射表，用 `field_calculator` 重编码后再对比
- 边界处出现大量伪变化 → 检查两期数据的空间配准精度，必要时做缓冲区过滤
- 变化面积统计不平衡 → 检查 NoData 区域是否被错误计入
- 栅格分辨率不同 → 用 `gdal_warp` 统一到相同分辨率再计算

## 输出检查清单

- [ ] 两期数据分类体系已对齐
- [ ] 两期数据 CRS 和范围一致
- [ ] 变化矩阵/变化图层已生成
- [ ] 各变化类型面积统计完整
- [ ] 变化检测专题图已导出
