# 栅格重分类与分区统计

## 概述

本 skill 提供栅格数据的重分类和分区统计能力，用于将连续值转为分类值并进行区域统计。

## 前置条件

- 输入栅格已加载到工程中
- 已明确分类方案或分区图层
- 分区统计时，分区图层（矢量或栅格）已准备

## 工作流步骤

### 1. 值域分析

- 使用 `raster_info` 获取栅格元数据（数据类型、波段数）
- 使用 `raster_statistics` 了解值域范围和分布（最小值、最大值、均值、标准差）
- **判断标准**：值域范围和分布特征已了解

### 2. 确定分类方案

- 等间距分类：按固定间隔划分（适用于均匀分布数据）
- 自然断点分类：按数据分布特征划分（适用于偏态分布）
- 自定义分类：按业务需求指定断点（如坡度分级：0-5°平坦、5-15°缓坡、15-25°中坡、>25°陡坡）
- **判断标准**：分类方案合理，类别数适中（通常 3-10 类）

### 3. 执行重分类

- 使用 `raster_reclassify` 按分类方案重分类
- 设置输入值范围和输出类别值
- 确认 NoData 值的处理方式
- **判断标准**：重分类结果类别数正确

### 4. 分区统计

- 使用 `raster_zonal_statistics` 按分区计算统计值
- 统计指标：均值、最大值、最小值、标准差、面积、像元数
- 分区可以是矢量多边形或分类栅格
- **判断标准**：统计结果已写入分区图层属性表

### 5. 栅格转矢量（按需）

- 使用 `raster_to_vector` 将分类栅格转为矢量多边形
- 适用于需要矢量化分析结果的场景
- **判断标准**：矢量图层已生成，类别字段正确

## 常见问题处理

- 重分类后类别缺失 → 检查分类断点是否覆盖完整值域，注意边界值归属
- 分区统计结果为 NULL → 检查分区多边形是否与栅格范围重叠，CRS 是否一致
- 栅格转矢量产生碎片多边形 → 先对栅格做平滑或合并小面积类别
- 分类方案不合理 → 参考值域统计的分位数或标准差来设定断点
- NoData 区域被错误分类 → 在重分类表中显式指定 NoData 的处理

## 输出检查清单

- [ ] 值域分析已完成
- [ ] 分类方案合理且覆盖完整值域
- [ ] 重分类结果类别正确
- [ ] 分区统计指标完整
- [ ] 输出图层已命名
