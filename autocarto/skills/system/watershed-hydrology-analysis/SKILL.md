# 流域水文分析

## 概述

本 skill 描述跨智能体协作的流域水文分析流程，从 DEM 提取完整的水文特征信息。适用于流域规划、防洪评估、水资源管理等场景。

## 前置条件

- DEM 栅格数据已加载（分辨率建议 ≤ 30m）
- DEM 使用投影坐标系（米制单位）
- DEM 无明显数据空洞（空洞会导致水系断裂）
- 如有流域出口点，需准备点要素图层

## 工作流步骤

### 1. 需求确认 [orchestrator]

- 确认分析区域和 DEM 数据
- 确认流域出口点或分析范围
- 确认所需水文产品（流域边界/水系/汇水面积/流向）
- **DEM 预处理要求**：
  - 分辨率：≤ 30m 适合中小流域，≤ 90m 适合大流域
  - 必须无数据空洞（空洞区域无法计算流向）
  - 平坦区域可能需要 DEM 填洼处理
- **数据传递**：将 DEM 图层名、出口点、所需产品列表传递给后续步骤
- **判断标准**：DEM 质量满足分析要求，分析范围明确

### 2. 数据准备 [data_processing]

- 加载 DEM 数据
- 用 `raster_info` 检查 DEM 分辨率和 CRS
- 用 `raster_statistics` 检查高程范围和 NoData
- 确认投影坐标系（地理坐标系需先用 `gdal_warp` 重投影）
- 如 DEM 范围大于分析区域，用 `gdal_clip_raster_by_extent` 裁剪
- **数据传递**：输出预处理后的 DEM 图层名
- **判断标准**：DEM 为投影坐标系，无异常值，范围覆盖分析区域

### 3. 水文分析 [raster_terrain]

- 使用 `grass_r_watershed` 执行流域提取，关键参数：
  - `threshold`（汇流累积阈值）：控制水系密度
    - 小值（如 100）→ 密集水系，适合小流域
    - 大值（如 10000）→ 稀疏水系，适合大流域
    - 推荐：先用中等值试算，根据结果调整
  - 输出产品：流向（drainage）、汇流累积（accumulation）、流域边界（basin）、水系网络（stream）
- 地形衍生分析（按需）：`slope`（坡度）、`aspect`（坡向）
- **数据传递**：输出流域栅格、水系栅格、汇流累积栅格
- **判断标准**：水系网络连续无断裂，流域边界闭合

### 4. 矢量化处理 [vector_spatial]

- 流域边界栅格转矢量：`raster_to_vector`
- 水系网络矢量化：`raster_to_vector`（线类型）
- 用 `add_geometry_attributes` 计算各子流域面积
- 用 `add_geometry_attributes` 计算各水系段长度
- 按需计算流域形态参数（面积、周长、形状系数）
- **数据传递**：输出流域矢量图层和水系矢量图层
- **判断标准**：矢量化结果完整，面积统计合理

### 5. 成果制图 [cartography_layout]

- 制作流域水文专题图：
  - 流域边界用面填充（不同子流域不同颜色）
  - 水系网络用蓝色线（按等级设置线宽）
  - DEM 山体阴影作为底图
- 标注主要水系名称和流域面积
- 导出流域分析报告

## 常见问题处理

- 水系断裂 → DEM 存在空洞或平坦区域，需先填洼处理
- 流域边界不闭合 → DEM 范围不够大，需扩大 DEM 覆盖范围
- 水系过密或过疏 → 调整 `threshold` 参数值
- 小流域被合并 → 降低 threshold 值以提取更细的子流域

## 输出检查清单

- [ ] DEM 为投影坐标系且无空洞
- [ ] 水系网络连续无断裂
- [ ] 流域边界闭合完整
- [ ] 各子流域面积统计合理
- [ ] 水文专题图已导出
