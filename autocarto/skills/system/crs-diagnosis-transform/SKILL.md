# 坐标系诊断与批量转换

## 概述

本 skill 提供坐标参考系统的诊断、推荐和批量转换能力，确保多源数据在同一坐标系下协同工作。

## 前置条件

- 至少一个图层已加载到工程中
- 需要进行空间分析或多图层叠加操作

## 工作流步骤

### 1. CRS 状态扫描

- 使用 `get_layers_info` 获取所有图层的 CRS 信息
- 列出各图层 EPSG 代码和投影名称
- 标记 CRS 缺失或不一致的图层
- **判断标准**：所有图层 CRS 状态已记录

### 2. CRS 诊断

- 识别 CRS 不一致问题（地理坐标系 vs 投影坐标系混用）
- 检测缺失 CRS 的图层
- 评估当前 CRS 是否适合目标分析（如面积计算需投影坐标系）
- **判断标准**：问题图层已识别

### 3. 目标 CRS 推荐

- 根据数据范围推荐合适的投影坐标系
- 中国区域常用：CGCS2000（EPSG:4490）、UTM 分带
- 全球数据：WGS84（EPSG:4326）
- **判断标准**：目标 CRS 已确定

### 4. 执行转换

- 使用 `reproject_layer` 或 `crs_reproject_vector` 执行坐标系转换
- 缺失 CRS 的图层使用 `crs_define_projection` 定义投影
- **判断标准**：所有图层 CRS 一致

### 5. 验证结果

- 重新检查所有图层 CRS 一致性
- 确认转换后数据范围和要素位置正确
- **判断标准**：CRS 统一，数据位置正确

## 常见问题处理

- 转换后数据偏移 → 原始 CRS 定义错误，需先正确定义再转换
- 缺失 CRS 不知道原始坐标系 → 用 `crs_find_projection` 尝试识别
- 转换后面积/距离不准 → 确认目标 CRS 为投影坐标系

## 输出检查清单

- [ ] 所有图层 CRS 已扫描
- [ ] 问题图层已识别
- [ ] 目标 CRS 已确定
- [ ] 所有图层 CRS 统一
- [ ] 转换后数据位置正确
