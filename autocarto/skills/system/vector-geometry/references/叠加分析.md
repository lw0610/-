# 叠加分析

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先核实两个真实输入的几何类型、空间范围、CRS 和有效性。显示叠加使用动态投影；分析算法是否自动转换输入、输出采用何种 CRS 以真实算法为准。仅在算法或量算要求下生成转换副本。

intersection 保留重叠部分和两侧属性；union 保留两侧覆盖并拆分重叠；difference 从第一输入减去第二输入；symmetric_difference 保留非重叠部分；clip 按掩膜保留输入内容。先确认属性来源、输入顺序和期望几何，再选择工具。

无效几何先按可追溯方式修复，属性字段冲突用清晰前缀。碎片不能默认按固定面积阈值删除，容差与阈值须有数据精度或任务依据。检查输出范围、要素数量、属性完整性和抽样空间关系；空结果可能源于无交集，也可能为 CRS、过滤条件或无效输入导致，须报告真实原因。
