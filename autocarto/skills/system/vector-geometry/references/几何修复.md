# 几何修复

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先用 check_validity 记录无效、空和重复几何的数量、类型及位置，再决定修复。fix_geometries 可能改变几何类型、部件数或拆分要素，不能只比较一项计数；保留原始数据并记录来源标识。

delete_duplicate_geometries 去除完全重复几何，remove_null_geometries 处理空几何，multipart_to_singleparts 仅在确需逐部件分析时使用。重复几何与重复属性记录不同，不能混用。必要时用 grass_v_clean 做拓扑清理，但应说明容差、单位和修改范围，避免过大容差破坏真实细节。

结果用 check_validity 再检查，并比较前后数量、类型、范围、面积或长度及属性关联。create_spatial_index 可改善后续空间查询，但索引成功不等于几何有效。仍失败的对象列出，不以“接近零”掩盖分析关键错误。
