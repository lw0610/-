# 缓冲与邻近分析

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先确认输入几何、距离含义和单位，再选择固定距离、按字段变宽、单侧或渐变缓冲。buffer 用于统一距离；variable_width_buffer 按字段变化；single_sided_buffer 用于线的一侧；tapered_buffer 用于线两端宽度渐变。具体参数和字段要求以当前工具目录为准，不能把半径与直径混用。

正距离通常外扩，面负缓冲可能缩至空；线方向会影响单侧左右。端点和连接样式影响边缘形状，segments 增大能使圆弧更平滑，但也增加顶点与计算量。需要合并覆盖范围时 dissolve，需保留单要素归属时不要融合。distance_matrix 产生多对多关系，数据量大时限制最近邻数量；最近目标距离不等于路网行程。

检查输出几何类型、有效性、空结果、距离和范围。异常放大优先检查单位，负缓冲为空核实输入宽度，边缘粗糙再调整分段。统计覆盖时消除重复计数，报告距离规则、测量方式和输出图层。
