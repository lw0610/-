# 流域水文分析

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

核实 DEM 的高程/水平单位、分辨率、NoData 和分析边界，确认是否需要填洼或水系约束。NoData 空洞与真实洼地不同，不自动把所有低地填平。流域出口点应与汇流路径核对，边缘截断会改变上游汇水范围。

grass_r_watershed 的 threshold 控制最小汇流支撑与河网密度，单位以当前工具定义为准，不能把像元数误称平方公里。按实际需要选择 accumulation、drainage、basin、stream 等输出；记录单流向/多流向等算法选项，调整阈值时比较网络连续性及尺度。

检查汇流累积值、流向约定、河网连通、子流域边界和出口关系。需要矢量化时核实类别和拓扑，长度/面积使用明确量算方式。范围不足、填洼或数据空洞引起的偏差必须随成果报告，不以看起来连续作为正确性的充分证据。
