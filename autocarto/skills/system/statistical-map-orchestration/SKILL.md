# 统计专题图制作流程

用于行政区数值分布、年度统计指标分级设色等任务。指标由用户和数据共同确定，可为人口、经济、教育、资源等；不预设 GDP、年份、区域或固定色阶，不把行军路线流程用于统计专题图。

## 1. 确认任务与输入

- 优先核对工程已有图层与文件，明确行政区层级、统计年份、指标、单位、数据来源、统计表格式和输出要求。资料已经提供时不重复要求用户填写。
- 行政区输入须为真实 Polygon/MultiPolygon，关联键必须与统计表一致；不凭相似名称猜测对应关系。数据工程阶段负责检查，而非要求编排角色自行清洗。
- 总量、占比、密度、增幅不可混称。缺少分母、两期数据或量算依据时，不把现有指标擅自改成比例、密度或变化率。
- Plan 模式只读取本技能并调用 `query_build_capabilities` 核对能力、形成计划，不运行数据生成、加载、符号化或布局工具；后续步骤在 Build 模式执行。

## 2. 委派数据准备

调用 `task` 委派 `data_engineer`，保留原始需求、输入路径、年份和已经确认的指标信息；由该角色先读取 `statistical-data-preparation`。

已有所需数值字段的行政区面时，数据角色核验字段类型、统计口径、年份、来源、缺测和有效值范围后可直接交接，不强制重找 CSV 或重新关联；保留已有真实字段，不假造派生 metadata 或 manifest。

新 CSV 数据由数据角色使用 `data_prepare_statistical` 先只验证、再生成独立派生文件并加载。必须交接真实结果中的 metadata、counts、未匹配/缺测/排除报告、value_range、paths，以及实际载入的专题图层、数值字段和标注字段；不要把文件名猜成图层名。

关联失败时先核对字段、表格式和名称。仅部分未匹配、仍有足够有效数值可分级时，保留完整问题清单，以 `allow_unmatched=true` 继续派生并将未匹配面保留为 NULL，最终用灰底和文字说明；无需逐项人工确认。不得模糊猜名、填零或隐去问题。重复键、非法数值或无可用数据仍需定位问题，不能伪造成功。未匹配与空单元格缺测须分别报告。

## 3. 委派制图与布局

确认数据交接完整后，调用 `task` 委派 `cartographer`，原样携带数据产物、统计口径和质量报告；由该角色读取 `thematic-map-styling` 与 `print-layout-statistical`。

执行顺序为数值分级设色 → 地名标注 → 读取真实渲染状态 → 锁定地图图层与范围 → 原生分级图例和说明要素 → 版面核验 → 导出。数据只有一个有效数值、字段非数值或真实分类失败时，返回阻塞原因，不输出伪装成分级图的统一填色地图。

## 4. 验收与交付

- 交付中保留行政区层级、指标、年份、单位和来源，实际分类方法、分级数量及区间，以及缺测/未匹配/排除情况。
- 核对 `graduatedSymbol`、专题字段、实际分级区间和图例条目一致；版面范围和地图 CRS 正确，只包含本次专题及必要底图。
- 返回布局名称、实际元素 ID、本次实际生成的派生数据与 manifest 路径（已有图层分支注明复用）、导出工具确认的成品路径。未指定格式时使用 `export_print_layout` 导出 PNG；用户明确要求 SVG 时使用 `layout_export_svg`，其他格式先核对实际工具能力。
- 导出文件存在不等于专题表达正确，必须同时具备渲染和版面核验结果。存在未解决问题时明确说明，不把工具报错改写为成功。
- 统计图核验使用真实工具返回的渲染与布局状态；现有行军路线质量模型没有统计图验收规则，不自动接入，也不把军标或角点规则作为本流程验收标准。用户要求进一步视觉评审时，明确当前流程的检查范围。

## 5. 工具故障处理

布局工具返回内部异常（如 `ImportError` 或 `handler 执行失败`）时，不得据此认定当前工程损坏，也不得擅自调用 `close_instance`、`open_project`、`create_project` 关闭、重开或重置工程。保留已生成数据、已加载图层及已创建布局。

仅当原始错误明确指出可修正的参数或前置条件时，才针对该原因修正并重试一次；无明确依据或重试仍失败时停止该阶段，不重复同参数、不只更换 `item_id` 或布局名碰运气。`cartographer` 向编排返回工具名、实际参数、原始错误及已完成产物；`orchestrator` 保留原始错误并报告阻塞，不把未验证的故障推测改写成恢复指令。
