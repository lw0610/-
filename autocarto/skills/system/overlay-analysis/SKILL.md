# 矢量叠加分析

## 概述

本 skill 提供矢量图层之间的空间叠加分析能力，支持多种叠加运算类型。适用于区域提取、空间合并、差异对比等场景。

## 前置条件

- 至少两个矢量图层已加载到工程中
- 所有输入图层 CRS 一致（不一致时需先用 `reproject_layer` 统一）
- 输入图层几何有效（建议先用 `check_validity` 检查）

## 工作流步骤

### 1. 前置检查

- 用 `get_layers_info` 确认输入图层存在
- 用 `get_active_layer_info` 检查各图层的 CRS 和几何类型
- CRS 不一致时：明确报告差异，建议先统一坐标系再执行叠加
- 使用 `check_validity` 检查几何有效性，无效时先 `fix_geometries` 修复
- **判断标准**：所有输入图层 CRS 相同，无效几何数为 0

### 2. 选择叠加操作

根据分析目标选择操作类型：

| 需求 | 工具 | 说明 |
|------|------|------|
| 提取两图层重叠区域 | `intersection` | 保留两图层属性 |
| 合并两图层所有区域 | `union` | 保留所有属性，重叠区域合并 |
| 从 A 中减去 B 的范围 | `difference` | 保留 A 的属性 |
| 提取非重叠区域 | `symmetric_difference` | 两侧非重叠部分 |
| 按掩膜裁剪 | `clip` | 仅保留掩膜范围内的部分 |

- **决策指南**：
  - 需要保留两图层属性 → `intersection` 或 `union`
  - 只需裁剪范围不需叠加属性 → `clip`
  - 需要找出 A 有但 B 没有的区域 → `difference`

### 3. 执行分析

- 调用对应的叠加分析工具
- 设置输出图层名称（建议命名：`{操作类型}_{图层A}_{图层B}`）
- **判断标准**：工具返回成功，输出图层已加载

### 4. 后处理（按需）

- 使用 `dissolve` 按属性融合结果（消除内部边界）
- 碎片多边形清理：用 `extract_by_expression` 过滤面积过小的要素（如 `$area > 100`）

### 5. 验证输出

- 检查输出要素数量和属性完整性
- 确认空间范围正确（不超出输入图层范围）
- **判断标准**：要素数 > 0，属性字段完整，空间范围合理

## 常见问题处理

- 叠加结果为空 → 检查两图层是否有空间重叠（范围是否相交）
- 执行报错"无效几何" → 先 `fix_geometries` 修复两个输入图层再重试
- 结果出现大量碎片多边形 → 后处理中按面积阈值过滤
- CRS 不一致报错 → 用 `reproject_layer` 将所有图层统一到同一 CRS

## 输出检查清单

- [ ] 输入图层 CRS 一致
- [ ] 输入图层几何有效
- [ ] 叠加操作类型正确
- [ ] 输出要素数量合理
- [ ] 输出属性字段完整
