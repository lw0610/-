# 空间聚类分析

## 概述

本 skill 提供基于空间位置的聚类分析能力，用于发现空间分布模式和热点区域。

## 前置条件

- 输入为点要素图层
- 图层使用投影坐标系（距离计算更准确）
- 要素数量满足聚类最低要求（建议 > 30）

## 工作流步骤

### 1. 数据准备

- 确认输入为点要素图层
- 检查坐标系（投影坐标系下距离计算更准确）
- 确认要素数量满足聚类最低要求
- **判断标准**：点要素图层，投影坐标系，要素数 > 30

### 2. 选择聚类方法

- `dbscan_clustering`：DBSCAN 密度聚类
  - 适用于不规则形状的聚类
  - 需设置邻域半径（eps）和最小点数（min_samples）
- `kmeans_clustering`：K-Means 划分聚类
  - 适用于已知聚类数量的场景
  - 需设置聚类数（k）
- **判断标准**：方法匹配数据特征

### 3. 参数设置

- DBSCAN：邻域半径建议根据数据密度调整，最小点数通常 ≥ 5
- K-Means：聚类数可通过肘部法则确定
- **判断标准**：参数合理

### 4. 执行聚类

- 调用对应聚类工具
- 结果写入聚类标签字段
- **判断标准**：聚类标签字段已生成

### 5. 结果统计

- 各聚类的要素数量
- 聚类中心坐标
- 噪声点数量（DBSCAN）
- 聚类质量评估
- **判断标准**：统计结果完整

## 常见问题处理

- 所有点归为一类 → DBSCAN 的 eps 过大，减小邻域半径
- 所有点为噪声 → DBSCAN 的 eps 过小或 min_samples 过大
- K-Means 结果不稳定 → 增加迭代次数或尝试不同 k 值
- 聚类结果不理想 → 检查坐标系是否为投影坐标系

## 输出检查清单

- [ ] 输入为点要素且使用投影坐标系
- [ ] 聚类方法和参数合理
- [ ] 聚类标签已生成
- [ ] 各聚类统计完整
- [ ] 噪声点已识别（DBSCAN）
