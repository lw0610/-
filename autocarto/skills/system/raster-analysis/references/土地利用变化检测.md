# 土地利用变化检测

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

这是两期分类数据比较的方法，先核实时间、类别编码及名称、分类粒度与数据版本。分类体系不同时先建立有依据的映射关系，再比较共同分析区域；不能把类别名称相似当语义一致。

逐像元比较必须统一分析网格的分辨率、范围和对齐，分类重采样用最近邻。用 raster_calculator 生成前后类别组合时，编码乘数必须大于类别最大编码并记录解码规则，不固定使用百位编码。矢量方案用 intersection 保留两期属性，再用 field_calculator 生成变化字段；筛选变化可用 extract_by_expression。

NoData 不等于一种有效类别。统计转移面积时说明共同有效区、排除区域及面积量算方式，核对变化面积与总面积平衡。边界伪变化先查配准和分类误差，不随意删除小斑块。交付时间、类别映射、方法、变化图层和转移统计。
