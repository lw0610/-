# 选址适宜性分析

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

确认评价因子、来源、时间、单位、评分方向、权重和排除条件。硬性限制先生成掩膜，不把禁止条件通过其他因子高分抵消。没有确定依据时等权重只能是披露的试算基线，不能报告成专家权重。

多因子逐像元叠加需相同分析网格和共同有效范围，按需矢量栅格化并对齐。用 raster_reclassify 把量纲不同因子映射到有依据的评分尺度，确认成本型/收益型方向；权重非负且归一化，再由 raster_calculator 加权。NoData、缺测和排除区分别处理，不默认零分。

检查评分值域、权重和、等级边界、有效面积与排除面积。改变权重或阈值做敏感性比较，报告结果依赖的假设；若需矢量化与面积统计，说明量算方法。输出因子清单、评分表、权重、限制掩膜及可复算参数。
