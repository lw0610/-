# 地形衍生

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先核实 DEM 范围、分辨率、高程单位、水平单位、数据类型和 NoData。像元分辨率决定可解释尺度，升采样不会增加真实地形细节。坡度/阴影涉及水平与垂直单位比值，不使用一个固定系数适配所有纬度或 CRS。

按需求选择 slope、aspect、hillshade、terrain_ruggedness、terrain_tpi 或 gdal_contour，无需把所有衍生产品都算一遍。坡度确认度或百分比；坡向确认北向定义和平坦区约定；阴影记录光源方位角、高度角和比例因子。等高距按高差、分辨率与出图尺度确定，不能把一种地形的等高距当固定默认。

检查输出值域、空间范围、NoData 和边缘效应，坡度度值通常在零到九十之间，坡向平坦标志依算法而异。条带或孔洞先查输入质量，不盲目平滑；填补空洞需要说明方法和影响。记录算法、参数、单位及真实产物。
