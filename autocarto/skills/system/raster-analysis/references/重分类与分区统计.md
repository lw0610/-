# 重分类与分区统计

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先分析值域、分布、数据类型和 NoData，再选择等间距、自然断点或有依据的自定义断点。用 raster_reclassify 前明确区间左右闭合规则，避免断点重复或遗漏；分类结果应覆盖全部预期有效值。

raster_zonal_statistics 要明确分区、目标波段、统计指标、字段前缀和像元计入规则。计数、总和、均值、面积含义不同：像元总和不能无条件报告为实际人口或面积。分区与栅格的坐标变换以算法处理能力为准，NULL 先查覆盖、掩膜和有效像元，不直接补零。

需要分类面时用 raster_to_vector，保留类别字段并核实碎片和几何有效性。报告重分类表、NoData策略、统计分母和真实输出；各类数量或面积之和应能与有效研究范围解释一致。
