# 空间插值

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

先确认离散样点、数值字段、有效记录、重复坐标、异常值和空间覆盖。点数多不代表分布均匀；研究范围外推和稀疏边缘应单独标识不确定性。

idw_interpolation 依据距离加权，幂次越大越局部，可能出现牛眼效应；tin_interpolation 在三角网内插值，需注意凸包之外和断裂线。分辨率应与采样密度、研究尺度和计算预算匹配，不能因输出需要更清晰就任意加密。搜索半径、最小/最大邻点及范围依当前算法实际参数设置。

检查输出值域、NoData、边缘伪影和采样支撑范围。比较训练点处预测只反映拟合情况，不能称独立交叉验证；精度评价应留出样本或按空间分组验证，记录 MAE/RMSE 的单位和样本数。报告方法、参数、范围及不可靠区域。
