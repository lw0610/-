# 栅格代数

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

核实输入波段、物理含义、数值比例因子、数据类型、NoData 和范围。多栅格逐像元运算需要共同分析网格；必要时用 gdal_warp 对齐范围、分辨率和网格原点，连续数据与分类数据采用适当重采样，不为显示而重复转换。

raster_calculator 引用真实图层和波段，表达式形如双引号包围的图层名@波段号。差值、比值和归一化前核实单位是否兼容、比例因子是否已应用、分母是否为零。计算指数须从数据元信息确定波段，不固定某传感器的波段序号。

明确 NoData 传播规则，不能把缺测填成零或把某个数值哨兵当有效数据运算。必要时用浮点类型避免溢出与整数除法。检查结果最小/最大值、有效像元数量和空间掩膜，报告表达式、对齐参数和异常区域。
