# 中国官方统计数据获取（china-statistics-data）

本方法用于从国家统计局获取 GDP、人口、就业、工业、农业、能源、环境、交通、教育、普查、年鉴等社会经济统计，服务行政区关联、专题制图、分析、图表和报告。沿用 GeoCode 同名技能的导航与来源核验方法，按本项目工具和流程交接方式适配；原文、固定版本和许可见本包 `UPSTREAM.md`、`upstream/china-statistics-data.md` 和 `LICENSE`。

## 1. 浏览器能力

国家数据平台是 JavaScript 应用，指标树、表格维度、筛选和导出需要通过 Playwright MCP 操作可见页面。当前项目采用包装工具：先 `browser_check_environment`，再 `browser_list_tools` 获取实际工具名及 `inputSchema`，然后用 `browser_call_tool` 传 `tool_name` 和 `args`。不要直接调用模型工具列表里不存在的 `browser_navigate` 等内部名称。

如果浏览器未启用或不可用，报告实际检查结果，请用户在扩展服务设置中启用或修复浏览器。准备就绪后继续从官方页面操作；不能以猜测门户接口、隐藏请求参数或非官方镜像代替尚未完成的网页取数。已有普通公开文件链接可直接下载。搜索摘要、网页标题或截图完成提示不代表已读到完整统计数据；真实返回的图片附件则可以作为视觉读取的来源。

每次导航或筛选后读取当前快照，再定位真实控件。以下入口来自上游记录，页面可能调整；入口失效时从国家数据主页的当前导航进入，不把旧 URL 或旧 DOM 当作永久规则。

## 2. 国家数据平台结构与入口

主要入口：`https://data.stats.gov.cn/dg/website/page.html`。主页：`https://data.stats.gov.cn/`；统计年鉴：`https://www.stats.gov.cn/sj/ndsj/`。

上游记录的顶层导航为：

```text
国家数据平台
├── 首页
├── 月度数据
├── 季度数据
├── 年度数据
├── 普查数据
├── 地区数据
├── 部门数据
├── 国际数据
├── 出版物
├── 我的收藏
└── 帮助
```

先根据空间层级和时间频率选入口，再操作指标和表格。专题制图常用“地区数据”；不能把所有中国统计任务一律导向分省年度页。

| 页面标识 | 导航名称 | 数据内容 | 官方入口 |
| --- | --- | --- | --- |
| `fsMonthData` | 分省月度数据 | 省、自治区、直辖市的月度 CPI、工业等指标 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/fsMonthData |
| `fsQuarterData` | 分省季度数据 | 省、自治区、直辖市的季度 GDP 等指标 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/fsQuarterData |
| `fsYearData` | 分省年度数据 | 省级年度统计，年度省域专题图的常用入口 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/fsYearData |
| `mainMonthData` | 主要城市月度价格 | 主要城市消费价格、商品价格等月度数据 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/mainMonthData |
| `hongKongYearData` | 香港特别行政区年度数据 | 香港年度统计 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/hongKongYearData |
| `macaoYearData` | 澳门特别行政区年度数据 | 澳门年度统计 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/macaoYearData |
| `taiwanYearData` | 台湾省年度数据 | 台湾年度统计 | https://data.stats.gov.cn/dg/website/page.html#/pc/national/taiwanYearData |

快速选择：

| 地域 | 月度 | 季度 | 年度 |
| --- | --- | --- | --- |
| 省、自治区、直辖市 | `fsMonthData` | `fsQuarterData` | `fsYearData` |
| 主要城市 | `mainMonthData`（月度价格） | 按当前网站核查有无目标指标 | 网站提供相应城市年度入口时使用该入口 |
| 香港 | 按当前网站核查 | 按当前网站核查 | `hongKongYearData` |
| 澳门 | 按当前网站核查 | 按当前网站核查 | `macaoYearData` |
| 台湾 | 按当前网站核查 | 按当前网站核查 | `taiwanYearData` |

省域年度任务优先 `fsYearData`，月度/季度任务分别使用相应入口。香港、澳门、台湾年度数据查各自专页，不强行从内地省级表中寻找。全国总量、普查、部门或国际数据按其实际导航进入；不得把省级汇总替代网站提供的全国口径。

## 3. 地区选择器

`fsMonthData`、`fsQuarterData`、`fsYearData` 的地区选择器在上游记录中提供“序列”选项，可一次展示所有省级单位。全国各省对比或省域制图时，若当前页面仍有该项，优先选“序列”，避免逐省点击漏项；只有少数指定地区时才逐项选择。

“序列”必须以当前快照核实。新版若改为多选或“全部地区”，按实际控件操作。核对最终表格地区名单与行数；不假定每项指标必有 34 个地区，不将“全国”合计行误当一个省，也不因网站缺少某地区就用零填补。

## 4. 导出前确定具体数据

国家数据平台的相似表格可能使用不同指标、时间范围、单位和维度。取得最初可见表格不等于已确定交付内容。先把用户需求、流程参数与网页的真实指标说明对应起来：

- **指标**：页面上的完整名称或指标类别；总量、增速、指数、现价、不变价等口径不能混用。
- **时间**：年份、月份、季度或其他期次；单期值与累计值应区分。
- **地域**：全国各省、指定省份、主要城市、港澳台或其他明确范围。
- **表格形态**：一个指标跨多个地区、一个地区的多个指标，或连续时间序列。
- **单位与注释**：保留页面单位、统计范围、缺失标识及脚注。

用户或流程已经明确的内容直接采用，不再逐项重复询问。仅对确实缺失、无法从上下文确定且会改变结果的条件请求补充，给出页面上实际可选项；不能用不存在的年份或指标让用户选择。

## 5. 获取与成果交接

优先使用官方页面的导出功能，保留原始下载文件。没有导出入口时，可提取真实页面表格；官方以图片或 PDF 发布的表格也可以作为来源，下载原件后读取并整理。下载按钮被点击但没有真实文件时，不报告下载成功。

独立统计取数默认按上游方式整理为 `.xlsx` 工作簿；调用流程已明确要求 CSV 时，按该流程交付真实 UTF-8 CSV 和来源记录即可完成取数步骤，不额外强制生成 Excel。无论哪种格式，都保留清楚的字段名、原始地区名称和时间标签。Excel 可用数据表及来源说明表，CSV 可用来源列或配套说明文件：

| 内容 | 要求 |
| --- | --- |
| 数据表 | 地区（有官方代码时保留代码）、时间、指标、数值、单位；表格形态按任务选择，不无故丢弃原始维度 |
| 来源说明 | 机构、原始页面/下载 URL、访问日期、筛选条件、单位、指标定义、脚注、表号或页码与整理方式 |
| 原始文件 | 保存网站导出或下载的原件；整理后的表记录所据原件，不覆盖原件 |
| 补充数据 | 通过来源列或独立说明表逐项追溯，不能伪装为原始国家统计局表 |

### 从原件读取并整理表格

1. 复用已经取得的原件、来源地址与表号，不为相同内容重新开始搜索。使用 `file_read` 读取真实文件。图片或 PDF 必须有模型实际可读取的附件或文档内容；仅返回路径、字节数、文件类型或“截图已完成”时，不能声称已经看到了表格。
2. 根据真实内容读取表头、地区、时间、数值、单位和脚注。视觉转录或 OCR 提取有来源依据的数值不等于编造；可以使用它们整理图片和扫描表格。逐项核对数字、行列对齐及单位，无法辨认的单元格保留缺失并指出位置，不用模型常识、估算或其他年份补写。
3. 可用 `shell_execute` 检查并调用本机已安装的文本、PDF、表格或 OCR 工具。先核实命令及依赖是否可用，按实际工具 schema 执行，不假定特定程序、Python 库或模型文档能力存在。提取结果要与原件核对；执行失败的命令或空输出不是数据。
4. 在当前会话输出目录，通过 `file_write` 将核对后的内容写为真实 UTF-8 CSV，或通过 `shell_execute` 使用可用表格工具生成 `.xlsx`。文件工具的相对路径以该目录为基准，读取源文件须在允许访问的范围内。网站已导出所需格式时直接复用。不得通过改扩展名冒充格式转换；同时提供 Excel 与 CSV 时，二者的地区、时间、单位和数值应一致。
5. 读取成果并核对字段、记录数和来源，保留原件、原始 URL、表号或页码及提取方式。在本项目流程中，用当前冻结的同次 `find_id` 和行名调用 `data_register`，提交整理后的合格统计表及原始来源。登记通过才交接；图片或 PDF 原件不能直接冒充 CSV、TSV 或 XLSX 统计表，消息中的路径也不能替代登记回执。

如果缺少实际视觉、文档解析或写表能力，报告缺少哪一步、已经取得哪些原件、哪些数据尚未核实。不要反复截图或下载相同文件；不要因为文件格式问题默认改用其他年份、指标或统计口径。只有用户接受范围变化且替代数据确实可用时，才能按新的要求继续。

交付前核查真实文件存在，表头、期次、单位、数值类型、地区名单、合计行、重复记录和缺失标识符合任务。仅删除明确属于展示用途的表头或空行，不把“—”“…”等缺失或保密标识当作零。来源页与访问日期必须可追溯。

### 页面表格的另一种 CSV 导出方式

下游统计关联要求 UTF-8 CSV 时，除了使用 `file_write` 或已安装的转换工具，也可以由浏览器把已经取得的页面表格导出为 CSV。先用 `browser_list_tools` 读取实际工具名与 schema；当前固定 Playwright MCP 版本提供 `browser_evaluate`，通过 `browser_call_tool` 调用它在页面中执行导出操作。若实际服务提供其他等价页面执行工具，则按返回的真实名称与 schema 使用，不猜工具名和参数。这种方法针对真实页面表格；图片和 PDF 的提取按前面的原件读取方法处理。

1. 根据当前快照选中真实数据表，读取表头与单元格；分页或虚拟滚动表必须先遍历并取得全部所需记录，不能把当前首屏当作完整结果。核对行列数、地区和期次。
2. 将已取得的单元格按 CSV 规则编码：单元格中的双引号写成两个双引号，含逗号、引号或换行的字段加双引号，行以 `\r\n` 分隔。使用 UTF-8，可加 BOM 便于 Excel 识别中文；不得修改数值、补造缺失值或用推测的表格替代真实页面内容。
3. 在页面内创建 `Blob([csvText], {type: 'text/csv;charset=utf-8'})`，用临时 `<a download="统计数据.csv">` 触发浏览器下载。这只整理已呈现的数据，不调用隐藏接口、读取浏览器凭据或向其他网站发送数据。
4. 等待浏览器报告下载完成并返回真实文件路径。下载结果需核对与页面记录数和字段一致，保留来源说明及已经取得的 `.xlsx` 原件，再按同次查询调用 `data_register`。仅返回文件名、Blob URL 或“已点击”不算文件交付；没有额外 Excel 原件不影响合格 CSV 的登记。

如果用户另行明确要求 `.xlsx`，必须使用真实可用的转换能力；浏览器导出的 CSV 不是 Excel 工作簿，不能通过改扩展名冒充。仅要求 CSV 的制图流程以合格 CSV 和来源记录为本步成果，不把上游独立取数的默认 Excel 格式扩大为所有流程的额外交付门槛。

## 6. 缺失地区或缺失值

**先在国家统计局平台内查找，再考虑外部补源。** 内地省级表缺少港澳台等所需数据时，先检查 `hongKongYearData`、`macaoYearData`、`taiwanYearData` 等相应专页及相关年鉴。不能看到主表缺失就直接转用任意搜索结果。

平台仍无目标值时，使用 `web_search` 查找可核验的补充来源，优先官方统计机构、政府出版物、统计年鉴。阅读原始发布页并核对时期、指标定义、单位及统计范围；搜索摘要不能作为最终数值来源。

所有非国家统计局来源必须在成果中标明机构、URL、访问日期，以及单位或定义差异：Excel 使用来源列或说明表，CSV 使用来源列或随附说明文件。可比的数据才能合并；不可比或时间不一致的数值保留说明或单列展示，不强行拼接、不凭模型估算补齐。确实未取得的值保留缺失并说明查找结果。
