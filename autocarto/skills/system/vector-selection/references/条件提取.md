# 条件提取

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

用 get_layers_info 和图层详细信息确认真实图层、字段类型、值域与总数。简单选择用 selection_by_attribute 或 selection_by_expression，选择后仍是原图层；需要独立结果时用 extract_selected_features。不能假设选择操作已经生成新图层。

extract_by_attribute 面向单字段条件，extract_by_expression 适合多条件组合，extract_by_location 按明确空间关系提取。表达式中字段用双引号、字符串用单引号，NULL 用 IS NULL。组合 AND/OR 时加括号明确优先级，数值字段不能按字符串比较。空间相交、包含和被包含含义不同，边界接触是否计入也应明确。

只用工具返回的真实图层和字段，不猜测中间层。检查匹配数量、总数、比例与抽样记录；空结果可能是合理结论，应先核查语法、值域和空间范围，不强行生成非空数据。报告完整条件、输出图层和异常记录。
