# 随机抽样

显示和叠加使用 QGIS 动态投影；只有分析、量算明确需要时才转换。先核实源 CRS、坐标单位和算法处理方式，不能因显示 CRS 不同而批量重投影；定义 CRS 只改元数据，重投影才改变坐标。转换时生成独立结果，核对范围、位置和精度。

确认总体、唯一标识、抽样单位和数量或比例；区分要素抽样与在空间内生成随机点。random_selection 改选择集，random_extract 生成独立图层；random_points_in_polygons 和 random_points_in_extent 用于范围内点生成，不能视为从原记录随机抽取。

需要可重复时记录工具实际支持的随机种子、总体版本与过滤条件。分层样本先明确分组及每组分配，不能把一次均匀随机结果必然视为具有空间代表性。最小间距、边界和孔洞限制可能导致未达到请求数量，须查看实际返回。

检查去重后的数量、总体包含关系、分组比例和空间分布。抽样不足时定位约束原因，不能复制记录凑数；验证/训练拆分应避免同一对象或近邻信息泄漏。交付真实样本、参数与未满足项。
