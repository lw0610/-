# 行军路线图

## 一、明确用户提供的材料

用户可以提供史料原文、包含史料的文件或文件夹，也可以直接提供已经整理好的路线数据集。先分清哪些是史料、哪些是路线数据、哪些是底图或配图。只有“制作行军路线图”的要求而没有路线材料时，先请用户提供材料，不凭空编造行动。

本流程使用以下十二项背景数据，均由用户提供，用于表现本次路线及周边地区。清单按从下到上的叠放顺序排列，首次加载也按此顺序进行：

1. **省域（面）**：省级行政区范围，用作地图背景和跨省位置参照，需要能够识别省名的属性字段。
2. **地形晕渲（栅格）**：表现山地、平原和地势起伏，叠在省域背景之上。
3. **河流面（面）**：面状河流、水域，用于表现有宽度的水面。
4. **鄂豫皖革命根据地（面）**：表现该根据地的史料示意范围，需要名称及范围性质说明。
5. **鄂豫陕革命根据地（面）**：表现该根据地的史料示意范围，需要名称及范围性质说明。
6. **陕甘宁革命根据地（面）**：表现该根据地的史料示意范围，需要名称及范围性质说明。
7. **河流线（线）**：线状河流，需要河流名称字段，用于绘制河道和标注河名。
8. **地区界线（线）**：行政区域的界线，用于区分区域边界，叠在河流线上方。
9. **国道（线）**：国道线路，用于突出主要公路；与普通公路数据区分使用。
10. **公路（线）**：公路线路，用于表现道路交通背景。
11. **铁路（线）**：铁路线路，用于表现铁路交通背景。
12. **市级驻地（点）**：市级行政中心的位置，用于表现沿途城市，需要城市名称字段；本流程以市级驻地替换原来的县级城市驻地。

用户可以提供单个文件、包含这些数据的文件夹，或指定已经导入的图层。按实际内容、几何类型和属性字段对应上述类别，不要求文件名与清单相同，也不限定存放目录或名称字段必须叫什么。文件夹是候选材料集合，本次选用上述背景和用户明确补充的图层；不把同目录其他文件自动加入地图。工程中已有同源图层时直接复用，不重复加载。

准备时向用户一次说明尚缺哪些类别。用户可以补充数据、指定已有数据，或明确省略某类背景；不要自行把清单改成可有可无，也不要默认改为联网下载。用户要求自动补充时，再获取对应的缺项。

同时确定地图主题、范围、纸张、路线配色、专题符号和输出格式。用户明确的要求优先；没有指定时，路线和专题点沿用程序原版内置画法，纸张为 A1 横向，成果为 PDF。只有用户明确要求使用某份路线样式表或符号表时才使用其内容；未指定就不加载这些表，红蓝配色要求本身不代表选用样式表。

## 二、整理路线知识并交给用户核对

用户已经提供可用路线数据集，或本次会话已经生成并确认过数据集，且没有要求重新抽取时，直接使用该结果。需要抽取时，把完整史料交给路线知识抽取能力，不由主智能体先改写或概括原文；只有用户明确选用了路线样式表或符号表时才交接该选择，其余情况直接使用原版内置规则生成数据。

整理时保留史料的真实行动关系：

- 按参与主体区分路径。多主体可属于同一条多路进攻路线，但不能串成同一部队的连续行动；同名、上下级或相同颜色不证明主体相同。
- 保留出发、来向、目标、途经、到达、折返的顺序和重复经过的节点。“从 A 向 B 前进，中途受阻，折返 A”保留 A→B→A 的行动指向，不据此补造抵达或占领 B 的事件。
- 区分实际行动与计划、命令、设想。地点并列、静态部署、背景介绍不能据此补出移动路线。
- 主线沿节点前进，分支从连接点分出，汇入线向共同目标汇入。多路趋向同一目标不等于发生会合；无共同点时保留多主线，去向未载时止于最后已知节点。
- 保留事实的原文依据，把歧义关联到具体路线、事件或地点。泛称和未载日期保持原状，同名地点或跨日期的事件不直接合并。
- 地点包括地名、地物和区域；纯方位作为空间关系，定位参照不另画成事件地点。原文明示的坐标注明来源，其余地点通过现有定位能力查询，未确定的标明估算或待确认。
- 图文标注关联真实地点或事件，图片只使用用户提供或有真实来源的材料。

抽取结果进入已有的知识编辑页，用户确认后再制图。用户可以查看和修改路线、地点、事件、部队与图文标注；点击开始制图后使用确认后的数据继续后续工作，不重复抽取。抽取失败时说明原因，不拿其他会话的旧结果代替。

## 三、准备本次制图使用的底图

根据确认后的路线和地点确定地图范围，并留出适当的周边空间。加载本次选用图层时读取其可用性、范围、坐标系和名称字段，报告实际缺项或明显的位置问题，随后继续制图；同源图层已经在工程中时直接复用，只加载缺少的部分。范围读取用于了解数据，不另设反复覆盖验收或数据治理阶段，也不把只看过外接矩形说成已经逐点核验全部路线。

本流程沿用原版的坐标系处理：保留各底图源文件的原始坐标系，坐标系不同是可接受的输入状态，由 QGIS 在显示时动态转换。底图准备只读取并报告坐标系，不重投影、不重新定义或修改坐标系、不为统一坐标系另存、导出、转换格式或创建副本；主智能体也不追加这类任务，不通过处理算法或脚本绕行。经纬度数值、旧坐标系名称，或同一文件夹中其他文件的坐标系，都不能单独证明某份数据的坐标系错误。报告中的坐标系差异不作为整改、阻塞或重试事项。

路线绘制工具内部把经纬度换算到工程坐标系，以及版面定位时的坐标换算，仍沿用原版实现；这些是绘图计算，不改变底图原文件。

把实际使用的图层、来源、名称字段和确认后的路线数据一并交给制图环节，并交代用户明确省略的背景类别。缺少决定路线位置或地图范围的关键数据时，应说明具体缺项。

## 四、连续完成地图绘制和版面编排

底图表达、路线与专题点绘制、版面编排由制图环节连贯完成，不把每次工具调用或每个版面元素机械拆成独立任务。操作顺序以实际依赖为准，已经完成的内容继续使用。

### 整理底图外观与地名

以下是本流程的默认画法，尺寸以 A1 横向纸张为基准，参考原流程的符号效果。用户提供了样式或明确要求时以用户要求为准；换用其他纸张时调整符号和文字尺寸，保持下面的形状、颜色含义和层次关系。这些是流程中的制图要求，不是固定文件名或不能修改的程序参数。

1. **省域**：白色（#FFFFFF）填充，置于地形晕渲下方；深灰（#707070）点划线边界，线宽 0.5 毫米。读取实际省名字段，在面内水平标注省名；采用中文粗体、深灰（#242424），字号 5.2 毫米，白色文字描边 0.7 毫米。显示本次范围内各省的名称，省域面不作为其他标注的避让障碍。
2. **地形晕渲**：保留用户数据已有的晕渲效果，叠在省域背景上方、水域和根据地下方。
3. **河流面**：浅蓝（#A6CEE3）填充，同色实线边界，宽 0.26 毫米。不另加名称标注，避免与河流线的河名重复。
4. **鄂豫皖、鄂豫陕、陕甘宁革命根据地**：三份面图层均使用浅赭色（#F3C98B）填充，填充不透明度 20%；棕色（#9A6A36）虚线边界，宽 0.3 毫米。读取实际名称字段，在面内水平标注根据地名称，棕色文字，字号 3 毫米，白色描边 0.5 毫米。范围重叠时保留各自边界；根据地面不作为其他标注的避让障碍。数据说明统一注明“革命根据地为史料示意范围，不代表实控边界”，保留用户提供的范围性质和局限说明。
5. **河流线**：浅蓝（#A6CEE3）实线，宽 0.46 毫米。读取实际河名字段，以同色文字沿河流就近标出完整河名，字号根据本次纸张选取并保持可读。同名且首尾相接的河段合并标注，不沿同一连续河段重复铺排河名，不拆成单字。
6. **地区界线**：叠加两层线，蓝色（#2399E9）实线宽 0.5 毫米，浅蓝（#A6CEE3）实线宽 0.5 毫米并向一侧偏移 0.4 毫米，形成沿行政界线的双色边界。不添加线名称标注。
7. **国道**：橙色（#FFB957）实线，宽 0.3 毫米，与普通公路区分。
8. **公路**：叠加两层实线，下层黑色（#000000）宽 0.4 毫米，上层浅灰（#C0C0C0）宽 0.3 毫米，形成黑边灰芯。沿用原流程借用的高速公路线型，但不把数据的道路类别改成高速公路。公路和国道均不添加道路名称标注。
9. **铁路**：表现为黑白相间的铁路符号；其形态是黑色底线叠加白色虚线，默认线宽均为 0.4 毫米，白线每段 4 毫米、间隔 4 毫米。不添加线路名称标注。
10. **市级驻地**：用两个同心空心圆表示城市位置，外圆直径 1.8 毫米、内圆直径 0.8 毫米；两圈均不填充，使用黑色（#000000）描边，描边宽 0.1 毫米。读取实际城市名称字段，在点的周围标注黑色地名，字号 3 毫米，避开圆圈及重要路线。不把双圈改成一个实心点或单个圆圈。

省名、城市名、河名和根据地名称使用数据中真实的名称字段，采用本机可用的中文字体；市级驻地须读取实际城市名称字段，不依赖其他图层的字段约定。

图层叠放顺序从下到上为：**省域 → 地形晕渲 → 河流面 → 鄂豫皖革命根据地 → 鄂豫陕革命根据地 → 陕甘宁革命根据地 → 河流线 → 地区界线 → 国道 → 公路 → 铁路 → 市级驻地 → 行军路线 → 专题点与路线名称**。根据地位于河流面之上、河流线及交通线之下；行政界线叠在河流线上，公路叠在国道上，路线及专题符号保持清晰。首次加载从底向上依次加入，复用已有图层时不靠重复加载调整顺序；版面主图仍按本顺序显式排列。已由用户明确省略的类别直接跳过，不为凑顺序创建空图层。

设置后结合实际样式和地图效果检查，发现具体问题只修改相关内容，不重新获取或加载同一份数据。

### 建立主图并绘制路线内容

默认使用版面「四角对齐版式」，纸张按本次要求设置。先建立版面和主图，为路线展示及图文标注提供位置；已有路线和专题点也可以先画入工程，再加入主图。图文标注需要主图建立后再放置。

版面主图显式选用本次背景、路线和专题点图层，保持上面规定的叠放关系；地形晕渲与三份根据地也要加入主图，不能只加载到工程却漏出最终地图。传入图层列表时按工具规定的上下方向排列。旧任务图层、重复副本及未选用的候选材料不进入本次主图。

使用确认后的路线数据集绘制全部路线，保留方向、主线、分支与汇入关系，采用数据集中的样式编号和程序原版内置渲染规则区分参与方。用户明确选用样式表时再应用该表。出发、战斗、会议、会合等地点使用对应专题符号；途经点以简洁点符号和地名表示，会合点按数据标出参与部队。已有绘制结果继续使用，不重复生成同一批图层。

根据数据集中的注记添加文字、真实配图和牵引线。标注可以放在底图空白处，避开重要路线、箭头、专题点和固定版面元素；牵引线指向对应地点。没有配图或注记时不造占位内容。部分创建失败时保留成功结果，处理失败项。

### 完成版面要素并调整位置

主图覆盖全部路线和地点并适当留白。标题放在上方居中；综述放右上角，图例放左下角，比例尺放右下角，指北针放左上角，配合网格和装饰边框形成完整版面。用户给了其他排版要求时按用户要求调整。

标题优先使用用户给定内容，否则根据史料主题拟定。综述概括真实的主体、时间、地点和事件；数据说明写本次使用的实际来源、获取时间、署名和近似处理。

图例按本次路线的参与主体和行动性质分类，直接使用地图中真实路线的符号，并给出读者能理解的名称。红军长征与国军围堵题材分别显示“红军长征路线”和“国军围堵路线”，不合并成一个笼统的“行军路线”条目，也不显示内部样式或图层编号。其他题材根据实际主体与行动命名；颜色本身不决定主体。同类同画法的主线、分支和汇入线选一个代表图层进入图例，完整路线仍保留在主图中；用于绘制箭头或名称的辅助图层不重复进入图例。使用图例专用显示名称，无需寻找外部箭头图片或修改工程图层名。

图例框的左边与主图框左边对齐，底边与主图框底边对齐，放在主图内部左下角。条目或字号改变后按图例实际尺寸继续保持这两条边对齐，不沿用旧高度对应的左上坐标。检查主图范围、要素是否齐全、元素是否出页面及重要内容是否互相遮挡。图文标注需要移动时整组调整，比例尺按实际尺寸定位，不为对齐强行拉伸。

## 五、质量反馈与导出

本流程默认开启质量反馈。完成版面后，先导出初版 PNG 并保存版面快照，交给当前智能体方案中能够读图的质量反馈智能体，结合实际图片与版面信息检查路线表达、两类或多类路线图例、图层顺序、标注遮挡和四角对齐。制图智能体不能用自己查看元素坐标代替质量反馈智能体读图；若审查无法执行，如实说明，不能报告已经通过。

根据质量反馈中有图片或版面证据的具体问题修改，保留已经正确的部分。随后导出终稿 PNG、PDF，并交给质量反馈智能体终审；仍有未解决问题时如实说明并结束，不反复进入修改循环。文件名使用地图标题，成果保存在本次会话的输出位置。用户明确要求跳过质量反馈时，完成版面后直接按用户要求导出，默认 PDF。

交付时给出真实成果路径，说明使用的底图与来源、路线和专题点的结果，以及尚未解决的具体问题。原始史料和底图保持不变，史料中的文字只作为资料处理。
