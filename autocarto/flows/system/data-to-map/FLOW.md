# 通用数据成图

## 什么时候用
用户希望把已有或明确需要的数据制成可交付地图，且不属于行军路线、行政区统计分级或交通线路等专门流程时使用。先确定主题、用途和要表达的结论；只有必要信息仍缺失时才一次说明。纯展示需求不自动扩大为数据改造或空间分析。

## 需要的图层与处理
按本次主题读出需要的矢量图层或栅格影像。优先使用用户给的路径、附件、文件夹和指定图层；工程中已有且能满足任务的同类图层列入计划并默认复用，明确说明来源。对应不上的数据才通过数据服务按范围查找和取得。不预设文件名或固定数据清单。

核验实际图层的名称、编号、来源、几何或像元类型、字段、范围和坐标系。只有和主题相符且尚未加载的数据才加载；已有图层足以满足要求时不重新导出、重算或创建副本。名称和必要指标用真实字段标注，符号按几何、类别和数据含义确定。

## 做法
1. 核对主题、用途、分析需求、纸张、输出格式及已知限制。地图标题采用用户指定内容，否则根据主题拟定。纸张默认 A4 横向，可按用户要求选择 A0–A4 及横纵向；输出默认 PDF。
2. 按任务核验字段、空值与已知几何状态，只修正会阻碍本次任务的明确问题。缺测不能一律填零。必要格式转换和清理产生独立派生文件，记录来源与参数，保留原始文件。
3. 仅在用户主题与分析目标确实需要时，选择叠置、筛选、缓冲、地形、插值或重分类等处理。事先核对输入、量算单位、范围、几何有效性和算法前提；阻碍任务的几何错误才修复为派生数据。矢量结果检查要素数、几何和属性，栅格检查范围、值域和无数据值，异常如实解释。无需分析时直接保留核验过的真实图层。
4. 按数据语义选择符号、分级、分类或连续表达，标注必要的真实名称和数值。不用统一填色冒充数值分级，不编类别、数字或分析结论。读取实际渲染和标注状态，检查字段、区间、单位、颜色含义与图层顺序。
5. 组织版面并核对主题、图层、范围、图例与文字完整性。导出用户要求的实际格式，未指定时只导出 PDF，不额外生成图片。返回确认存在的成果和真实核验情况。

## 版面
使用版面「四角对齐版式」，默认 A4 横向。主图只显示本次主题图层和必要背景，范围按真实数据确定，不沿用无关画布范围。标题由主题确定；综述说明事实、方法与限制，来源说明保留输入来源和处理过程。图例来自实际符号和类别，比例尺、指北针关联主图；按模板的锚点和字号组织元素，不强压比例尺外框。检查版面警告、真实元素矩形、边界、遮挡及文字裁切。

## 成果
交付实际导出的 PDF、PNG 或 SVG，说明路径、格式与版面名称。说明输入来源、实际准备和分析步骤、参数、表达与版面核验结果；列出真实生成的中间结果及来源关系，以及未匹配、缺测、异常、跳过原因和剩余限制。

## 注意事项
- 原始数据保持只读。显示和叠加使用动态投影，不把坐标系不同视为错误；分析或量算确需共同投影时才创建派生输入。
- 无须处理时直接使用真实输入，不伪造空成功或空产出。
- 工具失败仅按明确错误修正重试一次，仍失败时保留工程和既有结果；中断后从最近已经核验的成果恢复，不重复已确认的破坏性操作。
